# zing

简体中文 · [English](README.en.md)

一个让日常浏览器操作更顺手的 Chrome 命令面板。

个人本地加载版，无账号、后端或遥测。

## 功能

### Command Palette

在一个入口查找标签页、书签和浏览器命令。命中词高亮，相关命令优先，常选结果按使用习惯前移。点击结果或按 Enter 执行，通过「操作」菜单管理选中的标签页。

### Tab Switcher

按最近使用顺序切换当前窗口的标签页，也可输入标题或网址筛选。按住快捷键连续选择，松开确认，快速回到上一个标签页。

### Auto Tuck

把 7 天未使用的标签页自动放进折叠的「已收起」组，让标签栏留给正在做的事。页面保持打开，随时搜索或点击找回一页。默认关闭，也可手动收起、撤销收起。

## 交互原则

**Human first**：人可以用熟悉的快捷键，也可以用鼠标，并随时在两者之间切换。使用 zing 不应以记住快捷键为前提。

- **操作找得到**：常用操作有清楚、可点击的入口，更多操作集中在「操作」菜单；快捷键在对应入口旁提示。
- **同一操作，同一逻辑**：点击与快捷键使用相同的操作、状态和返回路径，切换输入方式不丢失当前上下文。
- **反馈及时，返回自然**：执行、等待、成功和失败都有明确反馈；返回上一层保留搜索、选中项和编辑位置，文本编辑遵循熟悉的习惯。

这些原则是后续设计与验收的标准。

## 安装

需要 Node.js / npm 和 Chrome 127+。

```sh
npm ci
npm run build
```

1. 打开 `chrome://extensions`，开启「开发者模式」。
2. 选择「加载已解压的扩展程序」，加载本项目生成的 **dist/** 目录。
3. 点击工具栏的 zing 图标，或按 **Cmd+Shift+P**（Windows/Linux 为 **Ctrl+Shift+P**）。

`dist/` 不纳入 Git，首次克隆后需要构建。快捷键冲突时，在 `chrome://extensions/shortcuts` 中修改；也可搜索「快捷键」进入设置。

## 开始使用

输入关键词即可搜索，不需要模式前缀。例如标签页标题、网站域名、`new tab`、`settings`，也支持相应中文关键词。

主搜索中，点击结果即可执行，也可以用方向键选择后按 Enter。底栏的主操作和「操作」按钮都可点击。

主搜索与二级列表页共用同一底栏：左侧依次是单色图标按钮、当前位置名称和 `·` 分隔的补充信息。主搜索显示设置齿轮与 `zing`，二级页（如 Local Storage、标签组）显示返回箭头与存储类型名称或组名，无单独标题栏。点击返回箭头与按 Esc 一样，每次退出最深的一层。名称使用统一的弱化文字样式，旁边不再叠加品牌装饰、类型图标或组色图标；右侧仍是主操作与「操作」菜单。

主搜索与 Tab Switcher 的导航提示、二级页的站点来源或成员数量共用补充信息位置，均使用 11px 的弱化辅助文字；导航按键无键帽框，右侧主操作与「操作」的键帽仍保留边框和背景。短暂状态反馈在同一位置替换它们。宽度不超过 520px 时，仅隐藏补充信息，包括主搜索与 Tab Switcher 的导航提示；复制成功、执行中或危险操作等状态反馈仍在该位置显示，必要时截断。图标按钮和名称始终保留，长名称先于操作控件截断，按钮不收缩。常规面板总高 516px、底栏 44px、列表行 40px，切换前后底栏和搜索框位置保持一致；Storage 的名称和值预览并排显示。

| 操作 | 鼠标入口 | macOS 快捷键 |
| --- | --- | --- |
| 执行搜索结果 | 点击结果或底栏主操作 | ↑ / ↓ 或 Ctrl+P / Ctrl+N 选择，Enter 执行 |
| 当前候选项的更多操作 | 底栏「操作」按钮，再点击菜单项 | Cmd+K |
| 打开设置 | 底栏设置按钮 | Cmd+, |
| 返回上一层 | 点击底栏左侧的返回箭头 | Esc；空搜索框也可用 Backspace |
| 关闭主面板 | 搜索栏右侧关闭按钮 | Esc |

最近标签页还提供按住快捷键连续选择的方式：按住 Control+J，N/P 选择，松开 Control 确认。

Tab Switcher 的网页浮层与独立窗口共用主搜索的搜索胶囊和列表布局。打开时搜索框为空且禁用，焦点留在候选列表，显示「搜索最近标签页…」。点击搜索图标、输入区域或按 Cmd+F（Windows/Linux 为 Ctrl+F）进入搜索，此后松开启动修饰键不会切页，可正常输入，再用普通 Enter、点击候选项或底栏「切换」确认；未进入搜索时仍按松键确认。按标题或网址筛选，不区分大小写，空白分隔的每个词都须命中，结果保持最近使用顺序并高亮匹配文字。修改搜索词时保留仍可见的选中页，否则选择首项；无匹配时不会切换标签页。

Tab Switcher 也复用同一套 44px 底栏：左侧在快速切换时显示「松开 Ctrl 切换」，进入搜索后显示「切换最近标签页」，后接与主搜索完全相同的「选择 ↑ Ctrl P ↓ Ctrl N」（英文为「Navigate ↑ Ctrl P ↓ Ctrl N」），悬停导航提示可查看方向键、Ctrl+P/N 与点击选择的说明。右侧是可点击的「切换 ↵」「取消 esc」，均先显示文字、再显示键帽。窄屏仅隐藏导航提示，保留松键提示或搜索状态标题；实际启动快捷键可悬停搜索栏查看。网页浮层填满面板可用空间，底部不另占一行帮助文字。

Windows/Linux 的菜单和设置操作使用 Ctrl 代替 Command；最近标签切换默认使用 Ctrl+,。多层返回、文本编辑和平台差异见 [使用指南](docs/USAGE.md)。

## 使用边界与数据

普通网页显示按页面视口水平居中、偏上的浮层，最大 750×516px，小视口按可用空间缩小。Chrome 内置页的命令面板，以及最近标签切换无法使用网页浮层时，使用独立窗口，按来源内容区与缩放比例估算位置，内容缩放跟随来源页，并在显示界面前通过 Chrome API 返回的窗口与标签页尺寸校准自身原生边框；系统标题栏仍保留。

独立窗口使用 Chrome 返回的来源标签页内容尺寸和浏览器外框尺寸（DIP），按水平对称、底边对齐估算内容区，再结合来源页缩放计算位置和尺寸。来源内容区的屏幕原点无法直接测量，垂直标签栏、停靠 DevTools 和系统边框可能造成偏差，不能保证像素级对齐。

命令面板在普通网页地址栏持有焦点、Web Store 等其他受限场景仍使用工具栏弹窗，其位置由 Chrome 控制。最近标签切换在地址栏等未监听区域快速点按时可能需要 Enter 确认。

偏好、保存的脚本及搜索使用记录只存本机；页面存储值和脚本结果仅保留在当前面板。

收起不会关闭或主动卸载页面。重启浏览器或重新加载扩展后，zing 会根据本机保存的记录恢复管理；无法唯一确认时，搜索「恢复收起组」，核对页面后选择「继续管理这组」。待确认期间避免重复建组。记录只在本机保存，不记录无痕页面。详见 [收起标签页](docs/USAGE.md#收起标签页)。

其他功能、权限与限制，以及 Ctrl+Tab 手动配置见 [使用指南](docs/USAGE.md)。

## 开发与测试

React、TypeScript、Fuse.js、esbuild。测试使用独立临时浏览器配置和本地页面。

```sh
npm run dev                       # 监听源码并构建
npx playwright install chromium   # 首次浏览器测试前安装
npm run check                     # 类型检查、单元测试、构建、端到端测试
```

日常按影响范围运行 `npm run typecheck`、`npm test` 和 `npm run test:e2e -- --grep '<用例筛选>'`；E2E 入口会先构建，并为本轮保存独立产物与 `validation.json`。`npm run check` 运行完整套件，当前定位矩阵仍有未解决项。`ZING_CHROMIUM_PATH` 可指定 Chrome for Testing 可执行文件；Vimium 兼容用例仅在提供 `ZING_VIMIUM_PATH` 且确认扩展加载后执行，缺少路径时明确跳过。运行方式与验收边界见[测试指南](docs/TESTING.md)。

构建后在 Chrome 扩展管理页重新加载 zing，并刷新测试网页。`public/` 的 manifest 或语言包改变后需重新运行构建。`dist/`、依赖和测试截图不提交到 Git。
