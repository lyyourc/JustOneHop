# zing · 浏览器命令面板

个人使用的 Chrome Manifest V3 扩展。网页上方居中的命令浮层，采用 Raycast 风格交互，统一搜索标签页、书签和浏览器命令。所有代码和数据处理都在本地，无账号、后端或遥测。

## 本地安装

当前已构建好 `dist/`，直接加载即可：

1. Chrome 地址栏打开 `chrome://extensions`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目的 **`dist` 文件夹**。
4. 按 `Cmd+Shift+P` 打开面板，也可以点击扩展图标。

若快捷键冲突，在 `chrome://extensions/shortcuts` 中找到「zing」，重新绑定「打开 / 关闭命令面板」。首次安装后建议把 zing 固定到工具栏，作为快捷键之外的入口。

要求 Chrome 127 或更高版本。Windows / Linux 默认快捷键为 `Ctrl+Shift+P`。

## 使用

| 操作 | 效果 |
| --- | --- |
| `Cmd+Shift+P` | 打开 / 关闭面板，输入框初始为空 |
| 直接输入关键词 | 同时搜索当前窗口所有标签页、全部书签和浏览器命令；支持中文、英文和常用拼音关键词 |
| `↑` / `↓` | 循环选择结果；也支持 `Ctrl+P` / `Ctrl+N` |
| `Option+↑` / `Option+↓`、`PageUp` / `PageDown` | 按可见列表高度翻页 |
| `Cmd+↑` / `Cmd+↓` | 空搜索时跳转最近标签页 / 常用命令分组；有关键词时跳到首尾 |
| `Enter` | 执行命令、切换标签页或在新标签页打开书签 |
| `Cmd+K` | 打开 / 关闭当前结果的操作菜单 |
| `Cmd+,` | 打开设置；也可点击左下角齿轮，或搜索 `设置` / `settings` |
| `Esc` | 从操作菜单返回；再次按下关闭面板 |
| 点击面板外 | 关闭操作菜单或主面板 |

命令包括：新建、刷新、关闭当前 / 其他 / 右侧标签页、恢复最近关闭的标签页或窗口、固定 / 取消固定、静音 / 取消静音，以及 Local Storage、Session Storage 和 Cookies 的查看与复制。

空输入展示最多 6 个最近使用的标签页，再列出常用命令。标签页按 Chrome 提供的最近激活时间排序，当前页面放在其他标签页之后，方便直接回车切回上一页。命令结合使用频率和最近使用时间排序，汇总搜索结果、首页和 Cmd+K 中成功执行的记录；已有记录直接生效，没有记录的命令保留默认顺序。关闭类命令仍通过明确搜索或 Cmd+K 进入。书签和其他标签页可直接输入搜索。

列表直接从搜索框下方开始，不显示 Quick Access、Common Commands 或结果数量等标题；首页以轻分隔线区分标签页和命令，搜索时仍显示结果类型。底栏集中展示 `Ctrl+P` / `Ctrl+N` 上下选择、Enter 执行和 Cmd+K 操作入口，窄窗口仍保留导航键提示。结果数量仅提供给屏幕阅读器；批量关闭时，底栏优先显示关闭数量。

默认搜索优先级：精确命令名称或内置别名 → 完整网页标题 → 名称前缀 → 词边界连续匹配 → 名称包含全部搜索词 → URL、目录等关键词 → 模糊匹配。中英文命令别名不受界面语言影响，例如 `new tab` 优先「新建标签页」，`New Tab Guide` 优先同名网页。没有学习记录时，完整标题相同的结果优先已打开的标签页，标签页之间保留最近使用顺序。结果仍标注类型，拼写容错由 Fuse.js 提供。

同一个搜索词下，成功选择过的结果会结合使用频率和最近使用时间前移；大小写和多余空格视为同一查询。精确命令、完整标题仍优先，模糊命中不会超过字面命中，也不会让无关结果重新出现。习惯记录只保存在本机，标签页按网址识别，关闭重开后仍有效。仅移动选中项、取消和执行失败不计入；空搜索切换标签页和无痕窗口不记录。Cmd+K 的次要操作（如静音目标标签页）计入命令使用习惯，不影响该网页在主搜索中的偏好。设置 → 搜索排序中的重置会同时清除首页命令和同词搜索的学习记录。

关闭类命令需要明确输入「关闭」、`close` 或 `guanbi`，也可在目标标签页的 Cmd+K 操作菜单中选择。没有模式按钮，`>` 作为普通搜索文字处理。

三个字符以内的搜索词只接受连续字面命中；中文、网址、书签目录、拼音和辅助关键词也不做错字扩展。较长的英文名称仅在长度相近的单词中保留有限拼写容错，例如 `reloda` 可以找到 Reload，`iam` 不会匹配 New Tab 的 `xinjian`。多词搜索要求每个词都满足规则。

标题、网址及 Cmd+K 操作菜单会以淡色底纹高亮匹配文字，使用与搜索一致的匹配规则。跨语言命中命令时会显示匹配的内置别名，例如中文「新建标签页」旁显示高亮的 `new tab`。空搜索不显示高亮，浅色和深色主题均适配。

在标签页的操作菜单中，命令作用于**选中的标签页**，不需要先切换过去。批量关闭仅作用于当前窗口，并保留固定标签页；底部显示预计关闭数量。单独「关闭标签页」仍可关闭固定标签页。

界面随系统切换浅色 / 深色，配色参考 [Snazzy](https://github.com/sindresorhus/hyper-snazzy)：深色采用蓝灰背景，粉色焦点、蓝色标签页、绿色命令与淡黄色命中高亮；浅色使用同系颜色的较深版本，保证文字对比度。结果采用单行紧凑列表，操作菜单固定在右下角，底部直接输入筛选操作。关闭操作菜单会恢复搜索词、选中项和原来的光标位置；鼠标静止时不会抢走键盘选中项。

所有功能入口都应能从主搜索找到。输入「语言 / language」「主题 / theme」「快捷键 / hotkey」「搜索排序 / search ranking」并按 Enter，打开设置并直接聚焦对应控件，Esc 返回原搜索；搜索排序的重置仍需点击或按 Enter 确认执行。设置包含语言、主题、搜索排序和打开面板的快捷键。语言默认跟随 Chrome 界面语言（通常与系统一致），也可固定选择「简体中文」或「English」；其他系统语言回退到英文，繁体中文环境暂时使用简体中文文案。主题支持「跟随系统 / 浅色 / 深色」。两项更改立即生效并保存到本机，也会同步到其他已打开的面板。不论界面语言是什么，命令和操作都可以用中英文关键词搜索。

快捷键显示 Chrome 当前实际绑定（未绑定时会明确提示），默认 `Cmd+Shift+P`。点击「前往修改」打开 Chrome 扩展快捷键页，在 zing 下录入新组合；再次打开面板会读取新绑定。Chrome 未提供扩展自行修改绑定的 API。设置中 `Tab` 移动焦点，方向键和 Enter 选择选项，`Esc` 逐级关闭下拉菜单、返回搜索、关闭面板；返回搜索保留关键词、选中项和光标。

手动语言设置用于 zing 面板；Chrome 扩展管理页里的名称和描述仍由 Chrome 自身语言决定。

普通网页使用居中浮层。Chrome 内部页面、Chrome Web Store 等不允许注入的页面，会使用工具栏扩展弹窗，搜索和操作保持一致。PDF 查看器的表现受 Chrome 注入限制影响。文件页未允许文件访问时同样走备用弹窗。

书签按名称、URL、文件夹搜索；脚本书签（`javascript:`）不执行。恢复操作使用 Chrome 最近关闭记录，可能恢复原窗口中的标签页或整个窗口。搜索最多显示 100 条结果，继续输入可缩小范围。

## 脚本收藏与 Ctrl+Tab 配置

设置 → 键盘 →「设置 Ctrl+Tab」提供内置绑定代码，自动使用当前安装的扩展 ID。先复制代码，再打开 Chrome 快捷键页，按页面说明在该页的 DevTools Console 中执行。该入口绑定 Ctrl+Tab / Ctrl+Shift+Tab；Chrome 内部接口不能从扩展设置页直接调用。

主搜索输入「新建脚本 / new script」直接创建；输入「脚本 / scripts / 管理脚本」打开脚本收藏。设置中的「管理脚本」保留为额外入口。命令面板支持按名称搜索脚本，Enter 在当前网页运行一次并显示结果。Cmd+K（Windows/Linux 为 Ctrl+K）打开操作菜单，可选择运行、运行并复制结果、复制代码、编辑或删除；支持搜索动作和 Ctrl+N/P 导航。也可以搜索「运行脚本 / run script」或「运行并复制结果 / run and copy result」，再选择已保存的脚本。编辑页沿用主面板的共用底栏：Cmd+Enter（Windows/Linux 为 Ctrl+Enter）保存，Cmd+K 打开复制、保存或删除操作；普通 Enter 在代码框中换行。编辑保存或 Esc 返回原搜索，保留搜索词、选中项与光标。删除先确认，默认聚焦取消；内置 Ctrl+Tab 脚本仅提供复制和查看设置说明。脚本仅保存于本机，仅在手动选择运行时执行；代码正文不参与搜索或使用习惯记录。内置 Ctrl+Tab 配置也可以直接搜索「ctrl tab」找到。

脚本执行需要 Chrome 135+。Chrome 138+ 首次使用时，按提示打开 zing 的扩展详情并开启「允许用户脚本」；Chrome 135–137 使用开发者模式。普通 HTTP(S) 网页通过已有 activeTab 临时授权运行，不申请全站主机权限。Chrome 内置页和内置 Ctrl+Tab 配置代码仍需手动执行。

例如保存名为「复制 token」的脚本：

```js
localStorage.getItem("token")
```

在目标网站打开 zing，搜索脚本名并按 Enter 查看结果，或 Cmd+K 选择「运行并复制结果」。代码最后一个表达式作为结果，Promise 会等待完成；异步多步逻辑可使用 async 函数立即调用。字符串原样保留，对象显示为格式化 JSON。结果仅在本次面板内显示、不保存；查看结果后 Enter 默认复制，不会重复运行。Esc 返回原搜索，退出等待中的脚本后不再自动复制，但已开始的脚本可能继续执行。

脚本运行在 Chrome 的隔离用户脚本环境，可访问当前顶层页面的 DOM、Local Storage 和 Session Storage；不提供网页自身的 JavaScript 变量、扩展 API 或油猴的 GM_* API。zing 不上传代码或结果；脚本本身可以修改页面或发起网络请求，具体行为取决于保存的代码。

## 最近标签页切换

遵循 VS Code Ctrl+Tab 的“选择后确认”交互。macOS 按 **Control+J** 打开独立小窗口，默认高亮上一个标签页，页面暂不切换。保持 Control，使用 **N/P**、↑/↓ 或重复 J 移动高亮；Shift+J 反向。**松开 Control 才切换到选中页并收起窗口**；Enter 或点击选中项同样确认。Esc、失焦或起始页被关闭/移走均取消，选择期间不激活候选标签页，列表顺序固定。

普通 HTTP(S) 网页预加载轻量修饰键监听，快速点按可直接切到上一页，无需 Enter；按住时仍打开独立窗口。窗口准备好后才接管焦点，加载期间的松键会被缓冲。扩展更新前已打开的网页需刷新一次才能启用监听。地址栏、Chrome 内置页、Web Store 等受限页面仍使用独立窗口兜底，极短点按可能需要 Enter；不以定时器猜测松键。原来的 Cmd+Shift+P 保持不变。Windows/Linux 默认 Ctrl+, 与 Ctrl+Shift+,，尚未做对应系统原生输入验收。详见 [切换器说明](docs/RECENT-TABS-PROTOTYPE.md)。

## 页面存储

搜索 `local storage`、`session storage`、`cookie`（也支持「本地存储」「会话存储」），Enter 打开当前页面的存储列表。输入名称筛选，↑/↓ 或 Ctrl+P/N 选择，Enter 复制原始值；Cmd+K 提供复制名称、查看详情和刷新。详情中的 JSON 自动格式化，复制仍保留原始字符串；Ctrl+P/N 或方向键滚动长内容。Esc 逐层返回，并恢复原来的搜索、选择和焦点。

Local/Session Storage 读取当前标签页的顶层页面；Cookie 列出与当前页面 URL 匹配的记录，包括 HttpOnly，并显示域名、路径、有效期与分区信息。Chrome 132+ 额外读取当前顶层页面对应的分区 Cookie；较旧版本读取普通 Cookie。页面导航后需重新打开 zing。Chrome 内部页等非 HTTP(S) 页面会显示说明。

Local/Session Storage 使用已有 `activeTab` 临时授权。Cookie 首次使用时点击「允许访问此网站」，在授权页确认域名后由 Chrome 请求网站权限；授权后自动返回列表。同一网站后续无需重复授权，可在 Chrome 的扩展设置中撤销。为完整读取普通和父域 Cookie，授权范围包含当前主机和必要的父域（HTTP/HTTPS），不含其他子域或所有网站。存储内容只在当前面板内存中显示，不写入扩展存储或日志，不上传；仅成功打开存储命令计入排序，条目名称、值、列表搜索和刷新不计入。该版本仅支持查看与复制。

可用 `node tests/storage-manual.mjs` 启动临时本地验收页，终端会输出 URL；页面含可复制的 Local/Session 测试值和 HttpOnly Cookie。

## 开发与测试

```sh
npm ci
npm run build
npm run check
```

`npm run check` 依次执行类型检查、逻辑测试、构建和真实 Chromium 扩展端到端测试。首次测试若缺少浏览器，运行 `npx playwright install chromium`；也可以通过 `ZING_CHROMIUM_PATH` 指定 Chrome for Testing 可执行文件。测试使用独立的临时浏览器配置和本地 HTTP 页面，退出时清理测试配置。可通过 `ZING_VIMIUM_PATH=/path/to/vimium npm run test:e2e` 同时加载 Vimium 源码，验证键盘兼容性。

```sh
npm run dev
```

监视源码变更并重新构建。在 Chrome 扩展管理页点击「重新加载」后，再刷新用于测试的网页。更改 `public/` 下的 manifest 或语言包后需重新运行构建命令。

## 实现与权限

- React + TypeScript；Fuse.js 做中英文模糊搜索，Lucide 图标，esbuild 构建。
- 语言包在 `public/_locales/`：manifest 使用 Chrome 原生 i18n，面板复用相同文案并优先读取手动语言选择；`en` 是默认回退语言。构建时将 `zh_CN` 复制为 `zh_TW`，共用一份中文文案。
- 页面内容脚本使用隔离的 Shadow DOM 和原生 modal dialog，在浏览器 top layer 中显示；内部空白沙箱框架隔离键盘事件，兼容 Vimium 的字母快捷键和 Esc。框架不加载外部页面或执行脚本，UI 仍由原内容脚本渲染。
- Service worker 负责读取浏览器状态和执行命令。每次执行会重新核对标签页所属窗口、当前位置与固定 / 静音状态。
- `activeTab`、`scripting`：仅用户唤起时注入命令面板。
- `userScripts`：用户主动选择已保存脚本时，在隔离的 USER_SCRIPT 环境运行一次；不注册自动执行脚本。执行前核对当前页面，并绑定具体文档，防止导航期间误在新页面执行。
- `tabs`：读取标签页标题、URL、状态并执行标签管理。
- `bookmarks`：读取书签供搜索。本版本不增删书签。
- `sessions`：恢复最近关闭内容。
- `cookies`：读取 Cookie，包含 HttpOnly；不增删或修改 Cookie。
- `content_scripts.matches`：普通 HTTP(S) 页面及其匹配子框架预加载轻量修饰键监听，只在内存保存 Control/Alt/Meta 状态，按需转发松键；不记录输入文字、不拦截网页快捷键、不上传数据。未增加全站 `host_permissions`，Cookie 仍逐站授权。
- `optional_host_permissions`：声明可按需申请 HTTP(S) 网站权限；首次查看 Cookies 时只请求授权页列出的具体域名，不预先授予所有网站访问权。
- `storage`：仅在本机保存语言、主题偏好、脚本收藏及搜索选择记录，不使用云端同步。搜索记录最多 500 条，90 天未使用的记录不再参与排序，并在下次记录时清理；频次权重每 14 天减半，让新习惯逐渐取代旧习惯。

操作组件与位置约束见 [交互架构](docs/INTERACTION-ARCHITECTURE.md)。验收记录见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。
