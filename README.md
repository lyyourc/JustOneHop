# zing

简体中文 · [English](README.en.md)

一个让日常浏览器操作更顺手的 Chrome 命令面板。

个人本地加载版，无账号、后端或遥测。

## 功能

### Command Palette

在一个入口查找标签页、书签、浏览历史和浏览器命令。命中词仅加粗提示，相关命令优先；支持学习的结果可按同词使用习惯在同级内前移。普通单击结果或按 Enter 执行；在主搜索或历史搜索中拖选结果文字后松开鼠标不会跳转。这两处搜索中，标签页、历史和书签等带 URL 的候选可从「操作」菜单选择「复制 URL」，复制完整地址，不打开页面或记录排序偏好，成功后保留搜索词、选中项和输入光标／选区。

关闭非来源页、固定、静音等整理操作完成后，zing 保持打开，保留搜索和输入位置；删除结果后选中相邻项，可连续整理。切换标签页、打开页面等导航操作完成后关闭面板。唤起 zing 的来源页（source）一旦被删除，无论是直接关闭、批量关闭连带删除，还是在 Chrome 中外部关闭，都结束当前 zing 会话；不新建独立面板，也不将已有面板重绑到其他标签页。结束当前页后回到 Chrome 自然选中的相邻页，不用额外 popup 抢焦点；关闭来源窗口或最后一页同样结束会话。窗口承载方式与定位不变。

### 收藏标签页

在主搜索输入 `bookmark tab / 收藏标签页` 收藏来源页，结果右侧显示 Chrome 收藏快捷键 `⌘D`（Windows/Linux 为 `Ctrl+D`）；取消收藏不显示此键帽。主列表与标签组成员的右键、「操作」或 Cmd/Ctrl+K 菜单则作用于所选标签页，普通点击和 Enter 仍切换页面。收藏使用 Chrome 原生书签，默认存入「其他书签 / Other bookmarks」，已有相同完整 URL 时不重复创建；查询参数与片段不同视为不同页面。

`bookmark / bookmark tab / add bookmark / save bookmark / 收藏 / 收藏标签页 / 添加书签` 按当前状态显示收藏或「取消收藏 / Unbookmark」；收藏后原查询直接显示取消动作。输入 `book`、`bookm` 等 `bookmark` 前缀也会优先显示当前状态命令；`unbook` 等 `unbookmark` 前缀只查取消收藏。`book guide` 等页面查询不享受这项提升。取消仍为危险操作，两种动作均不进入首页推荐；单独 `书签 / tab / close` 或错字不放行取消，明确的 `unbookmark / remove bookmark / 取消收藏 / 删除书签` 也不会反向添加。主搜索收藏成功后清空选择，避免再次 Enter 直接删除，需用方向键主动选择或点击结果；菜单收藏保留原标签页选中。取消单条直接执行；同 URL 多条书签先显示数量和目录，默认聚焦取消，确认后删除全部匹配项。匹配中包含受管理书签时整批拒绝；目标或确认集合变化时需刷新核对后重试，删除中途失败会如实提示可能已部分删除。操作后保留面板与搜索上下文。复用已有 `bookmarks` 权限，原生书签是否同步由 Chrome 设置决定，zing 不提供额外同步服务。

书签搜索结果的右键、「操作」或 Cmd/Ctrl+K 菜单提供「取消收藏 / Unbookmark」，只删除所选书签 ID，无需该 URL 已在标签页打开；同 URL 的其他书签保留。仅所选条目或其祖先受管理时拒绝，不因其他同 URL 书签受管理而阻止；执行前发现所选书签的 URL 已变化也拒绝。成功后保留面板、搜索词和输入位置，结果移除后选择相邻项。标签页菜单的取消收藏仍遵循上述全部同 URL 书签规则。

### 浏览历史搜索

输入关键词时同时搜索 Chrome 最近一周的历史（不限定从 zing 打开的页面），最多返回 100 个历史匹配；等待最多 100ms 后与其他来源一次性呈现，迟到结果不插入。普通关键词的第 7 条提供「搜索全部历史」（不足 6 条结果时放末尾）；输入 `history / 历史 / 搜索历史` 时该入口置顶，进入空搜索框，点击或 Enter 在面板内搜索全部时间；加载时仍可编辑关键词或返回。超时、无匹配与读取失败分别提示。历史页面在来源窗口新标签页打开，与匹配标签页／书签相同 URL 的历史候选去重。安装时申请 `history` 权限，只读 HTTP(S) 历史，不持久复制历史库。仅显式选择并成功打开后在本机记住搜索词与网站地址；读取接口本身和打开失败均不记录。无痕窗口不读取普通历史，也不记录选择。

搜索结果共用图标、标题与说明、右侧元信息布局。主搜索的「当前 / Current」在分类右侧以无背景的弱化文字显示，样式与历史时间一致。历史显示最近访问时间（刚刚、几分钟前、今天／昨天时分或日期），悬停可查看完整本地时间；窄屏仍保留时间。

### Chrome 内置页面

搜索 `extension`、`password` 或相应中文关键词，快速打开扩展管理、密码管理器、下载内容、历史记录、书签管理器、Chrome 设置和扩展快捷键。当前窗口已有相同目标地址时切换过去，否则新建标签页；保留当前网页及原生页面中的其他子页。输入「Chrome 内置页面 / Chrome Pages」可查找整组入口，空搜索时不显示。`settings / 设置` 仍打开 zing 设置。这些入口只负责跳转，不读取密码、历史或下载数据，不增加权限。

### Tab Switcher

「Zing: Tab Switcher」显示「Switch tabs like in VS Code」说明及 Chrome 实际绑定的启动快捷键，未绑定时不显示键帽。设置页同步显示实际绑定或「未绑定」；Ctrl+Tab 是可选的一次性配置。从首页或搜索选择该命令，在当前面板内按最近使用顺序浏览当前窗口标签页，直接输入标题或网址筛选；点击、Enter 或底栏「切换」确认，取消、Esc 或底栏返回恢复主搜索的查询、选择与输入位置。快捷键启动仍支持按住连续选择、松开确认，快速回到上一个标签页。

### 脚本收藏

搜索「脚本 / scripts」管理本机保存的脚本：左侧列表选择脚本，右侧即时显示只读代码预览、名称和内容类型 JavaScript。单击仅选择预览，悬停不改变选择；方向键或 Ctrl+N/P 同样切换预览，Enter 或底栏「复制代码」复制选中脚本。编辑从右键或「操作」菜单进入，内置项提供「查看配置说明」。底栏「新建脚本」（窄屏为加号）或 Cmd+Shift+N（Windows/Linux 为 Ctrl+Shift+N）创建，名称与代码表单用 Cmd/Ctrl+Enter 保存，删除需确认。宽度不超过 520px 时列表在上、预览在下，两者独立滚动。搜索「运行脚本 / run script」仍打开全宽选择列表，点击或 Enter 在当前网页运行一次。脚本仅显式运行，不自动展开文本或随网页加载执行；结果只留在当前面板。

### 页面存储

搜索 `local storage`、`session storage` 或 `cookie` 查看当前网站存储。与脚本收藏一致，左侧选择 key，右侧上方直接展示只读 value，下方显示 key、内容类型与 Cookie 属性；单击只选择，Enter 或底栏「复制值」复制原始字符串。JSON 自动格式化预览，Cookie 保留域名、路径等属性；窄屏上下排列并独立滚动。存储只读，Cookie 按网站授权，内容仅保留在当前面板。

### Auto Tuck

把 7 天未使用的标签页自动放进折叠的「已收起」组，让标签栏留给正在做的事。页面保持打开，随时搜索或点击找回一页。默认关闭，也可手动收起、撤销收起。

## 交互原则

**Human first**：人可以用熟悉的快捷键，也可以用鼠标，并随时在两者之间切换。使用 zing 不应以记住快捷键为前提。

- **操作找得到**：常用操作有清楚、可点击的入口，更多操作集中在「操作」菜单；快捷键在对应入口旁提示。
- **同一操作，同一逻辑**：点击与快捷键使用相同的操作、状态和返回路径，切换输入方式不丢失当前上下文。
- **反馈及时，返回自然**：执行、等待、成功和失败都有明确反馈；返回上一层保留搜索、选中项和编辑位置，文本编辑遵循熟悉的习惯。

这些原则是后续设计与验收的标准。

## 安装

需要 Node.js / npm 和 Chrome 127+。

```sh
npm ci
npm run build
```

1. 打开 `chrome://extensions`，开启「开发者模式」。
2. 选择「加载已解压的扩展程序」，加载本项目生成的 **dist/** 目录。
3. 点击工具栏的 zing 图标，或按 **Cmd+Shift+P**（Windows/Linux 为 **Ctrl+Shift+P**）。

`dist/` 不纳入 Git，首次克隆后需要构建。快捷键冲突时，在 `chrome://extensions/shortcuts` 中修改；也可搜索「快捷键」进入设置。

## 开始使用

输入中文或英文关键词即可统一搜索，无需模式前缀。例如页面标题、网站域名、`new tab`、`settings`，也可按日常说法检索（如 `refresh page / 刷新页面`、`reopen last tab / 恢复标签`、`dark mode / 深色`、`打开书签`），或组合标题、域名、标签组与书签目录（如 `github pull`、`notion 路线`、`前端 react`，词序不限）。

无需输入完整命令名称：`clo` 可找到关闭标签页，`clo oth` 找关闭其他，`tab clo ri` 找关闭右侧（「关闭」和 `guan` 同样可用；`cl`、`cloud` 或单独 `tab` 不会误触关闭操作）。静音与固定命令会根据目标标签页当前状态过滤反向别名。搜索排序优先保证相关性，本机使用习惯仅在同一搜索词、同一相关性等级内微调。首页只有一组「推荐 / Suggested」，混排页面与命令，最多 10 项。无使用习惯时默认依次为 **Zing: 设置**、**Zing: 使用帮助**、**Zing: Tab Switcher**、脚本收藏、搜索全部历史、新建标签页、刷新当前页、固定／取消固定、Local Storage、Cookies；有相应状态时还可显示撤销收起或恢复收起组入口。页面须有通过 zing 成功选择的记录才参与推荐，不以最近访问补位；排除当前完整 URL，同 URL 仅留一项并优先当前窗口已打开的标签页。首页跨搜索词汇总频次与衰减权重，仅在这里合并同 URL 的标签页／历史与书签偏好；权重每 14 天减半，90 天未使用失效，记录最多 500 条。静音／取消静音、恢复关闭的标签页和查看 Session Storage 仅在搜索时显示，即使有使用记录也不进入首页。具体设置项使用「设置: 主题」「设置: 语言」等名称，执行后打开并定位对应控件。

首页推荐分数在打开面板／来源会话开始时固定；输入查询、返回子页或新增学习均不重排首页，下次打开才更新，页面移除等真实数据变化仍会更新列表。首页 `Cmd/Ctrl+↑/↓` 跳到首尾；打开后直接 Enter 执行第一条推荐，不保证切回上一标签页。无痕首页仅显示默认入口并隐藏「搜索全部历史」，不使用普通窗口习惯；首页不预加载历史或增加权限。

主搜索与「搜索全部历史」子页中，有学习记录的结果右侧、快捷键键帽左侧显示历史小图标。悬停或聚焦时，用一句短文说明排序原因，并显示「忘记此搜索词的偏好」、首页的「忘记此命令的偏好」或「忘记此页面的偏好」；图标变为 X，点击即可忘记。键盘选中行后，可按 `Tab` 聚焦图标，再按 `Enter` / `Space` 忘记，也可直接按 `Shift+Backspace` 忘记当前选中项的记录。

有搜索词时，只清除此结果在当前归一化搜索词下的偏好（忽略大小写、首尾空格并合并连续空白）；首页命令清除该命令的所有查询记录，首页页面则一次性清除完整 URL 与同 URL 已学习书签在所有查询下的记录，均含空查询。删除成功后图标消失，顺序、选中项和滚动位置保留；搜索修改查询后重新排序，首页保持到下次打开。其他已打开面板同步更新记录与对应图标，页面关闭等真实数据变化仍正常刷新。忘记不会删除页面或书签，也不是隐藏或「不再推荐」，之后选择仍可重新学习；本面板「设置 → 实验性功能 → 搜索排序」的全部重置立即恢复默认排序及首页入口。

学习范围为普通标签页、浏览历史、书签、浏览器命令、设置与页面存储入口；脚本、帮助、标签组导航、Tab Switcher 入口和扩展重载不参与学习。首页直接选择页面并成功打开也会学习；切换器切换不记录。查询搜索中，历史与相同完整 URL 的标签页共用偏好，书签仍独立记录，忘记当前词偏好的范围不变。记录仅存本机，无痕窗口不记录选择。

| 操作 | 鼠标入口 | macOS 快捷键 |
| --- | --- | --- |
| 执行搜索结果 | 点击结果或底栏主操作 | `↑` / `↓` 或 `Ctrl+P` / `Ctrl+N` 选择，`Enter` 执行 |
| 当前候选项的更多操作 | 右键候选项，或点击底栏「操作」 | `Cmd+K` |
| 打开设置 | 底栏设置齿轮 | `Cmd+,` |
| 返回上一层 | 点击底栏返回箭头或搜索框尾部 `esc` | `Esc`（二级页空搜索框也可用 `Backspace`） |
| 关闭主面板 | 搜索框尾部 `esc` | `Esc` |

右键点击工具栏的 zing 图标，可查看当前实际绑定并前往修改快捷键，或在新标签页打开内置「使用帮助」（也可从「设置 → 通用 → 使用帮助」或主搜索 `help / 帮助 / 使用说明` 在面板内打开）。

**Tab Switcher** 支持 VSCode 风格的 Ctrl+Tab 切换，从「设置 → 键盘 → Tab Switcher」点击「复制并打开」，即可复制已填入扩展 ID 的一行命令并打开 Chrome 快捷键页；在该页 Console 粘贴并回车，一次配置正反向快捷键（不是终端命令）。Zing 配置说明支持多次切走、切回查看，退出说明后才恢复普通浮层的自动关闭行为；会失焦关闭的弹窗改由说明标签页承接。切换最近标签页时，按住 `Control+J`（Windows/Linux 为 `Ctrl+,`，或使用已配置的 `Ctrl+Tab`），用 `N` / `P` 或方向键选择，松开修饰键即可切换；若点击切换器搜索框或按 `Cmd/Ctrl+F` 进入筛选，则暂停松键切换，可松开按键正常输入标题或网址，再按 `Enter` 或点击结果确认。

最近标签页切换在 macOS 默认使用 `Control+J`，Windows/Linux 使用 `Ctrl+,`；反向切换均加 `Shift`。其他操作在 Windows/Linux 使用 `Ctrl` 代替 `Command`。更多用法与平台差异见[使用指南](docs/USAGE.md)。

## 使用边界与数据

普通网页显示按页面视口水平居中、偏上的浮层，最大 750×516px，小视口按可用空间缩小。Chrome 内置页的命令面板，以及最近标签切换无法使用网页浮层时，使用独立窗口，按来源内容区与缩放比例估算位置，内容缩放跟随来源页，并在显示界面前通过 Chrome API 返回的窗口与标签页尺寸校准自身原生边框；系统标题栏仍保留。

独立窗口使用 Chrome 返回的来源标签页内容尺寸和浏览器外框尺寸（DIP），按水平对称、底边对齐估算内容区，再结合来源页缩放计算位置和尺寸。来源内容区的屏幕原点无法直接测量，垂直标签栏、停靠 DevTools 和系统边框可能造成偏差，不能保证像素级对齐。

命令面板在普通网页地址栏持有焦点、Web Store 等其他受限场景仍使用工具栏弹窗，其位置由 Chrome 控制。最近标签切换在地址栏等未监听区域快速点按时可能需要 Enter 确认。

偏好、保存的脚本及搜索使用记录只存本机；页面存储值和脚本结果仅保留在当前面板。

「自动收起标签页 / Auto Tuck Tabs」位于「设置 → 实验性功能」，默认关闭；开启后自动收起符合条件且 7 天未使用的标签页。收起不会关闭或主动卸载页面。重启浏览器或重新加载扩展后，zing 会根据本机保存的记录恢复管理；无法唯一确认时，搜索「恢复收起组」，在成员详情卡片中核对页面，点击卡片仅选择候选组，再从底栏或操作菜单选择「继续管理这组」明确确认。待确认期间避免重复建组。记录只在本机保存，不记录无痕页面。详见 [收起标签页](docs/USAGE.md#收起标签页)。

其他功能、权限与限制，以及 Ctrl+Tab 手动配置见 [使用指南](docs/USAGE.md)。

```sh
npm run check                     # 类型检查、单元测试、构建、端到端测试
```

日常按[测试指南的分层矩阵](docs/TESTING.md#按影响范围验证)选择类型检查、模块单测和少量相关浏览器用例；纯布局调整不默认运行完整单测。`npm run test:e2e -- --grep '<用例筛选>' --list` 仅选例，不构建或启动浏览器；去掉 `--list` 才构建并执行。每轮保存独立产物、阶段耗时与 `validation.json`。`npm run check` 运行完整套件，当前定位矩阵仍有未解决项。`ZING_CHROMIUM_PATH` 可指定 Chrome for Testing 可执行文件；Vimium 兼容用例仅在提供 `ZING_VIMIUM_PATH` 且确认扩展加载后执行，缺少路径时明确跳过。运行方式与验收边界见[测试指南](docs/TESTING.md)。

构建后打开 zing，搜索 `Zing: Reload`、`reload zing` 或「重新加载扩展」，点击「Zing: 重新加载」或按 Enter 即可加载本机已构建版本；zing 面板会关闭，网页和已保存设置保留，再次唤起即可使用。首次安装此功能仍需在 Chrome 扩展管理页手动重新加载一次；扩展无法启动时也可使用该入口。`public/` 的 manifest 或语言包改变后需重新运行构建。`dist/`、依赖和测试截图不提交到 Git。
