# 使用指南

[返回 README](../README.md) · [架构决策](adr/README.md)

本文描述当前操作。快捷键表以 macOS 为例，Windows/Linux 的 Command 操作用 Ctrl；最近标签切换器的差异单独说明。

## 搜索与导航

| 操作 | 效果 |
| --- | --- |
| `Cmd+Shift+P` | 打开 / 关闭面板，输入框初始为空 |
| 直接输入关键词 | 同时搜索当前窗口所有标签页、全部书签和浏览器命令；支持中文、英文和常用拼音关键词 |
| `↑` / `↓` | 循环选择结果；也支持 `Ctrl+P` / `Ctrl+N` |
| `Option+↑` / `Option+↓`、`PageUp` / `PageDown` | 按可见列表高度翻页 |
| `Cmd+↑` / `Cmd+↓` | 空搜索时跳转最近标签页 / 常用命令分组；有关键词时跳到首尾 |
| `Enter` | 执行命令、切换标签页或在新标签页打开书签 |
| `Cmd+K` | 打开 / 关闭当前结果的操作菜单 |
| `Cmd+,` | 打开设置；也可点击左下角齿轮，或搜索 `设置` / `settings` |
| `Esc` | 退出最上层菜单或页面，回到上一层；仅在主搜索层关闭面板 |
| `Backspace` | 空搜索框或非编辑控件返回上一层；有文字时先删字，主搜索层不关闭 |
| 点击面板外 | 关闭操作菜单或主面板 |

命令包括：新建、刷新、关闭当前 / 其他 / 右侧标签页、恢复最近关闭的标签页或窗口、固定 / 取消固定、静音 / 取消静音，以及 Local Storage、Session Storage 和 Cookies 的查看与复制。

空输入展示最多 6 个最近使用的标签页，再列出常用命令。标签页按 Chrome 提供的最近激活时间排序，当前页面放在其他标签页之后，方便直接回车切回上一页。命令结合使用频率和最近使用时间排序，汇总搜索结果、首页和 Cmd+K 中成功执行的记录；已有记录直接生效，没有记录的命令保留默认顺序。关闭类命令仍通过明确搜索或 Cmd+K 进入。书签和其他标签页可直接输入搜索。

同一个搜索词下，成功选择过的结果会结合使用频率和最近使用时间前移；大小写和多余空格视为同一查询。精确命令、完整标题仍优先，模糊命中不会超过字面命中，也不会让无关结果重新出现。习惯记录只保存在本机，标签页按网址识别，关闭重开后仍有效。仅移动选中项、取消和执行失败不计入；空搜索切换标签页和无痕窗口不记录。Cmd+K 的次要操作（如静音目标标签页）计入命令使用习惯，不影响该网页在主搜索中的偏好。设置 → 搜索排序中的重置会同时清除首页命令和同词搜索的学习记录。

关闭类命令需要明确输入「关闭」、`close` 或 `guanbi`，也可在目标标签页的 Cmd+K 操作菜单中选择。没有模式按钮，`>` 作为普通搜索文字处理。

网站域名按名称参与排序，例如搜索 `sls` 能直接找到标题为中文的 `sls.console.aliyun.com` 标签页。同等相关且没有同词使用偏好时，优先固定标签页，其次是其他已打开的标签页，再到书签；更精确的标题仍优先，固定状态不会把无关页面推到前面。空搜索与 Tab Switcher 仍按最近使用顺序展示。

标题、网址及 Cmd+K 操作菜单会以淡色底纹高亮匹配文字，使用与搜索一致的匹配规则。跨语言命中命令时会显示匹配的内置别名，例如中文「新建标签页」旁显示高亮的 `new tab`。空搜索不显示高亮，浅色和深色主题均适配。

在标签页的操作菜单中，命令作用于**选中的标签页**，不需要先切换过去。批量关闭仅作用于当前窗口，并保留固定标签页；底部显示预计关闭数量。单独「关闭标签页」仍可关闭固定标签页。

所有功能入口都应能从主搜索找到。输入「语言 / language」「主题 / theme」「快捷键 / hotkey」「搜索排序 / search ranking」「自动收起 / auto tuck」并按 Enter，打开设置并直接聚焦对应控件，Esc 返回原搜索；搜索排序的重置仍需点击或按 Enter 确认执行。设置包含语言、主题、自动收起、搜索排序和打开面板的快捷键。语言默认跟随 Chrome 界面语言（通常与系统一致），也可固定选择「简体中文」或「English」；其他系统语言回退到英文，繁体中文环境暂时使用简体中文文案。主题支持「跟随系统 / 浅色 / 深色」。两项更改立即生效并保存到本机，也会同步到其他已打开的面板。不论界面语言是什么，命令和操作都可以用中英文关键词搜索。

快捷键显示 Chrome 当前实际绑定（未绑定时会明确提示），默认 `Cmd+Shift+P`。点击「前往修改」打开 Chrome 扩展快捷键页，在 zing 下录入新组合；再次打开面板会读取新绑定。标准扩展 API 不提供自行修改绑定的能力；Ctrl+Tab 的手动配置见下文。设置中 `Tab` 移动焦点，方向键和 Enter 选择选项，`Esc` 逐级关闭下拉菜单、返回搜索、关闭面板；返回搜索保留关键词、选中项和光标。

手动语言设置用于 zing 面板；Chrome 扩展管理页里的名称和描述仍由 Chrome 自身语言决定。

普通网页使用按页面视口水平居中、偏上的浮层，最大 750×516px；通常左右各留 24px、底部留 24px，顶部为视口高度的 16%（最少 28px、最多 150px）。视口宽度不超过 520px 时，左右各留 10px、顶部留 24px；可用高度不足时缩小面板。Chrome 内部页面使用独立小窗口，按来源内容区及缩放比例估算位置和尺寸，内容缩放同步跟随来源页；界面显示前用 Chrome API 返回的 popup 外框与标签页内容尺寸之差校准自身边框，系统标题栏仍保留。

独立窗口使用 Chrome 返回的来源标签页内容尺寸和浏览器外框尺寸（DIP），按水平对称、底边对齐估算内容区，再结合来源页缩放计算位置和尺寸。来源内容区的屏幕原点无法直接测量，垂直标签栏、停靠 DevTools 和系统边框可能造成偏差，不保证像素级对齐。

搜索和操作仍针对原页面；主搜索层按 Esc、再次按启动快捷键或切换到其他窗口会关闭。普通网页地址栏焦点兜底、Chrome Web Store 等其他不允许注入的页面仍使用工具栏扩展弹窗，其位置由 Chrome 控制。PDF 查看器的表现受 Chrome 注入限制影响。文件页未允许文件访问时同样走备用弹窗。

主搜索和列表型二级页共用面板尺寸、底栏和搜索框位置：常规面板总高 516px、底栏 44px、列表行 40px，切换时底边不跳动；Storage 的名称和值预览并排显示，长值可从「操作 → 查看详情」展开。二级页没有单独的标题栏。底栏左侧统一为「26px 单色图标按钮 + 当前位置名称 + `·` 补充信息」：主搜索是「设置齿轮 + zing + 导航提示」，Storage 是「返回箭头 + Local Storage 等类型名称 + 站点来源」，标签组是「返回箭头 + 组名 + 成员数量」。名称均用 11.5px、500 字重的弱化文字，保持只读，旁边不再叠加品牌装饰、类型图标或组色图标；右侧仍是主操作、操作菜单和快捷键。

点击返回箭头与 Esc 逐层返回语义一致，在空搜索框按退格也可返回；每次只退出最深的一层：先关闭操作菜单，再退出编辑层，最后返回主搜索，并恢复搜索词、选中项和光标。主搜索与 Tab Switcher 共用「选择 / Navigate」和 `↑ Ctrl P` / `↓ Ctrl N` 导航提示，均在补充信息位置显示，与站点来源、成员数量使用相同的 11px 弱化辅助文字，导航按键无键帽框；右侧主操作与「操作」的键帽仍保留边框和背景。短暂状态反馈占用同一位置，出现时替换原有信息。宽度不超过 520px 时仅隐藏补充信息，包括主搜索与 Tab Switcher 的导航提示；复制成功、执行中或危险操作等状态反馈仍在同一位置显示，必要时截断。图标按钮、当前位置名称和右侧操作始终保留，长名称先于操作控件截断，按钮不收缩。

书签按名称、URL、文件夹搜索；脚本书签（`javascript:`）不执行。恢复操作使用 Chrome 最近关闭记录，可能恢复原窗口中的标签页或整个窗口。搜索最多显示 100 条结果，继续输入可缩小范围。

## 脚本收藏与 Ctrl+Tab 配置

设置 → 键盘 →「设置 Ctrl+Tab」提供内置绑定代码，自动使用当前安装的扩展 ID。先复制代码，再打开 Chrome 快捷键页，按页面说明在该页的 DevTools Console 中执行。该入口绑定 Ctrl+Tab / Ctrl+Shift+Tab；Chrome 内部接口不能从扩展设置页直接调用。

主搜索输入「新建脚本 / new script」直接创建；输入「脚本 / scripts / 管理脚本」打开脚本收藏。设置中的「管理脚本」保留为额外入口。命令面板支持按名称搜索脚本，Enter 在当前网页运行一次并显示结果。Cmd+K（Windows/Linux 为 Ctrl+K）打开操作菜单，可选择运行、运行并复制结果、复制代码、编辑或删除；支持搜索动作和 Ctrl+N/P 导航。也可以搜索「运行脚本 / run script」或「运行并复制结果 / run and copy result」，再选择已保存的脚本。编辑页沿用主面板的共用底栏：Cmd+Enter（Windows/Linux 为 Ctrl+Enter）保存，Cmd+K 打开复制、保存或删除操作；普通 Enter 在代码框中换行。编辑保存或 Esc 返回原搜索，保留搜索词、选中项与光标。删除先确认，默认聚焦取消；内置 Ctrl+Tab 脚本仅提供复制和查看设置说明。脚本仅保存于本机，仅在手动选择运行时执行；代码正文不参与搜索或使用习惯记录。内置 Ctrl+Tab 配置也可以直接搜索「ctrl tab」找到。

脚本执行需要 Chrome 135+。Chrome 138+ 首次使用时，按提示打开 zing 的扩展详情并开启「允许用户脚本」；Chrome 135–137 使用开发者模式。普通 HTTP(S) 网页通过已有 activeTab 临时授权运行，不申请全站主机权限。Chrome 内置页和内置 Ctrl+Tab 配置代码仍需手动执行。

例如保存名为「复制 token」的脚本：

```js
localStorage.getItem("token")
```

在目标网站打开 zing，搜索脚本名并按 Enter 查看结果，或 Cmd+K 选择「运行并复制结果」。代码最后一个表达式作为结果，Promise 会等待完成；异步多步逻辑可使用 async 函数立即调用。字符串原样保留，对象显示为格式化 JSON。结果仅在本次面板内显示、不保存。成功后底栏主操作为「复制结果」，失败后为「重新运行」；Cmd+K 可选择复制或重新运行，底栏随菜单选中项变化。执行期间禁用操作；复制失败保留结果，可重试。结果文本仍可选中复制，关闭菜单恢复焦点和选区。Esc 逐层返回，退出等待中的脚本后不再自动复制，但已开始的脚本可能继续执行。

脚本运行在 Chrome 的隔离用户脚本环境，可访问当前顶层页面的 DOM、Local Storage 和 Session Storage；不提供网页自身的 JavaScript 变量、扩展 API 或油猴的 GM_* API。zing 不上传代码或结果；脚本本身可以修改页面或发起网络请求，具体行为取决于保存的代码。

## 最近标签页切换

遵循 VS Code Ctrl+Tab 的“选择后确认”交互。macOS 默认按 **Control+J**（已设置 Ctrl+Tab 时使用该绑定）打开切换器，默认高亮上一个标签页，页面暂不切换。保持 Control，使用 **N/P**、↑/↓ 或重复快捷键移动高亮；反向快捷键反向选择。未进入下述搜索状态时，**松开 Control 切换到选中页并关闭切换器**；普通 Enter 或点击候选项同样确认。Esc、失焦或起始页被关闭/移走均取消，选择期间不激活候选标签页。

网页浮层与独立窗口使用和主搜索相同的搜索胶囊、列表及标题／网址布局。打开时输入为空且禁用，焦点在候选列表，显示「搜索最近标签页…」（英文为「Search recent tabs…」），不显示编辑光标或焦点蓝框。点击搜索图标、输入区域或按 Cmd+F（Windows/Linux 为 Ctrl+F）进入搜索，暂停松键确认；此时可松开启动修饰键正常输入，用普通 Enter、点击候选项或底栏「切换」确认。未进入搜索时仍按松键确认。输入标题或网址即可筛选本次会话中当前窗口的候选项，不区分大小写，空白分隔的每个词都须命中标题或网址，匹配文字高亮，结果保持最近使用顺序。修改搜索词时保留仍可见的选中页，否则选择首项；无匹配时不能确认切换。候选页被关闭或移出窗口时会移除；若它是选中项，则仅在源页仍可见时回到源页，否则暂不选择，直到再次导航、点击或修改搜索词。

默认列表或启用后的输入框持有焦点时，↑/↓、Ctrl+P/N、Tab / Shift+Tab 循环选择，PageUp/PageDown 或 Option（Alt）+↑/↓ 按页移动，Ctrl/Cmd+↑/↓ 跳到首尾。独立窗口加载期间的导航会按原顺序保留，列表就绪后应用；搜索已启用时再次点击搜索图标或按 Ctrl/Cmd+F 可恢复输入焦点。Esc 经统一返回路由取消，加载期间也可使用。普通 Enter 确认当前选择；未进入搜索时也可松开启动修饰键确认。所有带修饰键、长按重复或输入法组合期间的 Enter 均不执行。

普通 HTTP(S) 网页预加载轻量修饰键监听，快速点按可直接切到上一页，无需 Enter；按住时显示与 Command Palette 同位置、同尺寸的网页浮层。独立窗口定位会换算来源页的缩放比例，内容缩放同步跟随，并以 Chrome 返回的窗口与标签页尺寸校准自身边框；系统标题栏仍保留。加载期间的松键会被缓冲。扩展更新前已打开的网页需刷新一次才能启用监听。无法聚焦网页、Chrome 内置页、Web Store 等受限页面仍使用独立窗口兜底，极短点按可能需要 Enter；不以定时器猜测松键。原来的 Cmd+Shift+P 保持不变。Windows/Linux 默认 Ctrl+, 与 Ctrl+Shift+,，尚未做对应系统原生输入验收。详见 [切换器说明](RECENT-TABS.md)。

Tab Switcher 的网页浮层与独立窗口共用 44px 底栏：左侧在快速切换时显示「松开 Ctrl 切换」，进入搜索后显示「切换最近标签页」，后接与主搜索完全相同的「选择 ↑ Ctrl P ↓ Ctrl N」（英文为「Navigate ↑ Ctrl P ↓ Ctrl N」）；悬停导航提示可查看方向键、Ctrl+P/N 与点击选择的说明，实际启动快捷键可在搜索栏的悬浮提示中查看。右侧「切换 ↵」「取消 esc」均可点击，文字在前、键帽在后；搜索栏右侧也有取消按钮。窄屏隐藏导航提示，保留松键提示或搜索状态标题与操作按钮。网页浮层填满面板可用空间，底栏下不另放帮助行。

## 收起标签页

「收起」把标签页移入当前窗口末尾的 Chrome 折叠组，例如「已收起 · 3」。页面仍然打开，zing 不会关闭、重新加载或主动卸载（discard）它们；Chrome 自身的内存节省机制仍按浏览器设置运行。

自动收起默认关闭。在设置 → 标签页中开启「自动收起闲置标签页」，也可搜索「自动收起 / auto tuck」直接到达开关。点击开关或文字标签可以切换；键盘聚焦后按 Space 或 Enter 也可操作。功能没有新增专用快捷键，沿用主搜索、底栏和 Cmd+K。

开启后，zing 在电脑暂时空闲时检查 **7 天未使用**的标签页。首次开启从当下开始计时，不把不确定的旧历史视为已经闲置；重新开启也重新计时。自动收起跳过当前页、固定页、已有分组、正在播放声音或加载的页面、多选页、分屏页和无痕窗口。不会接管你自己创建的分组，也不会按到期时间强行打断操作。

| 操作 | 入口与效果 |
| --- | --- |
| 手动收起当前页 | 搜索「收起标签页 / tuck tab」，点击结果或按 Enter；切到另一个已有标签页后收起当前页 |
| 手动收起其他页 | 搜索选中该页，点击底栏「操作」或按 Cmd+K，再选择「收起标签页」；无需先切过去 |
| 找回一页 | 搜索标题或网址，照常点击或 Enter 切换；也可展开 Chrome 的「已收起」组后点击该页。只将选中的一页移出组，其他页继续收起 |
| 用 Tab Switcher 找回 | 已收起页仍在最近标签列表中；确认切换才移出组，移动高亮或取消不会改变分组 |
| 撤销收起 | 搜索「撤销收起 / undo tuck」，或从空搜索中的命令进入，点击或 Enter 执行；仅撤销当前窗口最近一批仍由 zing 管理的标签页 |
| 停止自动收起 | 关闭设置开关；停止自动检查，并把当前仍由 zing 管理的组移回普通标签栏，保持当前相对顺序 |

手动收起在自动功能关闭时也可用。固定页和已有分组不提供收起操作；若当前页没有其他可切换的标签页，操作会显示原因。搜索中的已收起页保留原始标题、网站图标，右侧显示「已收起」。找回的页放在收起组之前，其他普通标签页不重排。找回或撤销会重新开始 7 天计时。

撤销不恢复已经关闭的页面，不从你后来移走或重新分组的位置抢回标签页，也不还原整个窗口的旧排序。你为组改名、改颜色或向组内添加页面后，该组交由你管理，zing 不再自动调整它。

**浏览器重启与扩展重新加载**：zing 在本机保留分组恢复记录，不依赖旧的组编号。组名、灰色、完整成员网址（含重复数量）及窗口其他网页都唯一匹配时，自动恢复管理。浏览器尚未恢复窗口时保留记录，后续恢复事件或再次打开面板会重新检查。撤销批次仍仅在本次会话内有效，不跨重启恢复。

信息不完整、成员变化或存在重复组时，搜索「恢复收起组 / recover tucked tabs」，核对当前窗口候选组中的具体页面，再点击底栏「继续管理这组」或从 Cmd+K 执行。确认后恢复灰色「已收起」名称及管理，当前活动页移回普通标签栏，其余页面折叠。Esc / Backspace 返回上一层，不作更改。旧版本没有持久记录的灰色「已收起」组也需要先确认。

尚未找到原窗口或不想继续管理时，可以稍后再决定，也可以从 Cmd+K 选择「停止恢复这条记录」；后者只删除恢复记录，不改变任何标签页或原生分组。待确认期间，zing 不会在未受管的窗口新建收起组，也不会向有待确认候选组的窗口继续收起，避免重复。关闭自动开关会展开已经确认归属的组；待确认组保持原状，需要先确认归属才能管理。

本机保存两类记录：开启自动收起时保存当前开放页面的网址和最近使用时间，关闭自动功能会清空这份计时记录；分组恢复记录保存组名、成员网址及窗口其他网页网址，直到已管理的组解除、用户改组或主动停止恢复。关闭窗口但可能恢复的记录会保留。相同网址的闲置计时取最近一次，避免过早收起。不保存页面正文或表单值，不上传，不记录无痕页面。权限为 `tabGroups`（操作原生标签组）、`alarms`（定期检查）和 `idle`（避开正在使用电脑的时刻）；无需新增网站访问权限。

## 页面存储

搜索 `local storage`、`session storage`、`cookie`（也支持「本地存储」「会话存储」），Enter 打开当前页面的存储列表。输入名称筛选，↑/↓ 或 Ctrl+P/N 选择，单击或按 Enter 复制原始值；双击或按 Cmd+K（以及右键候选项）提供复制名称、查看详情和刷新。详情中的 JSON 自动格式化，复制仍保留原始字符串；Ctrl+P/N 或方向键滚动长内容。Esc、空搜索框退格或点击底栏左侧的返回箭头逐层返回，并恢复原来的搜索、选择和焦点；底栏左侧依次是单色返回按钮、存储类型名称和 `·` 分隔的当前站点来源。

Local/Session Storage 读取当前标签页的顶层页面；Cookie 列出与当前页面 URL 匹配的记录，包括 HttpOnly，并显示域名、路径、有效期与分区信息。Chrome 132+ 额外读取当前顶层页面对应的分区 Cookie；较旧版本读取普通 Cookie。页面导航后需重新打开 zing。Chrome 内部页等非 HTTP(S) 页面会显示说明。

Local/Session Storage 使用已有 `activeTab` 临时授权。Cookie 首次使用时点击「允许访问此网站」，在授权页确认域名后由 Chrome 请求网站权限；授权后自动返回列表。同一网站后续无需重复授权，可在 Chrome 的扩展设置中撤销。为完整读取普通和父域 Cookie，授权范围包含当前主机和必要的父域（HTTP/HTTPS），不含其他子域或所有网站。存储内容只在当前面板内存中显示，不写入扩展存储或日志，不上传；仅成功打开存储命令计入排序，条目名称、值、列表搜索和刷新不计入。该版本仅支持查看与复制。

可用 `node tests/storage-manual.mjs` 启动临时本地验收页，终端会输出 URL；页面含可复制的 Local/Session 测试值和 HttpOnly Cookie。

### Tab Group 搜索与管理

输入标签组名称即可找到该组及成员标签页。选择 `Tab Group: 名称`（中文「标签组」）进入管理页；组内可继续搜索，点击或 Enter 切换标签页，Ctrl+N/P 或方向键选择。

底部「操作」、右键候选项或 Cmd+K 提供关闭所选标签页、移出组、展开/折叠组、重命名和换色（支持中英文关键词检索操作）。编辑页通过底栏保存，Esc、空搜索框退格或点击底栏左侧的返回箭头返回上一层；底栏左侧统一为单色返回按钮、组名和 `·` 分隔的成员数量，组名旁不再显示组色图标。Tucked Away 使用同一管理页，在 zing 内改名和换色会保留自动管理关系。关闭或移出最后一个成员后，Chrome 会移除空组，zing 提示组已不可用。


鼠标操作：Command Palette、标签组管理页、页面存储列表与收起恢复页中右键候选项均可直接打开该项的操作菜单，Esc 返回后可以继续输入。Tab Switcher 可以点击某个标签直接切换，也可以点击底部「切换」或「取消」；仅把鼠标移到候选项上不会改变松开 Ctrl 时的切换目标。
