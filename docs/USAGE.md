# 使用指南

[返回 README](../README.md) · [架构决策](adr/README.md)

本文说明 zing 的当前操作。快捷键以 macOS 为例。Windows/Linux 使用 Ctrl 代替 Command；Option 对应 Alt。最近标签页切换的系统差异见[最近标签页切换](#最近标签页切换)。

本文中的「主搜索」指 zing 面板的主搜索页。「来源页」指打开面板时的网页。「承载页」指显示 zing 网页浮层或工具栏弹窗所依附的标签页。

## 使用帮助

**打开帮助**

1. 在主搜索中输入 `help`、「帮助」或「使用说明」。
2. 按 Enter。

也可从设置 → 通用的最后一项「使用帮助」进入。这两种入口在面板内打开帮助。

要在独立标签页阅读，右键点击工具栏的 zing 图标，再点击「使用帮助」。每次点击都会在调用菜单的窗口中新建帮助标签页，不复用已有帮助页。

**结果**

帮助打开后，焦点位于顶部「搜索帮助」。正文包含打开与搜索、更多操作与返回、标签管理、脚本、网站存储及常见问题。两种入口使用同一份内置帮助，并跟随已保存的主题和语言偏好。帮助随扩展打包，无需联网或网站访问权限。

**筛选与阅读**

1. 在「搜索帮助」中输入关键词。
2. 连续按 Tab，直到正文获得焦点。
3. 用方向键或 PageUp / PageDown 滚动正文。

搜索匹配章节标题和正文，支持中英文，不区分大小写。用空格分开的每个词都必须匹配。帮助保留命中章节的全文，并高亮可见的匹配文字。空输入显示全部章节。没有结果时，可点击清空按钮重试。清空按钮只清除查询。

**退出帮助**

在面板内，点击底栏返回按钮、点击搜索框尾部 `esc` 或按 Esc，均返回上一层。返回设置时，zing 恢复设置筛选和帮助入口的焦点。返回主搜索时，zing 恢复关键词、选中项和光标。

在独立帮助页，底栏提供「关闭帮助」（英文为 Close Help）。点击此按钮、点击搜索框尾部 `esc` 或按 Esc，都会关闭帮助标签页。

Tab 可到达底栏按钮。搜索框有文字时，Backspace 删除文字；搜索框为空时，Backspace 在面板内返回上一层，在独立帮助页关闭标签页。

**工具栏菜单与启动快捷键**

右键点击工具栏的 zing 图标。zing 只在扩展图标菜单中添加以下两项，不向网页右键菜单添加入口：

| 菜单项 | 点击后的结果 |
| --- | --- |
| 打开 zing：实际快捷键 · 修改快捷键 | 打开 `chrome://extensions/shortcuts`；当前窗口已有相同地址时切换过去，否则新建标签页 |
| 使用帮助 | 在当前窗口新建内置帮助标签页 |

菜单文字跟随 zing 界面语言，外观和分组由 Chrome 决定。工具栏菜单仅新增 `contextMenus` 权限，不新增网站访问权限。主搜索不再常驻显示启动快捷键提示。

快捷键项显示 Chrome 的实际绑定。默认绑定为 macOS 的 Cmd+Shift+P，以及 Windows/Linux 的 Ctrl+Shift+P。帮助的「打开与搜索」也显示实际绑定，并展开按键名称；未绑定时明确说明。

改键后若立即在同一标签页右键，菜单可能仍显示旧绑定。切换标签页或打开 zing，再重新打开菜单。Chrome 没有提供菜单打开或快捷键变更通知，zing 不轮询检查绑定。

## 搜索与导航

### 基本操作

| 操作 | 结果 |
| --- | --- |
| `Cmd+Shift+P` | 打开或关闭面板；打开时输入框为空 |
| 直接输入关键词 | 搜索当前窗口的所有标签页、全部书签和浏览器命令；支持中文、英文和常用拼音关键词 |
| `↑` / `↓` 或 `Ctrl+P` / `Ctrl+N` | 循环选择结果 |
| `Option+↑` / `Option+↓` 或 `PageUp` / `PageDown` | 按可见列表高度翻页 |
| `Cmd+↑` / `Cmd+↓` | 空搜索时跳转最近标签页或常用命令分组；有关键词时跳到首尾 |
| `Enter` | 执行命令、切换标签页或在新标签页打开书签 |
| `Cmd+K` | 打开或关闭当前结果的操作菜单 |
| `Cmd+,` | 打开设置 |
| `Esc` | 退出最上层菜单或页面；在主搜索层关闭面板 |
| `Backspace` | 搜索框为空或焦点位于非编辑控件时，返回上一层；有文字时删除文字；在主搜索层不关闭面板 |
| 点击面板外 | 关闭操作菜单或主面板 |

也可点击左下角齿轮，或搜索「设置 / settings」打开设置。

命令包括新建、刷新、关闭当前标签页、关闭其他标签页、关闭右侧标签页、恢复最近关闭的标签页或窗口、固定、取消固定、静音和取消静音。主搜索也可打开 Local Storage、Session Storage 和 Cookies 的查看与复制功能。

### 搜索词与排序

不必输入完整命令名称。下表列出搜索示例。

| 搜索词 | 结果 |
| --- | --- |
| `新标签页`、`新建页面`、`open tab` | 找到新建标签页命令 |
| `refresh page`、`刷新页面`、`重新加载页面` | 找到刷新命令 |
| `reopen last tab`、`恢复标签`、`重新打开` | 找到最近关闭内容；可能是标签页或窗口 |
| `dark mode`、`深色`、`浅色` | 打开主题设置 |
| `English`、`英文`、`中文` | 打开语言设置 |
| `清除排序`、`重置排序` | 定位搜索排序设置 |
| `open settings`、`打开设置` | 打开 zing 设置 |
| `browser settings`、`浏览器设置` | 打开 Chrome 设置 |
| `打开书签` | 打开 Chrome 书签管理器 |

主题、语言和搜索排序的检索只打开对应控件。检索不会直接更改设置或清除记录。

可组合页面标题、网站域名、标签组名称或书签目录。例如：

- `github pull`
- `notion 路线`
- `Research Budget`
- `前端 react`

每个词都必须命中，词序可以调换。命令别名不区分大小写。例如，`des not` 和 `not des` 都优先找到 `Design Notes`。

搜索按下列顺序判断相关性：精确命令、完整标题、名称前缀、各词的词首匹配、名称包含、辅助字段、有限英文错字匹配。

网站域名按名称参与排序。例如，搜索 `sls` 可找到标题为中文的 `sls.console.aliyun.com` 标签页。同等相关且没有同词使用偏好时，排序依次为固定标签页、其他已打开的标签页、书签。更精确的标题仍优先。固定状态不会把无关页面排到前面。

相关性和使用习惯相同时，能覆盖全部查询词的较短命令名称或别名优先。增加别名数量不会让间接命令越过直接操作。有限英文错字命中时，接近完整单词的命令优先于长名称中的局部命中。例如，`setings` 优先找到 zing 设置。

标题、网址和操作菜单使用相同的匹配规则，并以淡色底纹高亮匹配文字。跨语言命中命令时，结果显示匹配的内置别名。例如，中文「新建标签页」旁显示高亮的 `new tab`。空搜索不显示高亮。浅色和深色主题均支持高亮。

**空搜索**

空搜索最多显示 6 个标签页，然后显示常用命令。标签页按 Chrome 提供的最近激活时间排序。当前来源页排在其他标签页之后，便于直接按 Enter 切回上一页。如果来源页不在前 6 项中，zing 用它替换第 6 项。其余位置优先显示最近使用的其他标签页。

主搜索、标签组和 Tab Switcher 都用「当前」标记来源页。空搜索和 Tab Switcher 始终按最近使用顺序展示标签页。要查找书签或其他标签页，直接输入关键词。

常用命令按使用频率和最近使用时间排序。zing 汇总在搜索结果、首页和 Cmd+K 菜单中成功执行命令的记录。已有记录立即生效；没有记录的命令保留默认顺序。关闭类命令不出现在空搜索首页，须明确搜索或从操作菜单进入。

**本机使用习惯**

同一搜索词下，成功选择过的结果可在同一相关性等级内前移。zing 同时考虑使用频率和最近使用时间。大小写和多余空格视为同一查询。

使用习惯不能跨越相关性等级。例如，只在 URL 路径中命中的结果不能超过名称前缀命中的结果。无关结果不会因历史记录重新出现。

记录只保存在本机。标签页按网址识别，关闭后重新打开仍可沿用记录。以下操作不计入记录：

- 仅移动选中项。
- 取消操作或执行失败。
- 空搜索中的标签页切换。
- 无痕窗口中的操作。

Cmd+K 菜单中的次要操作，例如静音目标标签页，计入命令使用习惯。它不影响该网页在主搜索中的偏好。脚本代码正文不参与搜索或使用习惯记录。

要清除学习记录，在设置 → 实验性功能 → 搜索排序中执行重置。重置同时清除首页命令和同词搜索的学习记录。

**关闭、静音与固定命令**

关闭命令支持以下搜索：

| 搜索词 | 结果 |
| --- | --- |
| `clo`、`clos`、`close`、`关闭`、`guan` | 显示关闭类命令 |
| `clo oth` | 找到关闭其他标签页 |
| `tab clo ri` | 找到关闭右侧标签页 |
| 完整的 `close` 或 `关闭` | 默认优先关闭当前标签页 |

`cl`、`cloud`、`closed`、单独的 `tab` 以及关闭动作的拼写错误，不会带出关闭命令。界面语言不影响这些规则。主搜索和目标标签页的操作菜单使用同一匹配规则。可通过右键、底栏「操作」或 Cmd+K 打开菜单。

zing 没有搜索模式按钮。`>` 是普通搜索文字。

静音和固定的别名随目标状态变化：

- 目标未静音时，搜索 `unmute / 取消静音 / 恢复声音` 不会推荐静音操作。
- 目标未固定时，搜索 `unpin / 取消固定` 不会推荐固定操作。
- 搜索 `sound / audio / jingyin / guding` 等功能词，仍可找到当前可用的切换动作。

操作菜单使用所选标签页的状态。主搜索使用当前来源页的状态。

**书签、恢复与结果数量**

书签可按名称、URL 和文件夹搜索。zing 不执行 `javascript:` 脚本书签。

恢复操作使用 Chrome 最近关闭记录。它可能恢复原窗口中的标签页，也可能恢复整个窗口。

搜索最多显示 100 条结果。继续输入可缩小范围。

### 整理标签页与继续操作

在标签页的操作菜单中，命令作用于**选中的标签页**。不必先切换到该页。

批量关闭只作用于当前窗口，并保留固定标签页。底栏显示预计关闭数量。单独执行「关闭标签页」仍可关闭固定标签页。

**执行后的面板状态**

| 操作 | 结果 |
| --- | --- |
| 关闭、关闭其他或右侧标签页 | 保留 zing；关闭承载页时按下文继续会话 |
| 固定、取消固定、静音、取消静音、移出组、编辑组 | 保留 zing |
| 刷新其他标签页、收起其他标签页、撤销收起 | 保留 zing |
| 切换标签页、打开书签、新建标签页、打开 Chrome 内置页面、恢复关闭内容 | 成功后退出 zing |
| 刷新或收起当前承载页 | 退出 zing |

保留面板时，zing 关闭操作菜单，并将焦点移回搜索框。搜索词和输入光标不变。原选中项仍存在时，zing 保留该项。原选中项消失时，zing 选择原列表中下一个仍存在的结果；没有下一项时，选择上一项。没有匹配时，列表保持为空。此时仍可继续输入或按 Esc 退出。

**关闭承载页后的会话接续**

通过 zing 关闭当前承载页后，如果来源浏览器窗口仍有标签页，zing 会继续会话。对其他页执行批量关闭并删除了承载页时，也使用此规则。

网页浮层或工具栏弹窗会转为带系统标题栏的独立面板。已有独立面板会更新来源页。主搜索和标签组子页保留搜索词与光标，但清空选择。

要继续执行操作，先按方向键、修改搜索词或明确点击结果。直接再次按 Enter 不会关闭接替的页面。

接续仅使用现有权限，不向新网页请求注入权限。以下情况不自动重开面板：

- 关闭最后一个标签页或来源窗口。
- 在接续期间切换到其他窗口。
- 在 zing 外关闭来源页。

执行期间主动退出 zing 会取消后续接续。已经请求的关闭操作仍会完成。

### 设置

所有功能入口均可从主搜索查找。要直接到达设置控件：

1. 输入「语言 / language」「主题 / theme」「快捷键 / hotkey」「搜索排序 / search ranking」或「自动收起 / auto tuck」。
2. 按 Enter。

**结果**

设置打开后，焦点直接位于对应控件。按 Esc 返回原搜索。搜索排序的重置仍须点击或按 Enter 执行。

普通打开设置时，焦点位于顶部「搜索设置」。返回按钮和「设置」名称位于底栏左侧。

**筛选设置**

在「搜索设置」中输入关键词。筛选匹配设置名称、说明和中英文关键词。按空白分开的每个词都必须匹配。设置按独立行筛选，并高亮可见的匹配文字。空分区隐藏。空输入显示全部设置。没有结果时，可点击清空按钮。

Tab / Shift+Tab 只遍历可见控件。在搜索框中按 Enter 不会切换开关或重置排序。搜索框有文字时，Backspace 删除文字；搜索框为空时，Backspace 返回上一层。从脚本管理返回设置时，zing 保留筛选，并恢复入口焦点。

设置包含三个分区：

| 分区 | 内容 |
| --- | --- |
| 通用 | 语言、主题、使用帮助 |
| 键盘 | 面板快捷键、切换最近标签页 |
| 实验性功能 | 自动收起、搜索排序、脚本收藏 |

语言与主题上下排列，选择框位于右侧。说明可换行，窄屏控件仍靠右。没有点击动作的设置名称使用普通指针。右侧控件和关联开关的文字标签使用手形指针。

**语言与主题**

语言默认跟随 Chrome 界面语言，通常与系统语言一致。也可固定选择「简体中文」或「English」。其他系统语言回退到英文。繁体中文环境暂时使用简体中文文案。

主题支持「跟随系统 / 浅色 / 深色」。语言和主题更改立即生效，并保存到本机。其他已打开的 zing 面板也会同步更改。不论界面语言是什么，命令和操作都支持中英文关键词搜索。

手动语言设置用于 zing 面板、独立帮助页和工具栏菜单中的 zing 项。Chrome 扩展管理页中的名称和描述仍由 Chrome 自身语言决定。

**修改面板快捷键**

1. 在设置 → 键盘中点击「前往修改」。
2. 在 Chrome 扩展快捷键页的 zing 项下录入新组合。
3. 再次打开 zing 面板。

结果：面板读取新绑定。设置始终显示 Chrome 当前的实际绑定；未绑定时会明确提示。macOS 默认绑定为 Cmd+Shift+P。

标准扩展 API 不允许 zing 自行修改绑定。Ctrl+Tab 须按[脚本收藏与 Ctrl+Tab 配置](#脚本收藏与-ctrltab-配置)中的步骤手动配置。

「切换最近标签页」右侧显示快捷键和「前往配置」按钮。macOS 键帽显示 `⌃Tab`，说明写明「设置 Ctrl+Tab 切换最近标签页」。悬浮提示和读屏提示保留 `Ctrl+Tab`。Windows/Linux 显示 `Ctrl+Tab`。

键帽悬浮提示展开实际按键和用途。例如：`Shift + Command + P — 打开 / 关闭 zing`。面板快捷键提示随 Chrome 实际绑定更新。

**设置中的键盘与下拉菜单**

底栏显示 `Tab 下一个 · Shift+Tab 上一个`。方向键和 Enter 用于选择下拉选项。按 Esc 逐层关闭下拉菜单、返回主搜索、关闭面板。返回主搜索时，zing 保留关键词、选中项和光标。

下拉菜单按可用空间向上或向下展开。空间不足时，在菜单内滚动。按钮、下拉框和开关保持各自的控件外观。尺寸与视觉细节见[交互架构](INTERACTION-ARCHITECTURE.md#列表与设置键盘一致性)。

### 重新加载 zing

如果正在开发源码，先运行构建或 watch。此命令只重新加载本机已安装的构建，不执行源码构建。首次安装包含此功能的版本后，仍须在扩展管理页手动 Reload 一次。

1. 搜索 `Zing: Reload`、`reload zing`、`reload extension`、`reload ext` 或「重新加载扩展」。
2. 点击「Zing: 重新加载」，或按 Enter。
3. 重载完成后，用启动快捷键或工具栏按钮重新打开 zing。

**结果与限制**

英文命令名称为 `Zing: Reload`。重载前，zing 关闭网页浮层和扩展面板。普通网页和已保存设置保留。

空搜索不显示此命令。单独搜索 `reload` 或「刷新」仍只表示刷新标签页。

### 面板位置、底栏与返回

普通网页使用水平居中、偏上的网页浮层。窄屏或可用高度不足时，面板会缩小。

Chrome 内置页面使用带系统标题栏的独立窗口。窗口按来源内容区和缩放比例估算位置与尺寸，内容缩放跟随来源页。界面显示前，zing 用 Chrome 返回的窗口外框和标签页内容尺寸校准自身边框。

来源内容区的位置仍是估算值。zing 根据来源标签页内容尺寸和浏览器外框尺寸，按水平对称、底边对齐估算内容区。它无法直接测量来源内容区的屏幕原点。垂直标签栏、停靠的 DevTools 和系统边框可能造成偏差，不保证像素级对齐。尺寸与定位细节见[交互架构](INTERACTION-ARCHITECTURE.md#位置与浏览器承载方式)。

独立面板中的搜索和操作仍针对来源页。在主搜索层按 Esc、再次按启动快捷键或切换到其他窗口，会关闭面板。

普通网页的地址栏持有焦点时，zing 使用工具栏扩展弹窗作为备用方式。Chrome Web Store 等其他不允许注入的页面也使用此弹窗。弹窗位置由 Chrome 控制。PDF 查看器的表现受 Chrome 注入限制影响。文件页未允许文件访问时，也使用备用弹窗。

**底栏与窄屏**

主搜索和列表型二级页共用面板尺寸、搜索框位置与底栏位置。切换页面时，底边保持不动。二级页没有单独的标题栏。

底栏左侧显示入口按钮、只读位置名称和补充信息：

| 页面 | 底栏左侧 |
| --- | --- |
| 主搜索 | 设置齿轮、zing、导航提示 |
| 页面存储 | 返回箭头、存储类型名称、站点来源 |
| 标签组 | 返回箭头、组名、成员数量 |

名称和补充信息用留白分开。右侧显示主操作、操作菜单和快捷键。主搜索与 Tab Switcher 使用相同的导航提示：`Ctrl+P 上一个 · Ctrl+N 下一个`，英文为 `Ctrl+P Previous · Ctrl+N Next`。提示直接显示 Ctrl+P / Ctrl+N，不显示方向键。每个快捷键组合显示在单个键帽中，例如 `⌘T`、`⌘⇧T`、`⌘K`、`Ctrl+Tab`；左侧导航提示不显示键帽边框。

短暂状态反馈替换补充信息。宽度不超过 520px 时，底栏隐藏补充信息，包括主搜索与 Tab Switcher 的导航提示。复制成功、执行中和危险操作等状态反馈仍显示，必要时截断。入口按钮、位置名称和右侧操作始终保留。长名称先截断，操作按钮不收缩。视觉细节见[交互架构](INTERACTION-ARCHITECTURE.md#面板布局与操作组件)。

**返回与操作菜单**

所有搜索框尾部都有可点击的 `esc`：主搜索、设置、页面存储、标签组、脚本选择、操作菜单和 Tab Switcher。悬浮提示说明 Escape 在当前页面的关闭、返回或取消用途。清空输入使用独立按钮。

点击返回箭头、点击 `esc` 或按 Esc，每次只退出最深的活动层。空搜索框中的 Backspace 也可返回。返回顺序为先关闭操作菜单，再退出编辑层，最后返回主搜索。zing 恢复搜索词、选中项和光标。二级页返回主搜索时，原选中项会重新滚动到可见位置。

主搜索、标签组管理页、页面存储列表和收起恢复页均支持右键候选项。右键直接打开该项的操作菜单。按 Esc 关闭菜单后，可继续输入。

脚本收藏单击行只选择只读预览；Enter 和底栏主操作复制代码。编辑须从操作菜单进入。脚本运行返回时，zing 恢复鼠标选择和搜索选区。两个脚本列表均支持 PageUp / PageDown、Alt+方向键翻页，以及 Cmd/Ctrl+方向键跳到首尾。

## Chrome 内置页面

「Chrome 内置页面 / Chrome Pages」用于打开或切换到指定的 Chrome 内置页面。所有入口支持中英文搜索。

1. 在主搜索中输入下表中的关键词。
2. 点击结果，或按 Enter。

底栏主操作和操作菜单执行相同动作。

| 入口 | 搜索词示例 | 目标地址 |
| --- | --- | --- |
| 扩展管理 | `extension`、`extensions`、扩展、插件 | `chrome://extensions/` |
| 密码管理器 | `password`、`passwords`、密码 | `chrome://password-manager/passwords` |
| 下载内容 | `download`、`downloads`、下载 | `chrome://downloads/` |
| 历史记录 | `history`、历史、浏览记录 | `chrome://history/` |
| 书签管理器 | `bookmark manager`、管理书签 | `chrome://bookmarks/` |
| Chrome 设置 | `chrome settings`、浏览器设置 | `chrome://settings/` |
| 扩展快捷键 | `extension shortcuts`、扩展快捷键 | `chrome://extensions/shortcuts` |

空搜索不显示这组命令。输入 `Chrome Pages`、「Chrome 内置页面」或「浏览器 / browser」，可找到整组入口。也可使用分类关键词，例如 `Chrome Pages: password`。

**结果**

zing 只复用来源窗口中目标地址一致的标签页。有多个匹配时，优先使用当前活动页；否则选择最左侧的匹配页。没有匹配时，zing 在来源窗口中新建标签页。它不替换当前网页，也不切换到其他窗口。

地址的子路径、查询参数和片段分别匹配。例如，扩展详情、扩展搜索和扩展快捷键页不算扩展管理首页。

成功后，zing 关闭面板。失败时，zing 保留搜索并显示错误。每个入口独立记录本机使用偏好。无痕窗口不记录。

**入口区别与限制**

`settings / 设置` 打开 zing 设置。`shortcut / 快捷键` 定位 zing 的键盘设置。要打开 Chrome 设置或扩展快捷键页，使用表中的具体关键词。

设置和脚本配置中的扩展快捷键按钮也使用上述标签页复用规则。书签管理器入口与书签内容搜索同时可用。

这些入口不读取密码、浏览历史或下载数据，也不新增权限。Chrome 负责密码查看和身份验证。打开当前页 DevTools 不属于这组入口；zing 目前未提供该命令。

## 脚本收藏与 Ctrl+Tab 配置

### 配置 Ctrl+Tab

1. 打开设置 → 键盘。
2. 点击「切换最近标签页」右侧的「前往配置」。
3. 点击底栏「复制代码」，或按 Enter。
4. 从「操作」中选择「打开 Chrome 快捷键页」。
5. 在该页面打开 DevTools Console。
6. 按配置说明执行已复制的代码。

也可在主搜索中输入「ctrl tab」直接找到配置说明。进入说明时，焦点位于底栏「复制代码」。

**结果与限制**

内置代码自动使用当前安装的扩展 ID，并绑定 Ctrl+Tab / Ctrl+Shift+Tab。Chrome 内部接口不能从扩展设置页直接调用。

内置代码只读，不可删除。zing 不会自动运行它。

### 查找、预览与复制脚本

1. 在主搜索中输入「脚本 / scripts / 管理脚本」。
2. 按 Enter。
3. 在脚本收藏中输入名称进行筛选。
4. 单击一个候选项。

也可从设置中的「管理脚本」进入。

**结果**

左侧单行列表按名称筛选，并高亮匹配文字。右侧立即显示所选脚本的只读代码预览、名称和内容类型 JavaScript。预览只显示实际数据，不显示未记录的创建时间、修改时间、复制次数或标签。

单击只更新选择与预览。悬停不改变选择。方向键、Ctrl+N/P、翻页和首尾快捷键也会更新选择与预览。要复制所选脚本，按 Enter 或点击底栏「复制代码」。

搜索栏和底栏保持固定。列表与预览分别滚动。宽度不超过 520px 时，列表移到上方，预览移到下方；两者仍分别滚动。

Tab 遍历控件，不逐项遍历候选行。

### 新建、编辑与删除脚本

要新建脚本，可使用以下任一入口：

- 在主搜索中输入「新建脚本 / new script」。
- 点击脚本收藏底栏的「新建脚本」。
- 在脚本收藏中按 Cmd+Shift+N；Windows/Linux 使用 Ctrl+Shift+N。

窄屏中，「新建脚本」显示为加号。悬浮提示显示名称和快捷键。

**编辑并保存**

1. 在脚本收藏中选择脚本。
2. 通过右键、底栏「操作」或 Cmd+K 打开操作菜单。
3. 选择编辑。
4. 修改名称。
5. 修改代码。
6. 按 Cmd+Enter 保存；Windows/Linux 使用 Ctrl+Enter。

在代码框中，普通 Enter 用于换行。编辑页中的 Cmd+K 可打开复制、保存或删除操作。

操作菜单还提供复制代码、新建和删除。删除须确认，确认框默认聚焦取消。内置项用「查看配置说明」替代编辑，不允许修改或删除。

从编辑页或菜单返回后，zing 保留搜索词、脚本选择和搜索选区，并将选中项滚动到可见位置。脚本收藏、编辑、内置配置和运行结果的返回按钮与层名都在共用底栏。编辑页和结果页没有搜索框。

### 运行脚本

**版本与授权条件**

脚本执行需要 Chrome 135+。Chrome 138+ 首次使用时，按提示打开 zing 的扩展详情，并开启「允许用户脚本」。Chrome 135–137 使用开发者模式。

普通 HTTP(S) 网页通过已有的 `activeTab` 临时授权运行脚本。zing 不申请全站主机权限。Chrome 内置页中的代码和内置 Ctrl+Tab 配置代码仍须手动执行。

**按名称运行**

1. 在目标网页打开 zing。
2. 搜索已保存的脚本名称。
3. 按 Enter。

结果：脚本在当前网页运行一次，面板显示结果。

该脚本候选项的 Cmd+K 菜单提供运行、运行并复制结果、复制代码、编辑和删除。

**从运行列表选择**

1. 在主搜索中输入「运行脚本 / run script」或「运行并复制结果 / run and copy result」。
2. 按 Enter。
3. 点击一个已保存脚本，或按 Enter 确认所选脚本。

运行选择使用全宽单行列表。其搜索、行样式和导航方式与脚本收藏相同。点击、普通 Enter 和底栏主操作都会显式运行一次。

**示例**

保存一个名为「复制 token」的脚本，代码如下：

```js
localStorage.getItem("token")
```

1. 在目标网站打开 zing。
2. 搜索「复制 token」。
3. 按 Enter 查看结果。

如果要自动复制结果，在第 3 步改用 Cmd+K 菜单中的「运行并复制结果」。

**结果与退出**

代码最后一个表达式作为结果。Promise 会等待完成。异步多步逻辑可使用 async 函数立即调用。字符串保持原样。对象显示为格式化 JSON。

结果只在本次面板中显示，不保存。成功后，底栏主操作为「复制结果」。失败后，底栏主操作为「重新运行」。Cmd+K 菜单可选择复制或重新运行；底栏主操作随菜单选中项变化。

执行期间，操作禁用。复制失败时，zing 保留结果供重试。结果文本仍可选中复制。关闭菜单后，zing 恢复焦点和选区。

按 Esc 逐层返回。退出仍在等待的脚本后，zing 不再自动复制结果。已经开始的脚本可能继续执行。

**执行范围与隐私**

脚本仅保存在本机。每次运行都须显式选择。zing 不会自动展开文本，也不会随网页加载运行脚本。代码正文不参与搜索或使用习惯记录。

脚本运行在 Chrome 的隔离用户脚本环境中。它可访问当前顶层页面的 DOM、Local Storage 和 Session Storage。此环境不提供网页自身的 JavaScript 变量、扩展 API 或油猴的 `GM_*` API。

zing 不上传代码或结果。脚本本身可以修改页面或发起网络请求。具体行为取决于保存的代码。

## 最近标签页切换

Tab Switcher 使用与 VS Code Ctrl+Tab 相同的「选择后确认」方式。

### 快速切换

在 macOS 上，默认快捷键为 Control+J。如果已配置 Ctrl+Tab，使用该绑定。

1. 按住 Control。
2. 按 J 打开切换器；已配置 Ctrl+Tab 时，按 Tab。
3. 用 N/P、↑/↓ 或重复快捷键移动高亮。
4. 如果尚未进入搜索状态，松开 Control 确认切换。

反向快捷键向反方向选择。也可用普通 Enter、点击候选项或底栏「切换」确认。

**结果与取消**

切换器打开时，默认高亮上一个标签页。页面暂不切换。移动高亮不会激活候选标签页。确认后，zing 切换到选中页并关闭切换器。

按 Esc、点击「取消」或使切换器失焦，会取消切换。起始页被关闭或移出窗口时，也会取消。仅将鼠标移到候选项上，不会改变松开 Ctrl 时的切换目标。

### 搜索最近标签页

打开切换器时，输入框为空且禁用。焦点位于候选列表。输入框显示「搜索最近标签页…」，英文为 `Search recent tabs…`。此时不显示编辑光标或焦点蓝框。

1. 点击搜索图标或输入区域，或按 Cmd+F；Windows/Linux 使用 Ctrl+F。
2. 松开启动修饰键。
3. 输入标题或网址。
4. 用导航键选择候选项。
5. 按普通 Enter、点击候选项或点击底栏「切换」确认。

**结果**

进入搜索后，本次会话暂停松键确认。可正常输入，不会因松开启动修饰键而切换。未进入搜索时，仍按松键确认。

搜索只筛选本次会话中当前窗口的候选项。搜索不区分大小写。用空白分开的每个词都须命中标题或网址。匹配文字高亮，结果保持最近使用顺序。

修改搜索词时，如果原选中页仍可见，zing 保留选择；否则选择首项。没有匹配时，不能确认切换。

候选页被关闭或移出窗口时，zing 将其移除。如果移除的是选中项，且来源页仍可见，选择会回到来源页。否则暂不选择任何项，直到再次导航、点击或修改搜索词。

搜索已启用时，再次点击搜索图标或按 Cmd+F / Ctrl+F，可恢复输入焦点。

### 导航、底栏与系统限制

默认列表或启用后的输入框持有焦点时，可使用以下按键：

| 按键 | 结果 |
| --- | --- |
| `↑` / `↓`、`Ctrl+P` / `Ctrl+N`、`Tab` / `Shift+Tab` | 循环选择 |
| `PageUp` / `PageDown` 或 `Option（Alt）+↑` / `↓` | 按页移动 |
| `Ctrl/Cmd+↑` / `Ctrl/Cmd+↓` | 跳到首尾 |
| 普通 `Enter` | 确认当前选择 |
| `Esc` | 取消；加载期间也可使用 |

所有带修饰键、长按重复或输入法组合期间的 Enter 均不执行。

独立窗口加载期间，zing 按原顺序保留导航输入，并在列表就绪后应用。加载期间的松键也会被缓冲。

**承载方式与快速点按**

普通 HTTP(S) 网页预加载轻量修饰键监听。快速点按可直接切回上一页，无需 Enter。按住时，zing 显示与主搜索同位置、同尺寸的网页浮层。扩展更新前已打开的网页须刷新一次，才能启用监听。

网页浮层与独立窗口共用搜索框、列表和标题／网址布局。独立窗口按来源页的缩放比例换算位置，内容缩放也跟随来源页。它用 Chrome 返回的窗口与标签页尺寸校准自身边框，并保留系统标题栏。

无法聚焦网页时，zing 使用独立窗口。Chrome 内置页、Chrome Web Store 等受限页面也使用独立窗口。此时极短点按可能需要 Enter 确认。zing 不用定时器猜测松键。

原有 Cmd+Shift+P 绑定保持不变。Windows/Linux 默认使用 Ctrl+, 和 Ctrl+Shift+,；对应系统的原生输入尚未验收。详见[切换器说明](RECENT-TABS.md)。

**底栏**

快速切换时，底栏左侧显示「松开 Ctrl 切换」。进入搜索后，左侧显示「切换最近标签页」。其后显示与主搜索相同的 `Ctrl+P 上一个 · Ctrl+N 下一个`，英文为 `Ctrl+P Previous · Ctrl+N Next`。提示直接显示 Ctrl+P / Ctrl+N，不显示方向键。搜索栏的悬浮提示显示实际启动快捷键。

右侧「切换 ↵」和「取消 esc」均可点击。搜索栏右侧也有取消按钮。窄屏隐藏导航提示，但保留松键提示或搜索状态标题，以及操作按钮。网页浮层填满面板可用空间，底栏下没有额外帮助行。

## 收起标签页

「收起」将标签页移入当前窗口末尾的 Chrome 折叠组，例如「已收起 · 3」。页面仍然打开。zing 不会关闭、重新加载或主动卸载（discard）这些页面。Chrome 自身的内存节省机制仍按浏览器设置运行。

### 开启或停止自动收起

自动收起默认关闭。

1. 打开设置 → 实验性功能。
2. 开启「自动收起闲置标签页」。

也可搜索「自动收起 / auto tuck」直接到达开关。点击开关或文字标签均可切换。开关获得键盘焦点后，Space 和 Enter 也可操作。

**结果与条件**

开启后，zing 在电脑暂时空闲时检查 **7 天未使用**的标签页。首次开启从当下开始计时，不将不确定的旧历史算作闲置时间。重新开启时，计时重新开始。

自动收起跳过以下页面或窗口：

- 当前页和固定页。
- 已有分组中的页面。
- 正在播放声音或正在加载的页面。
- 多选页和分屏页。
- 无痕窗口。

zing 不接管用户自行创建的分组，也不会在到期时强行打断操作。此功能没有新增专用快捷键，继续使用主搜索、底栏和 Cmd+K。

要停止自动收起，关闭设置开关。zing 停止自动检查，并将当前仍由 zing 管理的组移回普通标签栏。标签页保持当前相对顺序。待确认归属的组按下文的恢复规则处理。

### 手动收起

自动收起关闭时，仍可手动收起。

**收起当前页**

1. 在主搜索中输入「收起标签页 / tuck tab」。
2. 点击结果，或按 Enter。

结果：zing 先切换到另一个已有标签页，再收起当前页。

**收起其他页**

1. 在主搜索中搜索目标标签页。
2. 选中目标标签页。
3. 点击底栏「操作」，或按 Cmd+K。
4. 选择「收起标签页」。

不必先切换到目标页。

**限制**

固定页和已有分组中的页面不提供收起操作。如果当前页没有其他可切换的标签页，操作会显示原因。

搜索中的已收起页保留原始标题和网站图标，右侧显示「已收起」。

### 找回与撤销

**找回一页**

1. 在主搜索中输入页面标题或网址。
2. 点击结果，或按 Enter 切换。

也可展开 Chrome 的「已收起」组，再点击所需页面。

结果：只有选中的一页移出组，其他页继续收起。找回的页面放在收起组之前，其他普通标签页不重排。

已收起页仍在 Tab Switcher 的最近标签列表中。确认切换后，该页才移出组。移动高亮或取消不会改变分组。

**撤销最近一批收起**

1. 搜索「撤销收起 / undo tuck」，或在空搜索中选择该命令。
2. 点击命令，或按 Enter。

结果：仅撤销当前窗口最近一批仍由 zing 管理的标签页。找回或撤销后，7 天计时重新开始。

**限制**

撤销不会恢复已关闭的页面，也不会还原整个窗口的旧排序。对于已被用户移走或重新分组的标签页，zing 不会将其移回。

在 zing 外为组改名或改颜色后，该组交由用户管理。向组内添加页面后，也由用户管理该组。zing 不再自动调整这些组。在 zing 内改名和换色会保留自动管理关系，见 [Tab Group 搜索与管理](#tab-group-搜索与管理)。

### 浏览器重启与扩展重新加载

zing 在本机保留分组恢复记录，不依赖旧的组编号。只有以下信息全部唯一匹配时，zing 才自动恢复管理：

- 组名。
- 灰色组颜色。
- 完整成员网址，包括重复网址的数量。
- 窗口中的其他网页。

浏览器尚未恢复窗口时，zing 保留记录。后续恢复事件或再次打开面板会触发重新检查。撤销批次只在本次会话内有效，不跨重启恢复。

**手动确认归属**

如果信息不完整、成员发生变化或存在重复组，按以下步骤确认：

1. 搜索「恢复收起组 / recover tucked tabs」。
2. 打开恢复入口。
3. 核对当前窗口候选组中的具体页面。
4. 点击需要接管的候选组卡片。
5. 点击底栏「继续管理这组」，或从 Cmd+K 菜单执行该操作。

点击卡片只选择候选组，不确认接管。

结果：zing 恢复灰色「已收起」名称及管理关系。当前活动页移回普通标签栏，其余页面折叠。按 Esc 或 Backspace 返回上一层，不作更改。

旧版本中没有持久记录的灰色「已收起」组，也须先确认归属。

**暂缓或停止恢复**

尚未找到原窗口，或暂时不想继续管理时，可以稍后再决定。要停止恢复，从 Cmd+K 菜单选择「停止恢复这条记录」。此操作只删除恢复记录，不改变任何标签页或原生分组。

待确认期间，zing 不会在未受管的窗口新建收起组，也不会向有待确认候选组的窗口继续收起。这可避免重复创建收起组。

关闭自动收起开关后，zing 展开已经确认归属的组。待确认组保持原状，须先确认归属才能管理。

### 本机记录与权限

zing 保存两类本机记录：

| 记录 | 内容与保留条件 |
| --- | --- |
| 闲置计时记录 | 开启自动收起时，保存当前开放页面的网址和最近使用时间；关闭自动收起后清空 |
| 分组恢复记录 | 保存组名、成员网址和窗口其他网页的网址；已管理的组解除、用户改组或主动停止恢复后移除；窗口已关闭但仍可能恢复时保留 |

相同网址使用最近一次使用时间计时，避免过早收起。zing 不保存页面正文或表单值，不上传记录，也不记录无痕页面。

此功能使用 `tabGroups` 操作原生标签组，使用 `alarms` 定期检查，使用 `idle` 避开正在使用电脑的时刻。无需新增网站访问权限。

## 页面存储

### 查看与复制

1. 在主搜索中输入 `local storage`、`session storage` 或 `cookie`。
2. 按 Enter。
3. 在存储列表中输入名称进行筛选。
4. 用 ↑/↓ 或 Ctrl+P/N 选择条目。
5. 单击条目，或按 Enter 复制原始值。

也支持「本地存储」和「会话存储」。存储列表显示当前页面的数据。名称和值预览并排显示。

**详情与其他操作**

双击条目可打开详情。按 Cmd+K 或右键点击候选项，可打开操作菜单。菜单提供「复制名称」「查看详情」和「刷新」。需要阅读长值时，选择「查看详情」。

详情中的 JSON 自动格式化。复制仍使用原始字符串。Ctrl+P/N 或方向键可滚动长内容。

按 Esc、在空搜索框中按 Backspace，或点击底栏左侧返回箭头，可逐层返回。zing 恢复原搜索、选择和焦点。底栏左侧依次显示单色返回按钮、存储类型名称和当前站点来源，名称与来源用留白分开。

### 读取范围

Local Storage 和 Session Storage 读取当前标签页的顶层页面。

Cookie 列表显示与当前页面 URL 匹配的记录，包括 HttpOnly Cookie。列表包含域名、路径、有效期和分区信息。Chrome 132+ 还读取当前顶层页面对应的分区 Cookie。较旧版本读取普通 Cookie。

页面导航后，须重新打开 zing。Chrome 内置页等非 HTTP(S) 页面会显示说明。此版本只支持查看与复制。

### 网站授权与隐私

Local Storage 和 Session Storage 使用已有的 `activeTab` 临时授权。

首次读取某网站的 Cookie 时：

1. 点击「允许访问此网站」。
2. 在授权页核对域名。
3. 确认授权。

结果：Chrome 请求该网站的权限。授权完成后，zing 自动返回列表。同一网站后续无需重复授权。可在 Chrome 的扩展设置中撤销权限。

为了读取普通 Cookie 和父域 Cookie，授权范围包含当前主机及必要的父域，涵盖 HTTP/HTTPS。授权不包含其他子域或所有网站。

存储内容只在当前面板内存中显示。zing 不将内容写入扩展存储或日志，也不上传内容。只有成功打开存储命令计入排序。条目名称、值、列表搜索和刷新不计入。

**本地验收页**

可运行 `node tests/storage-manual.mjs` 启动临时本地验收页。终端会输出 URL。页面提供可复制的 Local/Session 测试值和 HttpOnly Cookie。

### Tab Group 搜索与管理

1. 在主搜索中输入标签组名称。
2. 选择 `Tab Group: 名称`，中文界面显示「标签组」。
3. 在管理页中继续搜索所需标签页。
4. 点击标签页，或按 Enter 切换。

搜索组名可同时找到该组和成员标签页。管理页支持 Ctrl+N/P 或方向键选择。

**管理操作**

底栏「操作」、右键候选项和 Cmd+K 均可打开操作菜单。菜单支持关闭所选标签页、移出组、展开或折叠组、重命名和换色。操作支持中英文关键词搜索。

编辑页通过底栏保存。按 Esc、在空搜索框中按 Backspace，或点击底栏左侧返回箭头，可返回上一层。

底栏左侧显示单色返回按钮、组名和成员数量。组名与数量用留白分开，组名旁不显示组色图标。

Tucked Away（「已收起」组）使用同一管理页。在 zing 内改名和换色会保留自动管理关系。关闭或移出最后一个成员后，Chrome 会移除空组，zing 会提示组已不可用。
