## 2. 验证环境分层与证据效力

在评估验证结论时，严格区分环境层级，不得以低层证据直接推断高层结论：

```
+-------------------------------------------------------------+
| 层级 3: 日常 Chrome 真实生产环境 (Daily Chrome Runtime)        |
| - 真实用户资料、实体按键触发、浏览器真实地址栏焦点与窗口层叠      |
+-------------------------------------------------------------+
                              ▲
+-------------------------------------------------------------+
| 层级 2: 隔离浏览器自动化 (Isolated Chrome for Testing)        |
| - 临时 Profile、闭合 Shadow DOM、CDP 真实键盘事件、真实渲染尺寸 |
+-------------------------------------------------------------+
                              ▲
+-------------------------------------------------------------+
| 层级 1: 内存与静态逻辑 (Node.js Unit Tests / Direct UI)       |
| - tsx / Node test runner、类型检查、状态机与算法断言           |
+-------------------------------------------------------------+
```

1. **层级 1（逻辑与状态）**：验证纯逻辑、排序权重、存储淘汰、状态机转移与国际化文案。通过仅证明算法逻辑正确。
2. **层级 2（隔离自动化）**：验证组件在标准 Chromium 环境中的真实渲染、几何外框、事件拦截与交互流转。其中独立 UI 测试加载真实构建产物、模拟 Chrome API，仅证明组件对给定响应的行为；扩展集成测试使用真实扩展与独立 Profile，承担后台消息、存储、权限和原生标签／窗口的验证。两者不可互相替代；自动化测试通过仅证明所用环境下的既定用例。
3. **层级 3（日常实机）**：验证与日常 Chrome 扩展生态（如 Vimium）、原生全屏、多显示器缩放、系统深浅色切换及用户手工操作的实际融合体验。

## 3. 已知受限与待解决项 (Known Limitations & Deferred Boundaries)

以下为当前版本明确已知的受限边界或架构演进中暂停的工作，不作为质量缺陷宣称已解决：

1. **双承载使用不同定位基准（[ADR 0010](adr/0010-content-anchor-panel-geometry.md)）**：
   - 普通网页浮层相对页面视口水平居中、偏上；原生页独立窗口相对来源浏览器窗口水平居中，从窗口顶部计算偏移。
   - 两种承载保持尺寸策略与交互一致，不要求屏幕坐标精确重合；侧栏展开时位置不同属于已接受的产品行为。固定显示器位置不属于当前验收目标。
   - 几何自动化覆盖横向／竖向标签栏及 100%、125%、80% 缩放；不同显示器与其他侧栏尺寸不能由这些用例推断通过。
2. **浏览器自动化稳定性**：
   - 隔离 Chrome 曾在启动持久上下文及关闭上下文阶段超过 30 秒；前者发生在用例主体开始前，后者可在主体完成后仍导致失败。当前候选的双 worker 完整验证已通过。此前原生面板创建期间曾记录 Chrome 整体失焦、触发来源保护退出；导航用例曾仅等待候选出现就回车，现等待选中且可执行状态。历史启动／收尾超时根因仍未确定，单轮全量通过不证明长期稳定性。
   - 后台生命周期压力场景的 Chrome 156 SIGTRAP 已通过匹配二进制与同版本源码定位到 `NetworkHandler::GetResponseBody()` 的 `CHECK(storage_partition_)`（[Chromium 156.0.8078.4](https://chromium.googlesource.com/chromium/src/+/refs/tags/156.0.8078.4/content/browser/devtools/protocol/network_handler.cc#3741)）。Playwright trace 会异步读取响应正文；压力用例现独立隔离其 DOM／网络快照，保留操作 trace、生命周期事件和脚本就绪等待。协议检查确认不再调用该响应正文接口；当前 0.3.0 候选构建的完整套件中，该用例完成 100 次停止与成功唤醒、20 次重载，无脚本加载错误或异常断连。存储分区变空的具体时序仍未确定；这属于测试采集路径规避，完整套件通过不代表 Chrome 缺陷已修复。不得以提高超时或减少压力次数替代验证。
3. **外部删除来源标签页直接结束会话**：
   - 若用户在小范围瞬移面板处于打开状态时，通过外部快捷键或鼠标关闭了唤起该面板的来源标签页，面板会话将立即安全退出，不进行跨标签页迁移接续。
4. **自动化测试无法完全替代 CDP 实体修饰键松开**：
   - 标准 WebDriver / Playwright 缺乏原生的系统级修饰键独立松开事件，自动化测试采用 CDP 底层协议注入按键序列作为替代证据，最终松键交互需以日常实机表现为准。
