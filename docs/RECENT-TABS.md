# 最近标签页切换器实现参考 · Recent Tab Switcher Technical Reference

用户使用指引见 [使用指南 (中文)](USAGE.zh-CN.md#3-最近标签页切换像-vs-code-一样顺手) · [User Guide (English)](USAGE.md#3-tab-switcher-recent-tabs-like-vs-code)。架构演进与设计权衡见 [ADR 0006](adr/0006-recent-tab-switcher.md)。

本文档记录小范围瞬移内置的 **Tab Switcher**（类似 VS Code 的 `Ctrl+Tab` 最近标签页切换器）的交互状态机、快捷键桥接、MRU 排序与双模承载技术边界。

---

## 1. 核心架构与两种进入模式

Tab Switcher 提供了两种使用路径，满足不同场景下的操作习惯：

```
┌─────────────────────────────────────────────────────────────┐
│                       Tab Switcher                          │
├──────────────────────────────┬──────────────────────────────┤
│ 1. 快捷键唤起 (极速穿梭模式) │ 2. 主搜索进入 (面板内嵌视图) │
│ - 按住 Control/Ctrl          │ - 搜索 "tab switcher" / 首页 │
│ - 点按触发键轮巡候选         │ - 初始即进入搜索状态         │
│ - 松开修饰键直接确认切换     │ - 回车 / 点击确认切换        │
│ - 支持点击/Cmd+F切入搜索     │ - Esc / 返回按钮退回主搜索   │
└──────────────────────────────┴──────────────────────────────┘
```

### 模式 A：快捷键极速切换（Hold, Cycle & Release）

1. **触发与聚焦**：
   - 默认快捷键：macOS 为 `Control+J`，Windows/Linux 为 `Ctrl+,`（反向加 `Shift`；可配置为 `Ctrl+Tab`）。
   - 唤起时默认高亮上一个标签页（MRU 列表中除当前活动页外的第一项）。
   - 网页浮层立即响应按键，统一在 150ms 后渐显面板。如果是极速轻敲点按，直接在后台切回上一页，无需多余闪烁。
2. **列表轮巡**：
   - 按住修饰键的同时，继续点按触发键、`↑`/`↓`、`Ctrl+P`/`Ctrl+N` 或 `Tab`/`Shift+Tab` 循环选择。
   - 鼠标悬停仅提供视觉高亮，不抢夺键盘当前的预选目标。
3. **松键确认 (Release to Switch)**：
   - 松开启动修饰键时，立即向后台发送切换指令并激活目标标签页。
   - 按 `Esc` 或窗口失焦则安全取消，不切页。
4. **即时搜索筛选 (Pause on Search)**：
   - 在按住修饰键的任何时刻，若**点击顶部搜索框**或按下 **`Cmd+F` / `Ctrl+F`**，会立刻**暂停**“松键即切换”模式。
   - 此时用户可以彻底松开按键，自如地输入标题或 URL 过滤标签页，随后通过 `Enter` 或鼠标单击明确确认。

### 模式 B：面板内嵌视图（从主搜索进入）

- 在空搜索首页点击「Tab Switcher」，或在主搜索中输入 `tab switcher` / `最近标签页` 进入。
- 此时切换器作为面板的二级视图打开，初始直接聚焦搜索框。
- 候选依然严格遵循当前窗口的 MRU 顺序排列。
- 明确通过单击、回车或底栏「切换」按钮完成跳转；通过 `Esc`、搜索尾部 `esc` 按钮或底栏返回按钮可无损退回上一级主搜索，完整保留原搜索词与光标。

## 2. 快捷键桥接与跨 Frame 监听 (`recent-keys.js`)

Chrome 官方扩展 API（`chrome.commands`）仅派发快捷键按下事件，**不提供原生 Keyup（修饰键松开）事件**。为了实现“松开按键即切换”的顺畅体验，小范围瞬移设计了精简的按键状态感知桥接：

- **轻量注入**：在普通 HTTP/HTTPS 页面及其匹配的 Subframe 中以 `document_start` 预加载轻量 content script（[`src/recent-keys.ts`](../src/recent-keys.ts)）。
- **严格隐私安全**：仅在后台会话活跃时观察并上报 `Control` / `Meta` / `Alt` 修饰键的状态转移，**绝不监听或读取常规字符输入、文本框打字内容或页面正文**，零日志且不上报任何按键序列。
- **子框架支持**：Subframe 覆盖确保即使页面焦点落在内嵌 iframe 中，修饰键释放事件依然能被精准捕捉。

## 3. 双模宿主承载与定位锚点

Tab Switcher 与主搜索面板完全共用两种宿主承载：

1. **网页浮层模式 (In-Page Overlay)**：
   - 运行在普通 HTTP(S) 网页内，相对页面视口水平居中、偏上显示，内容最大尺寸 750 × 516 CSS 像素。
   - 浮层容器自动适配视口大小，底栏高度固定为 44px。
2. **独立伴侣小窗口模式 (Dedicated Standalone Window)**：
   - 当来源页属于 Chrome 禁止注入的页面（如 `chrome://` 内置页、Chrome Web Store 或空标签页）时，自动转为轻量独立原生窗口承载。
   - 面板内容相对来源浏览器窗口外框水平居中，顶部留白从该窗口顶部计算；内容尺寸仍随来源标签页视口与页面缩放适配，系统标题栏与边框另计。两种承载不要求屏幕坐标重合，也不固定在显示器屏幕中心；定位、尺寸与边框换算见 [ADR 0010](adr/0010-content-anchor-panel-geometry.md)。
