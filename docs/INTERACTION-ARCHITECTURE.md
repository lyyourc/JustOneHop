# 交互实现参考

本文描述当前组件职责与实现约束；设计动机及取舍见 [ADR 索引](adr/README.md)，使用方法见 [使用指南](USAGE.md)。源码是接口的权威定义，本文不记录验收流水。

## 交互设计约束

产品遵循 README 的 [Human first 交互原则](../README.zh-CN.md#为什么做它)：鼠标和熟悉的快捷键都是正常使用路径，不要求用户先学习按键。新增或调整功能时，需同时考虑可发现的点击入口、快捷键提示、操作反馈与返回后的上下文。

鼠标按钮、菜单项与快捷键应调用同一操作逻辑，遵守相同的可用性和执行中状态。验收覆盖鼠标完成流程、键盘完成流程，以及两者交替操作；不能只验证快捷键能触发功能。本文的契约是新增或修改列表、子页面和操作弹窗时的逐项核对依据，不表示现有实现的所有边界均已验收；验证范围与证据见 [测试指南](TESTING.md) 和 [验收记录](ACCEPTANCE.md)。

### 通用列表与操作契约

- 默认候选行左键单击、普通 Enter 与底栏主操作执行同一主动作，使用同一目标和可用性判断。Storage 采用明确的预览列表例外：单击只选择并更新只读预览，普通 Enter 与底栏主操作复制原始值。收起恢复核对的卡片点击及卡片／列表 Enter 均只选择，不接管；纯键盘需 Tab 聚焦底栏确认按钮后执行，或通过操作菜单显式确认。配备 `ActionMenu` 的列表提供 `onContextMenu`：先 `event.preventDefault()`、选中该项并保存输入框光标，再打开对应菜单。
- 主搜索与全部历史页通过共享 `SearchResultItem` 支持标题、说明等结果文字的原生拖选；拖选文字后松开鼠标不得触发行主动作、导航或学习写入。普通左键单击仍执行主动作，不改为只选择或要求双击；行内按钮继续执行各自操作。手势判断由共享行负责，不能只在某个视图阻止 click，也不能因此前残留的文字选区吞掉后续普通单击。
- 采用悬停选择的列表，其 `onMouseMove` 比对物理坐标 `event.screenX / event.screenY`，使键盘滚动时静止的指针不抢选中项。Storage 悬停不改变选择或预览，保证阅读稳定；Tab Switcher 悬停只展示可点击描边，不改变松开修饰键时的确认目标。
- 所有关键词过滤列表（主搜索、Storage、Tab Group 及 ActionMenu）使用 `HighlightedText` 渲染命中高亮：仅以 600 字重强调，继承所在文字的颜色，背景透明且无内边距，避免词内命中被色块和额外间距切断。每个菜单动作同时提供 `icon` 与中英文 `keywords`，筛选同时匹配 `title` 和 `keywords`，支持跨界面语言检索。
- 所有列表支持 ↑/↓ 与无额外修饰键的 Ctrl+P / Ctrl+N；选中项变化后调用 `scrollIntoView({ block: 'nearest' })`。长列表支持 PageUp / PageDown、Option+↑/↓ 翻页和 Cmd/Ctrl+↑/↓ 首尾跳转。
- `isComposing` 或 `keyCode === 229` 期间，Enter / Escape / Backspace 留给输入法，不执行业务或返回。带修饰键或 `event.repeat` 的 Enter 不执行主动作；编辑字段的普通 Enter 保留编辑语义。

### 手动恢复搜索焦点

主搜索、设置、历史、Storage、标签组、帮助与 ActionMenu 使用 `SearchFocusButton` 将小范围瞬移 logo作为可点击的「聚焦搜索框」按钮，带悬浮操作说明与键盘焦点轮廓。点击或聚焦按钮后 Enter／Space 仅恢复当前输入焦点，保留搜索词、选择和输入选区；输入禁用时按钮同步禁用。Tab Switcher 保留既有激活搜索的按钮与松键语义。

`NavigationRoot` 在实际 owner window 及浮层父 window 处理普通 Tab：仅在面板内没有有效控件焦点时恢复当前搜索输入，保留 caret／选区；有控件焦点时不拦截原有 Tab／Shift+Tab 顺序。`searchFocus` 为恢复和提示共用活动层判定：仅选择可见且不处于 inert 背景中的聚焦按钮；有 modal 时限制在该 modal 内，无搜索输入的确认层不跳回背景搜索。搜索栏在无控件焦点时显示本地化「按 Tab 聚焦搜索框」，获得输入或其他控件焦点后隐藏，不占额外布局高度。输入法、重复及修饰键 Tab 不触发恢复。不注册 Cmd/Ctrl+F 聚焦绑定；Tab Switcher 原有进入筛选行为不在本次新增恢复逻辑中。以承载 iframe 的父文档（非 iframe 时为 ownerDocument）的 `hasFocus()` 区分页面是否持有焦点，同时监听两级 window 的 focus／blur。Chrome 地址栏或其他应用持有焦点时，即使 DOM activeElement 仍是输入框，也显示「点击搜索框开始输入」，页面收不到按键，用户需点击搜索框或小范围瞬移 logo。页面重新获得焦点后按控件焦点状态切回 Tab 提示或隐藏提示。

搜索框品牌图形由 `Logo` 复用构建用的小尺寸 SVG，以面板的 `--muted`／`--accent` 配色；主搜索、设置、历史、Storage、标签组、帮助、ActionMenu 和两种 Tab Switcher 承载保持一致。图形对读屏隐藏，按钮仍保留聚焦／启用搜索的可访问名称与操作语义。

### Chrome 原生视觉

表面遵循 Chrome CR2023 Omnibox / Tab Search：内嵌胶囊搜索槽在聚焦时浮起并显示蓝框；未选中项使用无框圆角图标槽（浅色 `#f1f3f4`、深色 `#35363a`）和单色类型图标，避免按类别添加杂色或层层嵌套边框。选中项使用柔和蓝底（`#e8f0fe` / `#394457`），左侧为 3.5px 圆头指示条（`#0b57d0` / `#8ab4f8`）；危险态保留红色警示。网站图标的原生缓存来源见[候选项呈现](#候选项呈现)。

### 紧凑面板的整体比例

Chrome Native 约束配色、控件语义、焦点、悬浮、选中和禁用状态，不要求照搬 Chrome 设置页的控件尺寸。小范围瞬移使用固定高度的紧凑面板，必须把控件、容器、模块标题和留白作为整体设计；不能只放大按钮或下拉框，再逐项补边距。

设置页以 32px 高的正文按钮／选择框、48px 基础设置行、16px 正文水平边距和 12px 卡片内边距形成统一比例；说明换行时行高自然增长。保留胶囊操作按钮、矩形选择框和开关的语义区别，文字、键帽与控件垂直居中。模块间距同时适配，搜索框与底栏保持共享几何。检查整页信息密度、实际可见内容、鼠标目标、键盘焦点和窄屏换行，允许正文滚动，不以压小文字、裁切说明或缩小点击区域强求一屏展示。尺寸偏离 Chromium 默认值是面板适配，不应被当作原生风格缺陷。

## 面板布局与操作组件

内部标识统一使用 justonehop：消息 source、runtime port 名称、注入标记、DOM/ARIA ID、CSS 类和动画名与产品名一致。界面按语言显示「小范围瞬移 / JustOneHop」。品牌专用会话、收起恢复与时钟键同步更名，不读取旧键、不兼容旧消息或搜索别名；原收起组不会自动继承管理关系。通用 preferences 与 searchUsage 键继续使用，不新增迁移。旧版 `saved-script:*` 数据原样保留，不读取或使用，也不迁移或自动删除。浏览器测试配置使用 JUSTONEHOP_CHROMIUM_PATH、JUSTONEHOP_VIMIUM_PATH。

主搜索、Storage 和 Ctrl+Tab 配置指南共用同一套操作呈现，避免每个功能各自添加底部按钮。此边界基于已经存在的页面和行为；不引入全局命令注册器或路由框架。

- `PaletteFooter` 渲染固定高度、不可收缩的底栏。左侧 API 统一为 `navigation?: { kind: 'settings' | 'back'; label: string; tooltip: string; disabled?: boolean; buttonRef?: Ref<HTMLButtonElement>; onAction: () => void }`、`title?: string`、`context?: ReactNode` 与 `status?: ReactNode`。组件根据 `navigation.kind` 自己渲染唯一的 26px 单色图标按钮，统一尺寸、圆角、悬浮态和禁用态；`label` 提供可访问名称，`tooltip` 提供悬浮提示，`onAction` 调用共享设置操作或页面现有返回回调。`buttonRef` 可用于恢复焦点或作为复制操作的锚点；返回按钮在 `mousedown` 阶段阻止默认行为和冒泡，避免外部点击处理先关弹层、随后 click 又退出父页。页面不再通过 `leading` 或 `title.onBack` 拼装控件。按钮后依次是只读位置名称和以留白分开的补充信息；标题后不渲染圆点或竖线，紧随标题的 context／status 使用统一 16px 左外边距（叠加容器 8px gap），提示内部的同级动作组才用圆点分隔；位置名称统一为 11.5px / 500 的弱化文字，主搜索传 `t('extensionName')`（小范围瞬移 / JustOneHop），Storage 传存储类型名称（如 `Local Storage`），标签组传 `groupLabel`。标题旁不得另加品牌装饰、类型图标或组色图标。
- `context` 承载只读背景（站点来源、成员数量），显式使用 11px 字号、400 字重、16px 行高的弱化文字；主搜索 `App` 与 Tab Switcher 的 `RecentSwitcherView` 均传 `context={<NavigationHint />}`，继承同一排版，共用本地化「Ctrl+P 上一个 · Ctrl+N 下一个」（英文「Ctrl+P Previous · Ctrl+N Next」），与设置统一按键在前、动作在后、先上一个再下一个、组间圆点分隔；Ctrl+P / Ctrl+N 直接显示，不展示方向键，`navigationHelp` 仅提供补充解释；不得各自拼装。二级列表页仍显示站点来源或成员数量。快捷键共用 `key-chord` 与 `formatShortcut` 的语义结构（一个 `kbd` 对应一个完整快捷键组合：符号修饰键直接拼接如 `⌘T` / `⌘⇧T` / `⌘K`，文字修饰键以 `+` 连接如 `Ctrl+P` / `Ctrl+K`，Mod 按平台显示 ⌘/Ctrl），但左侧导航键的 `kbd` 继承上下文的字体与颜色，无边框、背景、内边距或最小宽度，宽度自动、高度 16px，左侧补充信息不显示键帽框。右侧主操作与 Actions 键帽保持 20px 高及原有边框、背景。短暂 `status` 出现时替换 `context`，占据同一位置与留白结构，不增加独立槽位，不挤走位置名称。右侧 `primary` 保留标签、键帽、可用性、回调与危险态；可选 `secondary?: { label: string; keys: string[]; icon?: ReactNode; disabled?: boolean; onAction: () => void }` 提供次要操作，与主操作共用按钮规则，均文字在前、键帽在后；主操作与次要操作文字统一为 500 字重，不通过粗细区分，键帽保持 500 字重。`actions` 仍是可选菜单开关；`isMac?: boolean` 默认为 `false`，只用于 Actions 的平台快捷键显示。业务页面不能在滚动正文末尾另放主要提交按钮。
- `ActionMenu` 渲染统一操作面板，负责焦点、方向键与 Ctrl+N/P、翻页、首尾跳转、Enter 执行、Cmd/Ctrl+K 切换和菜单内 Tab 焦点限制；通过 BackLayer 登记 Esc 返回。页面提供过滤后的动作、查询、选中项与回调；主搜索保留现有搜索排序算法，二级页面使用简单动作筛选。菜单打开时，`PaletteFooter.primary` 的文案和行为跟随当前高亮动作；关闭、删除、放弃恢复等动作标记 `danger: true` 时，底栏也传入 `danger: true`，保持相同的危险提示。
- 共享 `PaletteFooter` 的返回／设置、主操作、次要操作与菜单按钮均保护键盘激活：Enter／Space 在输入法组合（含 `keyCode === 229`）、长按重复或额外修饰键期间不得触发操作，也不得经浏览器合成 click 绕过保护。普通 Enter／Space 只执行当前聚焦按钮的动作，不冒泡成列表主动作；鼠标点击沿用同一可用性与执行中判断。此规则由共享底栏覆盖所有调用方，不依赖各页面补丁。
- 页面保留自己的业务状态、执行逻辑及退出菜单后的焦点，恢复焦点时忽略复制操作创建的临时 textarea。
- 主搜索、Ctrl+Tab 配置指南、Storage 列表／详情与收起恢复核对共用 PaletteFooter 和 ActionMenu。Storage 保留自己的数据读取与复制逻辑，菜单统一提供高亮、键盘导航、滚动和焦点行为。Storage 菜单打开期间，背景列表与预览不得通过点击、双击、右键或键盘导航更换菜单目标，也不得执行背景复制／详情动作；背景控件不参与 Tab 顺序。菜单关闭后恢复原选中身份、搜索 query 与 caret／选区；目标失效时禁用旧动作，不改绑相邻条目。设置同样复用 PaletteFooter，返回与位置名称放在底栏左侧。
- 列表型二级页（Storage、标签组）不渲染独立标题栏，顶部仅保留共享搜索栏；Ctrl+Tab 配置指南及收起恢复核对同样不设独立标题栏。位置名称走底栏字符串 `title`，返回走 `navigation.kind: 'back'`；主搜索用 `navigation.kind: 'settings'` 调用共用设置操作。返回按钮与 Esc 逐层返回语义一致，匹配最深活动 `BackLayer` 的返回行为；适用的 Backspace 同样每次只退最深一层（先关菜单或确认，再退编辑层，最后回搜索），不能直接跳回主搜索；`label` 说明真实行为（如 `返回 · Local Storage`），不能只报地名。`disabled` 不得仅因业务忙碌而阻断鼠标返回，必须与键盘路径的可用性一致。只读站点来源、成员数量、配置说明或恢复记录名称走 `context`，不是第二个可点目标。设置保留与主搜索一致的搜索输入 header，底栏使用返回按钮、Settings／设置标题及 Tab / Shift+Tab 控件导航提示；下拉展开时底栏返回经 `useNavigateBack` 仅关闭下拉并恢复触发器焦点。没有搜索需求的配置说明与恢复核对层不强加搜索框。
- 面板尺寸由 `.palette` 统一给出：常规总高 516px（含边框），网页浮层受可用视口高度约束，独立窗口填满视口；页面不得分别硬编码高度。正文以 `flex: 1; min-height: 0` 占满剩余空间并内部滚动，使 44px 底栏在主搜索、列表/详情和编辑层之间保持位置；列表切层时搜索框与底栏均保持位置。候选行共用 `.result` 的 40px 高度、26px 图标槽和 `.entry-copy` 的单行文字布局；Storage 使用分栏预览布局：左侧 key 列表、右侧完整 value 与 Cookie 属性，独立滚动；≤520px 时列表在上、预览在下。右侧使用 `ReadOnlyPreview`：上方无标题、无说明条的只读 textarea，下方为信息标题与属性行；字号、内边距、文本选择与横纵滚动一致。信息为 key、JSON／Text 内容类型及实际 Cookie 属性；信息区最多占一半高度并可滚动，保证内容区可见。预览字段保留原生文本导航与选择，不将其方向键和 Enter 转为列表动作。JSON 格式化仅影响预览，复制保留原始字符串；双击或菜单仍可进入单独详情层。
- 快捷键启动的 Tab Switcher 网页浮层与独立窗口共用 `RecentSwitcherView`，首行复用主搜索的 `.search-bar` 输入胶囊，列表复用 `.results`、`.result` 与 `.entry-copy`，标题和 URL 使用 `HighlightedText`。输入框初始为空且原生 `disabled`，不显示输入光标或编辑蓝框，焦点留在可聚焦列表，使用本地化 `recentSearch` 占位文字与可访问名称；默认由列表持有 `aria-activedescendant`，点击搜索图标、输入区域或 Ctrl/Cmd+F 后才启用并聚焦输入，以 `combobox` 的 `aria-controls` / `aria-activedescendant` 关联列表与当前选中项；搜索栏右侧提供取消按钮。实际启动快捷键仍放在 `header` 的 `title` 属性，未绑定时不提供该提示。底栏直接复用 `PaletteFooter`，不另加 `recent-help` 行：`title` 在快速切换时使用本地化 `recentRelease`（如「松开 Ctrl 切换」，按 `releaseKey` 显示对应修饰键），显式进入搜索后改为 `recentSwitcher`，`context={<NavigationHint />}` 与根 `App` 相同，共用本地化「Ctrl+P 上一个 · Ctrl+N 下一个」（英文「Ctrl+P Previous · Ctrl+N Next」）和 `navigationHelp` 补充提示，继承 11px / 400 / 16px 的共享样式。右侧 `primary` 是「切换 ↵」，未加载、无有效选中项或关闭期间禁用；`secondary` 是「取消 esc」，调用共享取消回调。浮层 `.recent-overlay .recent-switcher` 用 `flex: 1; min-height: 0; height: auto` 填满父 `.palette` 的可用空间，避免单独的 516px／最大高度造成底栏溢出或底部空白；独立窗口仍为 `100vh`。
- 底栏骨架为「左＝可选控件 + 位置／提示 + 补充信息／状态，右＝主操作、可选次要操作与操作菜单」；设置／返回入口不重复，Tab Switcher 的搜索栏右侧提供取消入口。列表页的搜索胶囊几何由 `.search-bar` / `.storage-search` 共享的规则给出，包含窄屏间距；新增列表页必须复用，不得另写一份胶囊样式。宽度 ≤520px 时仅隐藏补充信息 `.palette-footer-context`（包括主搜索与 Tab Switcher 的导航提示），不隐藏 `status`；Tab Switcher 的松键提示或搜索状态标题位于 `title`，窄屏仍保留。复制成功、执行中及危险操作等状态继续在原位置替换上下文，必要时可截断。导航按钮、位置名称与右侧操作始终保留，按钮不收缩，长标题先于操作控件截断。分区参考 Raycast [A fresh look and feel](https://www.raycast.com/blog/a-fresh-look-and-feel) 中左侧命令身份／状态、右侧上下文操作的思路；共享导航按钮、弱化位置名称与窄屏策略是小范围瞬移自己的适配，决策见 [ADR 0009](adr/0009-list-page-footer-breadcrumb.md)。

## 位置与浏览器承载方式

本节描述当前实现。后续定位目标已改为所在显示器屏幕水平居中、从屏幕顶部计算垂直位置，具体垂直偏移未定，工作仍暂停且未解决；目标与保留普通网页浮层的约束见 [ADR 0010 的待实现目标](adr/0010-content-anchor-panel-geometry.md#待实现目标)。

网页浮层的位置由 `content.tsx` 和 `.justonehop-app.overlay` / `.palette` 控制，独立窗口通过 `src/panelGeometry.ts` 复用同一内容区几何；子页面不能决定自己的承载方式或另设位置。普通网页当前为内容区水平居中、偏上的浮层，子页面切换时沿用相同坐标。

`panelRect(viewport)` 对齐网页浮层 CSS：宽度为 `min(750, viewport.width - 48)`，宽度 ≤520 时改为减 20；顶部 inset 为 `clamp(28, viewport.height × 0.16, 150)`，窄屏为 24；高度为 `min(516, viewport.height - inset - 24)`，水平居中，底部至少预留 24px。几何函数将极小视口的宽高下限保护为 1px。这里的 750×516 是面板内容矩形，不含独立窗口的系统标题栏和边框。

Command Palette 与 Tab Switcher 的独立窗口共用 `nativePanelBounds(owner, tab, frame, zoom)`。Chrome 返回的来源 `tab.width/height` 与窗口 `left/top/width/height` 均为屏幕逻辑像素（DIP），不是页面缩放后的 CSS 像素。按窗口外框和标签页宽高水平对称、底边对齐估算内容区，来源尺寸缺失时使用保守回退值。内容宽高先除以 `chrome.tabs.getZoom` 返回的缩放比例换算为 CSS 视口，再调用 `panelRect`，将结果乘回缩放比例并加上估算的内容原点得到屏幕坐标。创建时默认暂估框架为 `{ left: 0, top: 44, width: 0, height: 44 }`；这只是首帧外框估算，不是固定窗口总高。

`popup.tsx`（仅独立窗口入口）与 `switcher.tsx` 在 UI 渲染前调用 `alignPanelWindow`；切换器也在发送 `ready` 交接前完成该步骤。它重新读取来源窗口、标签页与当前 popup，核对窗口归属；popup 以 automatic / per-tab 缩放跟随来源页，不修改其他扩展页面的缩放。自身边框由 Chrome API 的 popup 外框尺寸减去 popup 标签页内容尺寸计算，两者均为 DIP，避免将缩放后的 DOM `innerWidth/innerHeight` 与原生窗口尺寸混减；左右按总宽差的一半、顶部按总高差减去半宽差计算，更新窗口位置和外框大小。边框校准失败时保留创建时的位置与尺寸。该步骤测量的是 popup 自身的框架，来源内容区的屏幕原点无法直接测量，仍依赖上述估算；垂直标签栏、停靠 DevTools 和系统边框可能造成偏差，不能承诺像素级对齐。独立窗口保留系统标题栏。决策与取舍见 [ADR 0010](adr/0010-content-anchor-panel-geometry.md)。

Chrome 原生页（chrome / chrome-search / chrome-untrusted / devtools）的 Command Palette 使用上述独立窗口，复用同一 App、底栏与返回层级；主层 Esc、重复启动快捷键或失焦关闭。后台在 session storage 保存窗口令牌、来源窗口和标签页，解析该窗口消息时恢复来源上下文，并核对来源仍为原窗口的活动标签页。来源页无论被直接关闭、批量操作连带删除或外部关闭，都结束当前小范围瞬移会话并关闭面板；不新建独立面板，也不将已有面板重绑到其他标签页，详见下述来源删除契约。

Command Palette 只保留页面浮层和独立窗口。普通网页即使地址栏仍持有焦点、网页 `document.hasFocus()` 为 false，也继续创建浮层并明确回复就绪，自动聚焦尽力而为，不因失焦切换承载。Web Store、未开启文件访问等无法注入或创建浮层的页面，由 `paletteLaunch` 使用来源绑定的独立窗口，不配置或打开 action popup，也不以工具栏弹窗中转。点击扩展图标与快捷键共用启动逻辑；异步注入失败后重新核对来源仍活动、窗口及 URL 未变，再交给独立窗口的焦点校验，避免过时请求抢焦点。决策见 [ADR 0019](adr/0019-two-palette-hosts.md)。

后台启动握手必须收到面板的明确 `true` 回复。页面可能只有最近标签切换的轻量监听器；`sendMessage` 没有抛异常，或返回 `undefined`，不能说明面板已安装。需要补注入后再打开浮层。后台启动清除默认与现存标签页的旧 popup 设置，启动请求和页面导航也清除对应标签页设置，恢复图标点击进入统一启动路径；不再写入非空 popup。

## 搜索入口与标签身份一致性

`commands(target)` 为固定／静音生成与目标状态一致的别名：取消动作只在目标已固定／已静音时作为别名提供，不把 `unmute / 取消静音` 引向反向的静音操作。通用声音与拼音关键词仍可发现当前切换动作；主搜索使用来源标签，`actionsFor` 使用所选标签，刷新快照后重建候选和索引，不共享过期的状态别名。

主搜索与主搜索的操作菜单共用 `model.search`：关闭动作接受完整词或明确前缀 `clo / clos / close`、`guan / guanb / guanbi` 和中文「关闭」；仅命中其他词中的片段、关闭动作错字及单独类别名不解锁关闭命令。空搜索首页仍隐藏危险操作；静音切换、恢复关闭标签页与 Session Storage 使用 `searchOnly` 排除，即使有学习权重也不进入首页，搜索与标签页操作菜单的可用动作保持不变。扩展重载的扩展指向也接受 `ext` 起的前缀。所有查询词均须匹配，词序不强制；名称前缀优先于分散的词首，词首优先于词内片段。学习权重仅在同一相关性等级内排序，不能跨越名称、辅助字段或模糊命中的等级。跨语言的部分词、多词换序和有限错字命中，均尽可能显示可解释命中的别名并使用共享高亮。上述变化不改变点击、普通 Enter 与底栏主操作的执行契约。

内置命令通过固定 `aliases` 补充习惯叫法、缩写和已收录错拼，不增加纠错算法或改变相关性等级。白名单与来源见 [使用指南](USAGE.md#命令别名白名单)。`entryPresentation.brandAliases` 共用 `justonehop / just one hop / just-one-hop / joh / 小范围瞬移 / 瞬移`，供产品及设置分类、冒号查询、扩展重载别名和意图判断使用；英文品牌意图按完整词／词组识别，`john`、`johx` 不解锁重载。品牌简称不修改显示名称、命令身份或持久存储键。

所有可见搜索输入的尾部使用同一个 `SearchDismissButton` 显示可点击 `esc`，包括主搜索、设置、Storage、标签组、ActionMenu 以及两种 Tab Switcher。标题／读屏文案明确 Escape 的实际用途（关闭、返回或取消），设置的清空输入按钮保持独立。组件调用 `Navigation.useNavigateBack`，与实体 Esc 使用同一最深活动层判定；下拉或菜单开启时只关闭该层，不能因鼠标先触发外部关闭再退出父页。菜单 Tab 在输入与 Esc 按钮间循环，聚焦按钮后 Enter／Space 只执行返回。没有搜索输入的配置说明／恢复层不强加搜索框。

主搜索、标签组成员和 Tab Switcher 使用 `CurrentTabBadge`，以面板来源 ID 判定当前标签，统一显示「当前 / Current」。共享组件使用与历史时间一致的弱化纯文本样式，去除胶囊背景、边框及徽标内边距；主搜索中位于右侧分类文字之后，不放在分类左侧。所有调用方沿用此样式，身份语义不变。首页推荐排除当前完整 URL，包括同 URL 的其他标签页和书签；不为显示当前标记强行保留来源页。搜索结果不强行加入不匹配的来源标签。后台快照来源 ID 是身份依据，不用临时活动窗口／标签的 active 标志替代。

### 首页推荐（2026-10-18）

空查询直接呈现一组推荐列表，不渲染可见「推荐 / Suggested」标题或为其留白；列表保留本地化的「推荐 / Suggested」无障碍名称。页面与命令混排且最多 10 项。无学习时默认顺序为 Settings、Help、Tab Switcher、Search All History、New Tab、Reload Tab、Pin/Unpin、Local Storage、Cookies；有状态时可加入安全的撤销收起／恢复收起组入口，仍受总数上限约束。关闭等危险命令与 `searchOnly` 项不进入首页。页面候选来自当前窗口标签页及书签，必须有小范围瞬移显式成功选择的有效记录，不以 MRU 或历史预加载补位；完整 URL 去重、排除当前 URL，并优先用当前窗口已打开标签页代表。

首页跨查询汇总频次与衰减权重，含显式空查询；沿用 14 天半衰期、90 天未使用失效、最多 500 条记录。仅首页聚合同 URL 的 `tab:<URL>` 与对应已学习 `bookmark:<id>`，有词搜索的身份及同词同级排序不变。推荐分数在打开面板／来源会话开始时捕获，查询往返、子页返回、新增学习或忘记均不重排当次首页，下次打开再取新分数；关闭／移走页面等真实数据变化仍更新候选。本面板 Settings 全量 Reset 是例外，立即恢复默认首页与排序。无痕首页仅默认入口，隐藏 Search All History，不使用普通窗口习惯，不新增权限，也不增加独立收藏页、隐藏或推荐管理页；收藏动作从搜索或标签页菜单进入。Search All History 在首页仅提供导航，打开空历史搜索页，不预加载历史；有查询时仍沿用原来的独立插入规则，避免重复入口。

首页 Cmd/Ctrl+↑/↓ 跳首尾，不再按分组跳转；打开后立即 Enter 执行第一条推荐，不承诺切回上一页。最近使用顺序由 Tab Switcher 提供。

### 本机学习身份、解释与忘记

`usageTarget` 以 `entry.url` 为标签页与历史生成同一个 `tab:<URL>` 身份，不读取检索用 keywords；完整 URL 保留查询参数与片段差异，历史打开后变为标签页或「已收起」状态均不改变身份。书签沿用独立的 `bookmark:<bookmarkId>`。设置子项各用 `command:settings:<section>`，通用设置沿用 `command:settings`；旧记录不拆分或分摊给子项，仅用于通用设置。其他已接入命令沿用 `command:<action>`。学习范围为普通标签页、浏览历史、书签、浏览器命令、设置与 Storage 入口；帮助、Tab Switcher 导航入口、标签组导航、收起恢复核对和扩展重载未接入。仅显式成功执行写入；主搜索页面选择显式传入空查询 `''` 时也学习，切换器未提供查询的执行不学习，不能把缺省查询自动补为空串。无痕不记录选择；历史 API 读取本身和打开失败均不记录。

主搜索与全部历史子页以 `queryUsage` 读取当前归一化查询的权重，采用同词、同相关性等级内的学习排序；空首页以 `homeUsage` 汇总各查询的权重，再由 `homeRecommendations` 合并页面身份、去重并与命令混排，使用当次会话捕获的分数。`rankingInfo` 对比同批候选的学习顺序与无习惯默认顺序，在截断与插入固定历史入口前判断位置：有有效权重且位置确实前移才标为 promoted，不能仅凭非零权重显示前移。`SearchResultItem` 对有适用学习记录的结果只在右侧显示历史小图标；有快捷键时，图标位于键帽左侧，键帽保持最右侧对齐，不常驻「习惯前移 / Habit boost」「已有记录 / Remembered」文字。有查询时仍限同词、同相关性等级；首页按页面聚合权重解释，Tab Switcher 保留独立 MRU。

`rankingPresentation` 为主搜索与全部历史子页的历史图标提供同一套本地化 tooltip：hover / focus 时只用一句短文说明实际学习前移，或已有记录但本次未前移，再显示对应的删除动作标题；完整删除语义留在使用文档，不在 tooltip 展开。图标同时变为 X，点击直接忘记。无适用记录及未接入学习的结果不显示该图标，也没有忘记动作；首页页面图标使用同 URL 聚合记录。排序原因与忘记操作移出 Actions，右键、底栏 Actions 与 Cmd/Ctrl+K 菜单均不保留冗余解释或动作。

图标是具备可访问名称、tooltip 关联与可见焦点的按钮；键盘选中行的图标可通过 Tab 聚焦，Enter / Space 仅执行忘记，不触发行的主动作。仅当前选中行的图标加入 Tab 顺序，其他行仍可用鼠标点击；鼠标点击图标以所在行为目标，并保留原输入选区。主搜索与全部历史列表还支持 Shift+Backspace 忘记当前选中项，图标与快捷键调用同一删除逻辑、共用可用性和执行中状态。快捷键只接受 Shift+Backspace，拒绝额外 Ctrl / Alt / Meta、`event.repeat`、`isComposing` 或 `keyCode === 229`；无选中项、无适用记录、列表尚不可执行或菜单等更深层开启时不执行。有效触发时阻止默认删字和事件冒泡，不进入普通 Backspace 返回路由；图标的 Enter / Space 同样遵守输入法、重复和额外修饰键保护。

有查询时，忘记只删除归一化 query + target，动作标题为「忘记此搜索词的偏好 / Forget Preference for This Query」；空首页命令删除该 target 的所有 query 记录（含空查询），动作标题为「忘记此命令的偏好 / Forget This Command’s Preferences」；首页页面使用「忘记此页面的偏好 / Forget This Page's Preferences」，一次原子操作删除完整 URL 与同 URL 已学习书签身份在所有查询下的记录，不能按各 target 分次写入。查询归一化与写入一致：去首尾空白、转小写、连续空白合并。历史与标签页共用 query + `tab:<URL>` 偏好，从任一展示忘记均对两者生效。忘记只删除学习记录，不删除页面或书签，也不保存禁学标记；之后成功选择可重新学习。

删除沿用后台 `usageStorage` 的串行读改写队列，与记录和全量重置串行，避免多个面板覆盖彼此的更新；其他面板继续通过现有 storage 事件同步记录及对应图标。删除成功后移除对应图标，执行忘记的当前列表保留原查询、结果顺序、选中身份与滚动位置，并恢复输入焦点与光标／选区；有词搜索的本地保序属于该查询的导航上下文，进入二级页或从二级页返回不得清除；同一会话内只有 query 变化或本面板显式全量 Reset 才解除，返回时仍恢复原顺序、选中身份和滚动位置。首页则保持会话分数与顺序，查询往返或子页返回也不重排，直到下次打开。页面关闭、新历史结果等真实数据变化仍正常更新列表；本面板设置中的全量重置解除本地保序，立即恢复默认排序及首页入口。其他面板同步图标与记录，但当次首页仍保持到下次打开，不新增重置通知。失败保留学习记录，在当前列表反馈错误供重试，不依赖菜单承载。设置中的「搜索排序」说明提供历史图标及 tooltip 的发现路径，保留全量重置，不新增开关或独立记录管理页。

### 面板内 Tab Switcher（2026-10-18）

「JustOneHop: Tab Switcher」在首页及搜索结果常驻说明「Switch tabs like in VS Code」（中英文界面一致），说明与中文别名共同参与检索。右侧复用 `Shortcut` 展示快照从 `chrome.commands.getAll()` 读取的 `switch-recent` 实际绑定，缺失或空绑定时不显示键帽；刷新快照重新读取。设置页接收同一快照字段，显示实际绑定或本地化「未绑定」，title 与 aria-label 展开实际按键；Ctrl+Tab 只作为可选配置。键帽不替换点击／Enter 的子页进入方式；Actions 内仍以 Enter 执行该 UI 导航，不将 Chrome 绑定注册成菜单局部动作。它是首页及中英文主搜索可达的 UI 导航入口，点击、普通 Enter 与底栏主操作在当前 palette host 内打开共享 `RecentSwitcherView`，不启动后台快捷键会话或另开窗口，入口自身不学习。子页搜索初始启用并聚焦，按来源窗口 MRU 展示其他页、来源页置末，可直接筛选标题／URL；仅点击候选、普通 Enter 或底栏「切换」确认，没有松键确认或快速点按展示延迟。未提供学习查询的切换不写搜索记录。

取消、Esc、搜索尾部 esc 与底栏返回共用父面板的 `BackLayer`，只退出子页，恢复主搜索 query、selection、caret／选区与选中项可见位置；不注册第二个 `NavigationRoot`。搜索栏、列表键盘、当前标记、禁用条件、底栏及可用空间沿用共享组件；成功切换关闭面板。原快捷键启动的浮层／独立窗口、松键握手与焦点校验路径保持不变。

## 统一返回路由

`NavigationRoot` 是面板唯一的 Esc 捕获入口。监听器安装在实际承载 UI 的 ownerDocument.defaultView，而非代码运行环境的全局 window；普通网页还覆盖承载 iframe 的父窗口，处理焦点落回宿主时的按键。卸载时移除监听器。页面与菜单不得再各自添加 Esc 按键分支。

`BackLayer` 只登记返回回调，不添加 DOM 容器。优先级由 React 嵌套深度决定，不依赖 effect 的执行或注册顺序。每次 Esc 仅调用最深的活动层：主搜索 → 设置 → Ctrl+Tab 配置指南 → 操作菜单；Storage 列表/详情/菜单、设置下拉框及删除确认同样接入。Command Palette 中只有主搜索层的返回会关闭整个面板，内嵌 Tab Switcher 取消只退回主搜索；快捷键启动的 Tab Switcher 使用 `NavigationRoot` + `BackLayer` 将 Esc 路由到取消回调；启动时在异步初始化前挂载返回路由，加载期间也可取消。

每次独立按键同步提交一次返回，阻止后续冒泡和浏览器默认行为；长按产生的 repeat 不再弹出下一层，输入法组合期间的 Esc 留给输入法。返回回调更新页面状态；从 ActionMenu、详情或重命名、换色等内嵌编辑态返回列表时，页面恢复原搜索词、选中项与保存的光标／选区（`setSelectionRange(...caret.current)`）。
Backspace 也进入同一返回路由，但保留编辑语义：二级页面搜索框标记 `data-back-on-empty`，只有这类搜索框为空，或焦点位于非编辑控件时才返回。搜索框有内容时正常删字；名称、只读内容及其他编辑区域不触发返回。带修饰键、输入法组合和长按重复不触发返回；主搜索层的 Backspace 不关闭面板。面板可能运行在闭合 Shadow DOM + 沙箱 iframe、独立窗口或扩展标签页中，焦点从面板自身的 `getRootNode()` / `ownerDocument` 解析，不能依赖全局 `window` 或被闭合 Shadow DOM 重定向后的事件 target。

`.palette` 与菜单保留 `tabIndex=-1` 以承接鼠标焦点，但 Esc 不依赖这些容器或任何输入框获得焦点。即使焦点位于 iframe body，仍通过同一路由返回。

### 横滑返回

`NavigationRoot` 内的真实 DOM surface 通过 `@use-gesture/react` 的 `useWheel` 监听面板内 wheel；监听目标来自实际承载文档，不挂在宿主全局 window，也不依赖无 DOM 的 `BackLayer`。横滑复用最深活动层的返回回调与上下文恢复：主搜索根层关闭，内嵌 Tab Switcher 返回主搜索，快捷键启动的 Tab Switcher 在网页浮层和独立窗口中均取消关闭，不确认切换。

- 仅返回方向的横滑（`deltaX < 0`，常见 macOS 自然滚动双指右滑）可进入候选；达到距离阈值后显示蓝色箭头，子页、菜单或确认层立即调用最深活动层返回。包含惯性的一次序列最多退一层；返回后继续拦截同一序列的 wheel，静默 140ms 仅用于解锁下一手势，不延迟本次返回。
- 主搜索关闭面板、快捷键启动的 Tab Switcher 取消关闭，以及独立帮助关闭，达到阈值后仍等待 wheel 静默 140ms 才执行，避免承载消失后残余惯性流入来源网页。
- 未达到阈值可通过反向、按键或点击取消；已执行的返回不撤销。键盘、点击或导航层变化取消尚未执行的动作及箭头提示，残余惯性不得重新触发；横滑返回自身造成的层级变化不得解除序列拦截。退出仍恢复原 query、selection、滚动位置与 caret／选区。
- 短滑、纵滑、缩放等不触发。可横向滚动的长文本／输入区域整段避让，即使已到边界也不接管为返回。

wheel 无法可靠识别手指数或真实惯性结束，140ms 静默是启发式；本契约不构成实机原生手势验证结论。不增加权限或持久状态，不实现拖动定位，不改变 [ADR 0010](adr/0010-content-anchor-panel-geometry.md) 的当前定位与暂停目标。决策见 [ADR 0018](adr/0018-wheel-back-navigation.md)。

## 验收边界

除了直接加载 UI 的功能测试，还要从后台真实命令回调驱动全新普通网页的启动，断言浮层存在且未降级、面板水平居中、进入子页面后坐标不变。相关页面需验证菜单开关、选区恢复、配置指南复制与跨页保留、确认取消、较矮窗口底栏可见，以及真实闭合 Shadow DOM/iframe 与 Vimium 组合。

## 候选项呈现

主搜索的 tab、bookmark、history、command统一使用 `SearchResultItem`，全部历史页也复用它。组件根据 Entry 与展示上下文统一处理图标、分类标题、命令别名／说明、高亮、截断、状态徽标、来源和快捷键；`ResultContent` 只负责共享视觉槽，页面保留选择、指针、菜单与执行回调。`HistoryMetadata` 与 `formatVisitTime` 提供统一最近访问时间：刚刚／分钟前／今天或昨天时分／今年月日／往年年月日，按本地日历判断昨天，完整本地时间用于 time 的 title 与无障碍名称，dateTime 使用 ISO。无效或未来时间不显示。主搜索显示来源与时间，历史页省略来源；窄屏仅隐藏有时间的历史来源文字，时间不隐藏。没有后台定时刷新或新增持久状态。Tab Group、Tab Switcher 与 Storage 预览列表保持各自契约。

主搜索与全部历史页的标签页、历史、书签等带 URL 候选由共享 `actionsFor` 提供「复制 URL / Copy URL」，无 URL 的候选不提供此动作；标签组成员页仍使用自己的动作集，不因此获得复制入口。右键、底栏 Actions 与 Cmd/Ctrl+K 使用同一动作集合，主搜索与全部历史页接入同一复制语义。复制读取候选完整 `entry.url`，保留路径、查询参数和片段，不使用截断的说明文字或检索 keywords；不调用导航动作，也不写入学习记录。成功后关闭菜单并保持面板打开，保留 query 与选中身份，恢复输入焦点及原 caret／选区，在现有底栏 status 显示结果；失败反馈错误并允许重试，不冒充导航成功。普通行单击与复制动作分开，拖选保护由共享 `SearchResultItem` 处理。

Entry 的可选 category、shortcut、faviconPageUrl 仅承载呈现信息，不改变命令 ID、存储或后台接口。主搜索命令按 Tab / Storage / JustOneHop Settings / Chrome Pages / JustOneHop 添加本地化前缀；根设置显示为 JustOneHop Settings（中文 小范围瞬移 设置），帮助仍显示为 JustOneHop: Help（中文 小范围瞬移：使用帮助）。具体设置项使用 JustOneHop Settings: Theme／Language（中文 小范围瞬移 设置：主题／语言）等名称，英文使用半角冒号加空格，中文使用全角冒号；只打开并定位控件，不直接修改值。标签页、书签保留网站原始标题。分类参与中英文检索，支持 `JustOneHop Settings: Theme`、`小范围瞬移 设置：主题` 及原有 `Settings: Theme`，沿用严格匹配、命令意图优先和使用习惯排序，不另增分组标题或模式。

右侧键帽由共用 Shortcut 渲染，一个 `<kbd>` 容纳完整快捷键组合（如 `⌘T`、`⌘⇧T`、`⌘↵`、`Ctrl+↵`），Mod 按平台显示 Command 或 Control。仅展示已支持的快捷键；非当前标签页操作不展示浏览器 Close/Reload 快捷键，独立面板中也隐藏这两个快捷键，避免指向错误目标。ActionMenu 使用相同绑定匹配执行动作。`describeShortcut` 将符号和文字组合展开为真实按键名称（如 `Shift + Command + P`），供候选项／菜单键帽的 title 与 aria-label、设置说明及底栏按钮悬浮提示复用；可见键帽保持紧凑，不改变绑定。

标签页、书签与最近标签切换器使用共用 Favicon，读取 Chrome 扩展 `_favicon` 缓存资源；manifest 声明 favicon 权限及网页浮层所需的资源访问。内部页面、加载失败或加载完成前显示现有类型图标，不请求第三方图标服务。快捷键区域不收缩，长标题截断，保持窄窗口下可见。

## 收藏标签页

`bookmarkTabAction` 仅为添加收藏提供 `Mod+D` 元信息，主搜索复用 `Shortcut` 显示 `⌘D`／`Ctrl+D`；取消收藏不展示此绑定。主搜索 `actionsFor` 沿用来源目标判断，仅当前页菜单保留并通过 `ActionMenu` 执行该快捷键，非当前页菜单隐藏；主搜索行的按键提示沿用现有浏览器原生快捷键语义。

主搜索由 `bookmarkTabAction` 为来源标签生成 `bookmarkTab`／`unbookmarkTab`；主列表 `actionsFor` 与标签组成员菜单为所选标签调用同一 helper。标签行默认仍为 `switch`，菜单通过右键、底栏与 Cmd/Ctrl+K 共用目标。动作属于 tab 分类，带书签图标、中英文别名与目标标题说明；两者均为 `searchOnly`，取消标记 `danger`。`model` 区分中性状态查询、明确添加和明确取消：`bookmark / bookmark tab / 收藏 / 收藏标签页` 按当前状态发现收藏或取消动作；收藏后这些 query 直接显示 Unbookmark。`add bookmark / save bookmark / 添加书签` 只表达添加意图，已收藏时呈现不可执行的「已收藏」状态，不暴露删除动作。单独 `book` 至 `bookmark` 的中性前缀与 `unbook` 至 `unbookmark` 的取消前缀也通过意图检查，并将对应书签命令归入最高相关性层级，高于页面同名／前缀匹配及其学习权重；可带 `Tab:`／`标签页：` 分类。过短词、错字、`bookcase` 与 `book guide` 等页面词不触发此提升，裸 `书签` 优先保留书签管理器语义。有词搜索的危险意图检查仅允许中性状态查询及明确的 `unbookmark / remove bookmark / 取消收藏 / 删除书签`；明确添加词、单独 `书签 / tab / close` 或错字不放行取消。明确取消及其前缀在未收藏时不提供添加，空菜单可展示危险动作。

完整原始 URL（含 query/hash）决定收藏状态。执行携带 `tabId`、`expectedUrl` 与全部匹配 `bookmarkIds`，保留 managed 项；组菜单另携带 `groupId`。复用既有 `bookmarks` 权限，创建时不指定 parentId，由 Chrome 默认放入 Other bookmarks，已有精确匹配则不重复创建。共享 URL 策略仅接受 HTTP(S)、file、FTP、chrome，排除脚本与其他不支持的地址。原生书签遵循 Chrome 同步设置，不属于小范围瞬移的本机偏好存储。

单条取消直接执行；多条使用共享 `BookmarkConfirmation`，列出数量、完整 URL 与目录，默认焦点为取消，Tab 在按钮间循环，Esc／取消退出最深 `BackLayer` 并恢复上下文。确认仍保护输入法、长按和额外修饰键。任一匹配受管理时 UI 提示并由后台整批拒绝。后台串行执行书签写入，使用实时树重新核对目标窗口、标签 URL／待导航地址、适用的组归属及确认 ID 集合；集合变化不得扩大删除范围，需刷新核对后重试。删除每项前再次验证，Chrome API 不提供事务，中途失败明确报告部分删除，不宣称已回滚。

书签结果的 `actionsFor` 新增 `removeBookmark` 菜单动作，文案为「取消收藏 / Unbookmark」，保留 `danger`、图标与中英文检索词；右键、底栏 Actions 与 Cmd/Ctrl+K 使用同一动作。普通点击与 Enter 仍打开书签。删除请求以所选 `bookmarkId` 和 `expectedUrl` 为目标，不要求该 URL 存在已打开标签页，不转换为 `unbookmarkTab`，也不展开为同 URL ID 集合。后台沿用串行书签写入和来源校验，从实时树重新核对所选条目、完整 URL 及祖先；条目已不存在、URL 变化或所选条目／祖先受管理时拒绝旧请求。同 URL 的其他项保留，其受管理状态不阻止所选可写条目的删除；不进入标签页的多条确认流程。`unbookmarkTab` 的全部同 URL、任一 managed 整批拒绝及集合变化校验规则不变。

`keepsPaletteOpen` 为收藏／取消标签页收藏与 `removeBookmark` 保留面板；所有成功操作关闭菜单、刷新快照、恢复查询与 caret／选区，并在现有底栏反馈。删除书签结果后按共享选择规则选相邻幸存项。`App` 主搜索收藏成功后设 `selection = null`，避免第二次 Enter 直接执行新出现的取消动作；用户用方向键主动选择或点击结果后继续。菜单收藏保留原标签页选中；失败保留错误并刷新，确认取消不改变列表上下文。书签原生事件使缓存失效并通知面板刷新；执行期间沿用旧请求失效规则。决策见 [ADR 0015](adr/0015-native-tab-bookmarks.md)，实际验证另记验收记录。

## Chrome 内置页面

`chromePages.ts` 定义七个固定目标与各自的执行 ID、中英文别名、标题和单色图标，候选项归入 `chromePages` 分类，显示「Chrome 内置页面 / Chrome Pages」前缀。它们仅在搜索时出现，分类也参与中英文检索和冒号前缀解析；不增加搜索模式或二级列表。精确命令意图沿用主搜索排序，各目标使用独立 `command:<action>` 学习身份。`settings / 设置` 和 `shortcut / 快捷键` 保留小范围瞬移自身设置语义。

后台按执行请求的来源窗口查找目标，精确比较规范化 URL（无路径时视为 `/`），保留子路径、查询参数和片段的差别；已有标签页按活动页优先、标签位置其次选择，执行前重读所属窗口及当前／待导航地址。无匹配则在来源窗口新建，不覆盖网页或跨窗口复用。主搜索和现有扩展快捷键按钮共用该导航函数；原生独立面板沿用来源窗口恢复机制。点击、Enter、底栏与菜单共享成功关闭／失败留在面板的流程。固定地址映射不接受调用方提供任意 URL，不新增权限或读取目标页数据。

## 访问网址（Go to URL）

主搜索从原始 query 生成单个 `navigateAddress` 候选，仅在本轮匹配的 tab／bookmark／history 结果没有相同规范化完整 URL 时插入普通结果之前；去重使用已合并历史的本轮结果，不能仅凭快照中存在该地址就隐藏。协议、路径、query、hash 的区别保留，未匹配结果不参与去重。不进入学习排序或空首页。`addressUrl` 共享解析前端输入与后台目标：接受 HTTP(S)、裸域名、localhost／IP 和端口；裸域名默认 HTTPS，localhost／回环默认 HTTP，显式协议优先。拒绝空白、控制字符、反斜线、凭据、无效主机及其他协议，使用 URL 标准规范化并保留路径、query、hash 的语义。地址解析不处理普通搜索词；Google 候选按下节独立生成，不新增在线联想或权限。

候选复用 SearchResultItem，标题「访问网址 / Go to URL」、说明为规范化完整地址。单击、普通 Enter 与底栏主操作「当前页打开」同义；`addressActions` 为底栏次要操作及共享 ActionMenu 提供 `openAddressNewTab`，macOS 绑定 Mod+Enter，Windows/Linux 绑定 Alt+Enter。地址与 Google 搜索候选允许这项修饰键 Enter，不扩展到普通标签页、书签、历史或命令；输入法、repeat、额外修饰键和聚焦按钮的保护继续适用。菜单支持中英文检索，关闭恢复主搜索 query／selection／caret；窄屏新开按钮使用 PaletteFooter 已有 compact-icon 契约，保留 tooltip 和可访问名称。固定来源页禁用主动作并提示，菜单与新开操作仍可用。其他候选的默认动作不变。

地址候选携带来源 `tabId` 与 `expectedUrl`，原始输入变化期间沿用历史查询的最多 100ms 提交门控，旧结果不可执行。后台对两种动作均核对真实 sender／独立面板映射后的来源 ID、窗口与活动状态，执行层再次读取来源 URL／pendingUrl 并验证规范化 HTTP(S) 目标。原地导航拒绝固定来源页；新开明确指定来源窗口、active=true，不复用同 URL 页。成功提交后关闭面板，失败保留输入并反馈，来源失效不改绑其他页；两种动作不写本机学习。不改变承载和定位。决策见 [ADR 0020](adr/0020-open-in-browser.md)。

## 在 Google 搜索

非空主搜索生成一个「在 Google 搜索『词』 / Search Google for “…”」候选，支持中英文，不要求前缀，空首页不生成。普通查询将其放在本地匹配之后，无本地匹配时置首且在「搜索全部历史」之前；地址查询保留地址优先与既有去重，Google 后置。明确的 `google <词>`、`search google <词>`、`search in google <词>`、`谷歌搜索 <词>`、`在 Google 搜索 <词>` 去掉前缀，以剩余词生成标题与目标并置顶。本地匹配间的相关性和学习排序不变；截断时预留 Google 位置，包含地址、Google 与历史入口的列表仍最多 100 行。全部候选沿用最多 100ms 的同批提交，输入变化后旧结果不可执行。

在本地构造 `https://www.google.com/search?q=` 加编码后的查询，复用 `navigateAddress`／`openAddressNewTab`，不增加后台动作。行点击、普通 Enter 与底栏主操作导航来源页；macOS Cmd+Enter、其他平台 Alt+Enter 及底栏／ActionMenu 新开动作在来源窗口新开并激活。固定来源页只允许新开。共享来源校验、执行中状态、键盘保护、菜单返回上下文和成功关闭／失败保留输入契约，不改变承载或定位。只有显式执行才发起网络导航，输入及候选生成不请求 Google；无在线联想、新权限、持久状态或学习写入。决策见 [ADR 0021](adr/0021-google-search.md)，补充 0020 的搜索与修饰键适用范围。

## 浏览历史搜索

主搜索通过独立 `search-history` 消息按关键词查询最近一周，不把历史加入快照或持久缓存。UI 对整个请求设置 100ms 等待预算，当前输入与提交结果分别管理：等待期间旧结果不可执行，新结果或超时统一提交，迟到响应、旧查询和已卸载页面不得提交。输入与返回始终可用。主搜索与全部历史子页均遵守相关性分级，同词同等级内先比较学习权重，再按来源与历史访问时间排序；共用结果右侧历史图标、hover / focus 的排序与删除范围 tooltip、变为 X 后点击忘记，以及 Tab 聚焦后 Enter / Space 和 Shift+Backspace 的忘记操作（保护条件见「本机学习身份、解释与忘记」）。仅对历史与已匹配标签页／书签的同 URL 去重，保留路径、查询参数与片段差别。

明确的 `history / search history / search all history / 历史 / 历史记录 / 搜索历史` 意图将「搜索全部历史」置顶，进入子页时清空子页搜索框而保留主搜索上下文；普通关键词携带原词进入。有关键词且非无痕窗口时，普通查询的「搜索全部历史」在排序后固定插入第 7 条，不足 6 条则跟随已有结果，无本地匹配时位于 Google 之后，整体仍最多 100 行并为 Google 保留位置。入口不参与相关性或使用习惯排序，说明区分完成无匹配、超时、失败及结果达到上限。与其他候选同批呈现，点击／Enter／底栏同义，右键菜单也使用共享动作。

`HistoryView` 是全部时间的关键词搜索子页，复用 `.search-bar`、`.results`、40px 候选行、`Favicon`、`HighlightedText`、`PaletteFooter`、`ActionMenu`、`BackLayer` 与 `SearchDismissButton`。没有独立标题栏，底栏标题「历史」，context「全部时间」；空关键词提示输入，不读取整个历史库。加载提示延迟 150ms，15 秒无结果提供重试；搜索与返回保持可用，返回主搜索恢复关键词、选择、滚动与光标。普通行单击、Enter、底栏主操作与菜单「打开页面」均在来源窗口新标签页打开；拖选文字后松开鼠标不打开。结果行复用主搜索的 `SearchResultItem` 手势保护；菜单同时提供「复制 URL」，遵守完整地址复制、不导航、不写学习及成功后恢复 query／selection／caret 的共享契约。两种查询最多返回 100 个匹配 URL，达到上限须提示，不能把全部时间称作全部结果。

安装权限新增 `history`，后台验证调用者和来源窗口，无痕来源不读取普通历史、不记录选择，仅返回并打开 HTTP(S) URL，不调用历史写入接口。显式选择成功打开后，以 query + 完整 URL 写入既有本机学习存储，仅保存选择及衰减权重／时间，不持久复制整个浏览历史；历史 API 读取本身和打开失败不记录。沿用 500 条上限、90 天未使用失效及 14 天权重减半的规则。原 `openHistory` 命令继续跳转 Chrome 原生历史页。决策见 [ADR 0014](adr/0014-history-search.md)。

## 扩展重新加载

`reloadExtension` 使用现有分类呈现机制：`category: 'justonehop'` 与动作名称分别提供，统一生成 `JustOneHop: Reload`／`小范围瞬移：重新加载`，不把扩展名称拼入动作标题；分类参与搜索并支持中英文冒号。该命令无标签页目标和专属快捷键；空输入不展示，查询须包含 JustOneHop／小范围瞬移／extension／扩展指向，单独 reload／刷新继续表达标签页刷新。沿用主搜索的点击、Enter、底栏和菜单执行路径及输入法／修饰键保护，不新增权限。

后台经过现有消息来源、面板来源和窗口校验后，先枚举标签页完成预检并确认接收请求，再关闭自身 popup.html／switcher.html 页面，向普通页发送 `close-for-reload` 并等待已注入浮层清理，最后调用 `chrome.runtime.reload()`。内容脚本仅接受自身扩展发送的关闭消息；未注入页面无接收者属于正常情况。显式清理避免 runtime 失效后旧浮层残留，不依赖固定延时等待响应；重载命令不写使用记录。普通网页不刷新、关闭或重新创建，已保存本机数据保留。重载完成后用户重新唤起面板，命令不构建源码。

## 响应速度与缓存边界

后台按需缓存扁平化书签及正在进行的读取，创建、修改、删除、移动、子项重排和导入完成时失效。读取过程中发生变化时丢弃旧树并跟随最新读取。缓存仅在内存中，后台重启后重新获取；标签页状态和快捷键每次仍实时读取，避免快速 Enter 操作过期的目标。

主搜索与操作菜单复用同一候选数组的归一化字段和 Fuse 索引（包含归一化后的中英文别名），候选数据或语言改变时重建。同等级与使用权重下，命令比较能覆盖全部查询词的最短名称／别名，再使用 Fuse 分数，避免别名数量放大排名。有限英文错字候选中，完整单词命令匹配优先于长名称中的局部词匹配；两者均低于字面命中。主题、语言和排序的自然说法只定位设置控件，执行语义不变。有词排序按当前查询和候选数据计算，忘记后保留当前列表直到查询改变；首页使用当次来源会话捕获的推荐分数，查询往返、子页返回及学习更新均保序，下次打开刷新，本地设置 Reset 立即恢复默认。真实数据变化仍正常处理，不建立跨次打开的排名缓存。高亮组件只在文本或查询改变时重算，方向键选择无需重复计算所有行的高亮。

执行函数的可选 onPerformed 回调在 Chrome 操作成功后通知仍存在的面板，页面按操作意图决定关闭或刷新；执行 Promise 仍等待后台串行写完使用记录。来源页实际被删除时直接结束当前会话，不等待使用记录写入，也不创建或重绑面板来接收完成反馈。失败操作不提前回应，不记录使用；调用页面消失也不阻断后台写入。

### 整理操作与来源删除

`paletteActions.keepsPaletteOpen` 将收藏／取消收藏、删除所选书签、关闭非来源页（含未删除来源的批量关闭）、固定、静音、分组更新／移出组与撤销收起归为保留面板；非来源页的刷新和收起也保留。来源页实际删除的终止规则优先于整理操作的保留规则，不得仅凭关闭命令名或所选目标判定保留。切换、打开与恢复内容属于导航，成功后关闭；来源页刷新／收起仍退出。鼠标、Enter、底栏与菜单使用同一执行路径。完成保留面板的整理后先关闭菜单，再刷新快照并恢复搜索焦点／选区，状态反馈替换底栏 context；失败且来源仍存在时保留错误供重试。

主搜索与标签组通过 `useResultSelection` 保持选中身份，消失时优先原结果顺序中的下一个幸存项，再找上一项；后台重排不能把仍存在的选择换成首项。主搜索收藏成功后使用显式无选择状态，更新快照或移动鼠标不自动重新选中；方向键、查询修改、点击或右键明确指定结果后继续。输入法、重复 Enter 与修饰键 Enter 仍不执行。主搜索与标签组共享执行中状态，返回仍可用，但返回主搜索不会允许重叠操作。执行期间暂停通知触发的快照读取，并废弃此前未完成读取；成功整理或执行失败后都重新读取，首次加载的重试也走同一版本检查，防止旧来源或旧列表覆盖完成后的结果。操作已成功但刷新失败时明确提示已完成，避免误导重复执行。

source 是本次唤起绑定的来源标签页，网页浮层与已有独立面板遵循同一生命周期：任何来源页实际被删除都结束当前小范围瞬移会话，包括直接 close、对其他目标执行批量关闭时连带删除来源，以及 Chrome 外部关闭。来源窗口关闭或最后一页删除同样结束；批量操作即使部分失败，只要来源已删除就不得保留会话。仅关闭非来源页时继续保留搜索上下文。来源删除后绝不创建接续 popup、复用或重绑已有独立面板，也不迁移搜索状态到 Chrome 接替的活动页；迟到响应不得重新打开或恢复已结束面板。让 Chrome 自然选中的相邻页接回焦点，用户需要时重新唤起小范围瞬移。

旧 continuation 底层已移除，兼容入口不再接续会话：旧 `Execution.paletteState` 字段接受但忽略，`palette-state` 返回 `undefined`，`cancel-palette-continuation` 为 no-op；均不保存、读取或恢复接续状态，不创建、重绑或聚焦窗口。窗口会话仍保存 token、source 与 popupId，用于正常独立面板的身份及来源校验，不包含接续状态；后台 wrapper 仍负责关闭操作的来源验证。窗口承载、系统标题栏、现有几何估算及暂停中的屏幕定位目标均不改变。当前决策见 [ADR 0016](adr/0016-source-close-ends-palette.md)；[ADR 0012](adr/0012-continuous-tab-management.md) 保留历史理由，其中来源关闭后接续部分已被替代。

最近标签切换的受管窗口使用后台握手携带的已排序标签列表，不再重复查询；独立打开的兜底窗口仍自行读取。松键、焦点丢失、目标关闭或跨窗口移动的校验保持不变。

性能基准使用合成数据与隔离 Chrome 配置：`./node_modules/.bin/tsx tests/search-benchmark.ts` 测量搜索算法；`npm run test:e2e -- --grep 'English performance'` 验证重复打开、慢存储下的及时响应、大书签库及最近标签窗口的重复查询。耗时用于同环境比较，不能当作所有机器的时延保证。

主面板首次等待快照时，150ms 后仍未返回才显示 Loading（包括读屏状态提示）；结果到达或读取失败立即取消计时，重试重新计时，卸载清理定时器。搜索框始终可输入，已有结果的后台刷新保留列表。快速切换浮层的蒙层与面板也共用 150ms 延迟展示，确认中取消展示，快速操作直接完成，切换不等待视觉延迟；避免白屏或蒙层闪烁。延迟展示本身不引入快照缓存、消息接口或存储结构。

## 列表与设置键盘一致性

设置保留 56px 顶部区域，复用搜索图标、输入胶囊和聚焦样式，提供「搜索设置」输入框。`settingsSearch.ts` 从两份语言包的名称、说明、分区名和别名建立本地索引，不区分大小写、空白分词后按 AND 字面匹配；空输入展示全部，未命中行不渲染，空分区隐藏，文字使用 `HighlightedText` 且关闭拼写容错，与筛选语义一致。无结果显示状态和清空按钮，清空后聚焦输入框。普通进入聚焦搜索，主搜索直达仍聚焦指定控件；Tab / Shift+Tab 按 DOM 顺序只遍历可见控件，搜索框的 Enter 不执行设置操作。搜索输入标记 `data-back-on-empty`，沿用统一 Esc / Backspace 返回路由。Ctrl+Tab 配置指南返回设置时保留筛选词并恢复原入口焦点和可见位置。使用共享 PaletteFooter 在底部左侧显示返回按钮与 Settings／设置标题，正文按「通用（General）」「键盘（Keyboard）」「实验性功能（Experimental Features）」分为三个独立纯白圆角模块卡片，卡片上方为带 14px 单色图标的弱化模块标题，卡片内部各项以独立设置行与轻分隔线上下排列：语言与主题共用通用卡片，名称／说明在左，等宽选择框在右，极窄空间允许换行；键盘卡片两行左侧以纯文案陈述功能名称与作用，右侧统一以单个 `<kbd>` 键帽（面板与 Tab Switcher 均读取 Chrome 实际绑定，未绑定显示本地化「未绑定」；title 与 aria-label 展开当前按键名称）加动作按钮呈现；自动收起和搜索排序共用实验性功能卡片，说明简短且允许换行；自动收起说明须公开关闭开关也会移出仍受管理的手动收起页面，不为保持单行而省略此范围，设置页正文操作按钮借鉴 Chromium WebUI `cr-button` 的视觉语言，按紧凑面板适配为 32px 高、100px 胶囊圆角、12px 横向内边距、透明底与主题色文字，500 字重；hover／active 使用轻量状态底色，保留共用焦点轮廓与禁用态。下拉框使用 160px 宽、32px 高、8px 圆角的透明底矩形字段，内侧焦点轮廓；菜单间隔 4px、圆角 8px，选项最小高度 32px，13px 字号与触发器一致，选中项通过勾选与 500 字重标识，键盘／鼠标高亮使用柔和蓝色。展开方向按实际菜单内容高度与正文剩余空间选择，空间不足时菜单内部滚动。正文上下留白 8px／12px、水平 16px，卡片内侧水平 12px，行上下 8px、最小高度 48px；模块标题上方 12px（首模块为 0）、下方 4px；说明可换行，窄屏控件换行后靠右；开关以 32px 点击区域承载 26×16px 轨道，关闭／开启分别使用 8px／12px 滑块，两种状态都有 hover／active 反馈。返回与清空继续使用紧凑图标按钮。这些是本项目对 Chrome 外观的适配，不等同于直接使用 Chrome 私有 WebUI 控件。各控件保留独立标签和原搜索直达焦点，分区不引入额外模式或折叠层。设置行统一使用「Tab Switcher」术语，Ctrl+Tab 说明明确通过一次性配置片段设置 VSCode 风格的最近标签切换；自动收起标题使用「Auto Tuck Tabs / 自动收起标签页」，具体闲置触发条件留在说明中。设置名称没有点击动作时使用普通指针，只有关联开关的 `label[for]` 保留手形；键帽 title 与 aria-label 展开实际按键名称和用途，面板快捷键跟随 Chrome 实际绑定，Ctrl+Tab 配置入口不声称已绑定。设置底栏标题后以 `context` 固定显示 `Tab 下一个 · Shift+Tab 上一个`（英文 `Tab Next · Shift+Tab Previous`），常用 Tab 在前，每组按键与动作靠近、组间以圆点分隔；设置标题与提示沿用共用留白规则，不使用页面特例或添加竖线，悬浮说明向前／向后移动控件焦点，与列表的选择提示区分；全项目统一一个 `kbd` 对应一个快捷键组合，沿用弱化无框样式。窄屏仍保留这条设置提示。

主搜索从任意二级页面返回、标签组从编辑或菜单返回时，使原选中项重新进入视口。设置下拉框支持 Ctrl+N/P，Esc 关闭后保留触发控件焦点。根面板 Tab 遍历排除 inert、禁用及 tabIndex 为负的控件，弹层背后的输入框不参与焦点循环。

快捷键启动的 Tab Switcher 默认禁用输入框并聚焦列表，通过搜索图标按钮、输入区域外层 `pointerdown` 或标准 Ctrl/Cmd+F 显式启用搜索，暂停本次会话的修饰键松开确认；初始列表聚焦不触发此状态。进入搜索后可松开启动修饰键正常输入，用普通 Enter、行点击或底栏主操作确认；再次点击搜索图标或按 Ctrl/Cmd+F 都恢复输入焦点。独立窗口加载期间的导航按原始按键语义与重复启动步骤依次缓冲，列表挂载后按实际可见高度重放翻页，再处理已缓冲的松键。`recentSearch.ts` 在本次会话的来源窗口候选内按标题／URL 筛选：不区分大小写，空白分词后按 AND 匹配，保留 MRU。查询变化保留仍可见的选中标签，否则选首项；选中标签被关闭或移走时，仅在源页仍可见时回退到源页，否则保持无选择，直到导航、点击或修改查询。无匹配或无选择时，Enter、松键与底栏主操作均不激活标签页。输入框控制列表，↑/↓、Ctrl+P/N、Tab / Shift+Tab 循环选择，PageUp/PageDown 或 Alt+↑/↓ 翻页，Ctrl/Cmd+↑/↓ 跳首尾，选中项滚动到可见区域。所有带修饰键、重复、输入法组合或 `keyCode === 229` 的 Enter 均不执行；普通 Enter 确认当前选择，未进入搜索时松开启动修饰键也可确认。

## Ctrl+Tab 配置指南

`BindingGuide` 独立承载只读 Ctrl+Tab 配置说明，由设置页「键盘 → Tab Switcher」与 `popup.html#binding` 复用；主搜索以仅搜索可见的 `settings:binding` 入口（标题使用 `bindCtrlTab`，别名含 Ctrl+Tab／bind Ctrl+Tab／设置 Ctrl+Tab）打开 Settings 并聚焦配置控件。它不依赖脚本收藏、已保存脚本或 UserScript 执行接口，不提供创建、编辑、删除或运行任意代码的入口。脚本收藏、运行选择和执行结果页面及相应搜索、设置入口、执行接口与 `userScripts` 权限已移除，决策见 [ADR 0017](adr/0017-remove-script-library.md)。

指南复用 `PaletteFooter`、`ActionMenu` 与 `BackLayer`，没有独立标题栏或搜索框。进入时聚焦底栏「复制并打开」主操作，点击与普通 Enter 共用先复制、成功后打开 Chrome 快捷键页的流程；菜单提供单独「复制代码」和「打开 Chrome 快捷键页」，沿用搜索高亮、Ctrl+N/P、Tab 焦点约束及逐层返回。复制反馈显示在底栏 status；复制失败留在原页，返回或卸载后忽略旧复制请求的后续导航。带修饰键、长按重复及输入法组合的 Enter 不触发主操作。

配置代码为填入当前扩展 ID 的一行命令，一次设置正反向绑定，仍须用户在 Chrome 快捷键页 Console 显式粘贴执行，扩展不代为运行。普通网页浮层通过 host 提供的 `BindingNavigation` 在指南挂载期间暂停隐藏销毁，保留原 Settings／配置上下文，允许反复切走和切回；返回设置或卸载指南时恢复正常规则。持久标签页直接保留；`#window=` 独立面板在跳转前，由后台在来源窗口创建或复用非激活的 `popup.html#binding` 说明标签页，避免失焦销毁说明。菜单单独打开快捷键页沿用相同策略。返回设置恢复筛选词、入口焦点与可见位置，指南例外不改变其他页面的生命周期或定位。

## 内置使用帮助

主搜索移除常驻的空搜索启动提示。`HelpView` 的「打开与搜索」章节继续显示 Chrome 实际绑定及 `describeShortcut` 展开的按键名称，未绑定显示本地化说明；动态内容也参与帮助搜索。不新增首次使用状态、轮换提示或导览步骤。

`HelpView` 是随构建打包的只读文档。帮助正文必须区分关闭非来源页后继续整理与来源删除后结束会话；明确涵盖直接关闭、批量操作连带删除与 Chrome 外部关闭来源页，不能笼统承诺「关闭后面板保持打开」。设置通用分区最后一项和主搜索 `help / 帮助 / 使用说明` 在当前面板内打开帮助；工具栏菜单在调用窗口中新建 `help.html` 标签页，每次均新建，不复用已有帮助页。独立页复用同一 HelpView、共享控件及现有主题／语言偏好，不依赖网站访问授权、网络或新增存储。内嵌帮助沿用父页面返回上下文；独立帮助页的退出语义是关闭自身标签页，不进入主搜索或关闭调用窗口。独立文档页保持共享 750px 宽度上限，外边距 24px（窄屏 10px），高度随标签页视口变化、上限 900px，正文内部滚动；这是文档标签页的布局，不适用紧凑面板的 516px 高度，也不接入面板定位。

帮助顶部复用共享搜索胶囊，打开时聚焦搜索输入。`helpSearch.ts` 按两份语言包的章节标题和正文做大小写无关、空白分词 AND 匹配，保留命中章节的完整内容；可见命中使用 HighlightedText，关闭拼写容错。空输入展示全文，无结果提供清空按钮；查询变化重置正文滚动。筛选时帮助正文顶部为 8px，首个可见章节 h2 不叠加上边距。正文以 article 承载章节并独立滚动，聚焦后显式处理无修饰键的方向键、PageUp / PageDown 和 Home / End 阅读，输入法组合期间不拦截。Tab / Shift+Tab 遍历搜索、适用的清空按钮、Esc、正文和底栏操作并循环。

两种承载均复用 `SearchDismissButton`、`PaletteFooter` 与统一返回路由。内嵌帮助通过 BackLayer 返回父页面，恢复搜索、选择与焦点。独立帮助的关闭控件使用「关闭帮助 / Close Help」标签，底栏提供显式关闭操作；点击关闭、搜索尾部 Esc、实体 Esc 或空搜索框中的 Backspace 均关闭帮助标签页。清空与退出分离，搜索框有内容时 Backspace 保留编辑语义；输入法、修饰键与长按保护沿用共享契约。设置入口参与设置中英文筛选和高亮；主搜索帮助入口也在空搜索展示。空搜索遵循单组「推荐」契约；JustOneHop Settings、JustOneHop: Help 是冷启动前两项，学习后的混排不保证其永久置顶，帮助入口本身不学习。有查询时按相关性和同级学习排序，不套用首页优先顺序。

### 扩展图标菜单与绑定刷新

`chrome.contextMenus` 只注册两个 `contexts: ['action']` 项：本地化的「打开小范围瞬移：实际快捷键 · 修改快捷键 / Open JustOneHop: actual shortcut · Change shortcut」和「使用帮助 / Help」。Chrome 决定菜单的呈现和分组；不向网页、选择文字或链接菜单添加入口。快捷键项点击后使用已有 Chrome 页面导航逻辑，在调用窗口复用精确匹配的 `chrome://extensions/shortcuts` 标签页，无匹配时新建；帮助项始终在调用窗口新建扩展自带的 `help.html`。本次仅新增 `contextMenus` 权限。

后台在 service worker 初始化、安装／启动、标签页激活、窗口聚焦、快捷键页更新、面板快照读取及语言变更时，通过 `chrome.commands.getAll()` 刷新实际绑定和菜单文案。刷新使用事件触发，不增加轮询或存储。Chrome 不提供 `contextMenus.onShown` 或命令绑定变更事件，不能保证每次右键前都重新读取：在同一标签页改键后立即右键，菜单可能显示旧绑定。用户切换标签页或打开小范围瞬移后，再重新打开菜单可读取更新后的文案。不将事件刷新描述为即时订阅，也不据此宣称已完成原生菜单验收。决策见 [ADR 0013](adr/0013-toolbar-help-and-shortcuts.md)。

## 技术栈与权限分工

- React + TypeScript；Fuse.js 做中英文模糊搜索，Lucide 图标，esbuild 构建。
- 语言包在 `public/_locales/`：manifest 使用 Chrome 原生 i18n，面板复用相同文案并优先读取手动语言选择；`en` 是默认回退语言。构建时将 `zh_CN` 复制为 `zh_TW`，共用一份中文文案。
- 页面内容脚本使用隔离的 Shadow DOM 和原生 modal dialog，在浏览器 top layer 中显示；内部空白沙箱框架隔离键盘事件，兼容 Vimium 的字母快捷键和 Esc。框架不加载外部页面或执行脚本，UI 仍由原内容脚本渲染。
- Service worker 负责读取浏览器状态和执行命令。每次执行会重新核对标签页所属窗口、当前位置与固定 / 静音状态。
- `activeTab`、`scripting`：仅用户唤起时注入命令面板。
- `tabs`：读取标签页标题、URL、状态并执行标签管理。
- `contextMenus`：仅向扩展图标的 `action` 菜单添加快捷键修改与帮助入口；菜单外观和分组由 Chrome 控制，不增加网站访问权限。
- `bookmarks`：读取原生书签供搜索；用户显式收藏／取消收藏标签页时创建或删除精确 URL 的书签，从书签结果取消收藏时只删除所选 `bookmarkId`。复用既有权限，原生书签同步由 Chrome 设置控制。
- `sessions`：恢复最近关闭内容。
- `cookies`：读取 Cookie，包含 HttpOnly；不增删或修改 Cookie。
- `content_scripts.matches`：普通 HTTP(S) 页面及其匹配子框架预加载轻量修饰键监听，只在内存保存 Control/Alt/Meta 状态，按需转发松键；不记录输入文字、不拦截网页快捷键、不上传数据。未增加全站 `host_permissions`，Cookie 仍逐站授权。
- `optional_host_permissions`：声明可按需申请 HTTP(S) 网站权限；首次查看 Cookies 时只请求授权页列出的具体域名，不预先授予所有网站访问权。
- `offscreen`：本地 `theme.html` 以 `MATCH_MEDIA` 监听系统深浅色，经校验来源的消息调用 `chrome.action.setIcon`。不跟随面板强制主题，不读取网站，不发起网络请求或保存主题状态；后台重启及窗口聚焦重新同步，复用 `alarms` 每 30 秒检查作为离屏媒体事件不送达的兜底（Chrome 可延后调度）；创建失败保留默认浅色图标并在后续窗口聚焦或闹钟时重试。无法读取 Chrome 自定义工具栏颜色，见 ADR 0023。
- `storage`：仅在本机保存语言、主题偏好及搜索选择记录，不使用云端同步。搜索记录最多 500 条，90 天未使用的记录不再参与排序，并在下次记录时清理；频次权重每 14 天减半，让新习惯逐渐取代旧习惯。

## 标签组

当前窗口的原生组进入统一搜索，显示 `Tab Group: 名称 · 数量`（中文为「标签组」）；成员标签页显示组名和颜色，组名参与搜索但不改变标签页的使用记录身份。进入组管理页后继续搜索成员，鼠标或 Enter 切换，Ctrl+N/P 和方向键选择。底栏与 Cmd+K 共用切换、关闭、移出组、展开/折叠、重命名、颜色操作；重命名和颜色编辑属于下一层，Esc/非输入状态 Backspace 每次仅返回一层。

快照增加当前窗口组信息和标签页 groupId；执行接口增加 updateGroup、ungroupTab，使用已有 tabGroups 权限。执行前核对窗口与成员归属，拒绝对已移组的候选项执行旧操作。组被外部删除或移出窗口时显示已不可用，仍可返回搜索；不自动认领同名组。

在小范围瞬移内修改受管理的 Tucked Away 名称或颜色，会在串行生命周期队列内同步预期状态及恢复记录，后续新增成员不覆盖自定义名称/颜色。Chrome 外部的手动改名/换色仍沿用保守规则，停止自动管理。组置顶不在本次范围内。


## 鼠标与键盘混用（2026-10-16）

Command Palette、标签组管理页（`TabGroupView`）、页面存储列表（`StorageView`）及收起恢复页（`TuckRecoveryView`）的候选项右键均直接打开该项的共享操作菜单，选中项与菜单目标同时更新；关闭菜单恢复原列表焦点，有搜索框时恢复搜索词与选区，继续支持 Ctrl+N/P。与底栏和 Cmd+K 使用相同动作集合、图标、中英跨语言关键词及危险操作红色提示。`StorageView` 单击候选项只选择并更新右侧只读 value 预览，悬停不改变选择；普通 Enter 或底栏「复制值」复制原始字符串，双击或从操作菜单进入详情。

收起恢复核对保留成员详情卡片，点击卡片以及卡片／列表的普通 Enter 均只选择候选组，不接管、不将焦点隐式转移至确认按钮；底栏或菜单的「继续管理这组」才显式确认。Tab／Shift+Tab 必须能从列表到达底栏确认与菜单入口，聚焦确认按钮后 Enter／Space 才执行接管；无有效候选时确认禁用。底栏显示返回、恢复核对层名与记录名称，菜单开启时返回仅关闭菜单。此页不强加搜索框或压成 40px 单行，需让用户核对成员；无候选时焦点落在底栏返回控件，停止恢复仅删除记录的行为保持不变。后台确认后保留候选组现有名称与颜色，并记录为受管理组的预期状态，后续收起不得覆盖为默认标题或灰色；仍按最新指纹检查确认目标。

自动收起设置关闭时停止自动检查，并将所有仍确认受管理的成员移回普通标签栏，包括手动收起的页面；待恢复候选组不受影响。此范围必须在设置说明与使用帮助中可见，不把开关解释为仅停止定时器或仅恢复自动收起的成员。

Tab Switcher 的确认和取消提示是可点击按钮，聚焦按钮后 Enter 遵循按钮自身行为；列表普通 Enter 确认当前选择；仅快捷键启动且未进入搜索时，松开修饰键同样确认。鼠标悬停用独立描边提示可点击，不改变键盘选择，避免指针偶然停在列表上改变松键目标；点击行直接切换。长标题可悬停查看完整标题。空快捷键不显示多余分隔符。

面板视觉尺寸：Command Palette 与 Tab Switcher 的内容矩形均以 750×516 为上限，独立窗口按来源标签页内容区估算锚点并校准自身边框，外框尺寸另含系统标题栏与边框，详见[位置与浏览器承载方式](#位置与浏览器承载方式)。两者共用 56px 高的搜索栏与输入胶囊；常规横向内边距 24px，窄屏 18px，输入字体 14.5px，候选行 40px，列表内边距为 4px 8px 8px。切换器候选标题与 URL 使用 `.entry-copy` 同行布局，溢出省略，底栏复用 `PaletteFooter` 的背景、44px 高度与按钮样式。新增或修改二级页面时按本文的通用契约与对应组件章节核对，验证范围按 [测试指南](TESTING.md) 选择。
