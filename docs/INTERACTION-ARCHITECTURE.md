# JustOneHop · 交互架构与组件规范

本文档定义小范围瞬移（JustOneHop）的交互架构、设计契约与组件行为规范。所有视图、组件的新增与重构均以此为权威核对依据。设计取舍与演进决策见 [ADR 索引](adr/README.md)，用户操作流程见 [使用指南](USAGE.md)。

---

## 1. 核心设计原则

- **Human First（人本优先）**：鼠标操作、标准快捷键以及两者之间的任意交替，均为完整且平权的使用路径。任何功能均不得要求用户记忆隐晦前缀或模式组合。
- **Local & Honest（本地与诚实）**：无服务端、无用户账号、无遥测上报；权限严格按需最小化。命名忠于真实行为（例如「收起」仅移入原生折叠组，绝不关闭或 discard 页面；外部改名即停止自动接管；危险操作提供明确警示与二次确认）。
- **Chrome Native（原生融合）**：复用 Chrome 原生能力（Tab Groups、`_favicon`、`sessions`）。视觉严格遵循 Chrome CR2023 设计语言：安静的单色圆角图标槽、内嵌胶囊搜索框、柔和蓝色选中态、统一排版层次与协调比例。

## 2. 承载模型与几何规范 <a id="位置与浏览器承载方式"></a>

### 2.1 双承载模型

| 承载类型 | 适用环境 | 实现机制与交互边界 |
| :--- | :--- | :--- |
| **网页浮层 (Content Overlay)** | 普通 HTTP(S) 网页 | 通过隔离的 **Shadow DOM + 空白沙箱 iframe** 挂载至宿主顶层（Top Layer）。完全隔绝宿主页面样式与按键监听（兼容 Vimium）。页面导航或关闭时由宿主清理。 |
| **独立窗口 (Standalone Window)** | Chrome 原生受保护页（`chrome://`、Web Store、DevTools 等）及地址栏激活场景 | 通过 `chrome.windows.create` 创建无工具栏、无地址栏的紧凑独立弹出窗口。跨应用切换时保留会话；退出规则见下文。 |

- **暂停与继续**：命令面板及其二级视图在切换应用或窗口被遮挡时保留搜索词、选择和当前视图，不主动抢焦点；返回可继续操作。
- **会话结束**：显式退出、执行跳转、切走来源标签页、来源页导航或关闭时结束面板。网页浮层的快捷键配置指南允许跨标签查看，离开指南后恢复普通规则。
- **独立窗口外部交互**：在 Chrome 内将焦点从面板移到浏览器窗口仍关闭；从其他应用返回来源窗口的焦点交接保留面板，不自动激活它。
- **快捷切换器例外**：快捷键启动的 Tab Switcher 仍在失焦或页面隐藏时取消，避免恢复焦点后误执行松键确认。

### 2.2 几何与视口契约 <a id="紧凑面板的整体比例"></a>

- **尺寸上限**：面板内容矩形统一以 **`750px × 516px`** 为尺寸上限。
- **网页浮层居中**：在宿主视口内保持水平居中，视口较窄时自适应缩放为 `min(750, viewport.width - 48)`。
- **独立窗口锚定**：独立窗口通过 `nativePanelBounds` 估算来源标签页内容区几何，并校准系统标题栏与边框差值，保证在原生页弹出时视觉定位与网页浮层一致。
- **子视图禁止私设几何**：所有二级页面、操作菜单与确认层均严格填满面板可用空间，禁止自行改变面板外框尺寸。

### 2.3 性能与加载感知 <a id="响应速度与缓存边界"></a>

- **无感加载阈值**：异步读取标签页、历史或书签快照时，仅在等待时间超过 **150ms** 后才呈现 Loading 状态（含读屏提示），快操作严禁闪烁空白或加载圈。
- **输入无阻断**：后台快照尚未就绪期间，键盘输入框必须保持响应，用户输入的按键不得丢失。

## 3. 全局键盘与指针交互模型

### 3.1 输入法 (IME) 与按键防护

- **输入法合成保护**：在 `isComposing` 为真或 `keyCode === 229` 期间，Enter、Escape、Backspace 等按键全权留给输入法候选，禁止触发面板内的执行、返回、清空或切换操作。
- **修饰键与长按保护**：
  - 单次普通 Enter 触发列表主动作。
  - 带有修饰键（如 Shift / Alt）或长按连击 (`event.repeat`) 的 Enter 严禁触发列表主动作。
  - 编辑输入框内的 Enter 保留编辑语义，不向外层列表冒泡。

### 3.2 指针与文本选区契约

- **指针坐标防抖**：采用悬停高亮的列表，其 `onMouseMove` 必须比对物理屏幕坐标（`screenX / screenY`）。当用户使用键盘快速滚动列表时，静止的指针绝对不得抢占选中项。
- **原生文本拖选保护**：
  - 搜索结果（`SearchResultItem`）中的标题、说明、URL 等文本支持原生鼠标拖动选择复制。
  - 用户拖选文本后松开鼠标，严禁触发行点击主动作、页面跳转或写入搜索学习权重。
  - 单纯的左键单击仍正常执行主动作；未发生文本选区拖拽时不得强行要求双击。
- **悬停与选中解耦**：
  - **Storage 列表**：鼠标悬停不改变选中项，亦不切换右侧预览，保证阅读稳定。
  - **Tab Switcher**：鼠标悬停仅展示可点击外框反馈，绝对不修改松开修饰键时的确认目标。

### 3.3 搜索焦点生命周期与恢复契约

- **失焦感知与引导**：监听双级 window focus/blur。当 Chrome 地址栏持有焦点导致网页无法接收按键时，搜索框呈现「点击搜索框开始输入」引导文案。
- **双重焦点恢复机制**：
  1. **Logo 聚焦按钮 (`SearchFocusButton`)**：搜索框左侧 Logo 作为可点击按钮。点击或聚焦后按 Enter / Space 立即恢复搜索框输入焦点，完整保留已输入的 Query、光标位置与选区。
  2. **无焦点按 Tab 恢复**：当面板内没有有效控件持有焦点时，按普通 Tab 键自动恢复输入框焦点（搜索框右侧动态显示「按 Tab 聚焦搜索框」提示）；当已有控件（如按钮、列表）聚焦时，严格遵循原生 Tab 顺序跳转，不作拦截。

## 4. 统一导航与返回路由体系 <a id="统一返回路由"></a>

### 4.1 统一 Esc 捕获中心

- 全局仅由 `NavigationRoot` 在宿主 owner window 统一安装单点 Esc 捕获监听，并在卸载时安全移除。
- 严禁各业务视图、二级页面或弹层各自绑定全局 Esc 监听。

### 4.2 分层返回堆栈 (`BackLayer`)

基于 React 树嵌套深度自动管理返回堆栈，每次 Esc 仅调用**最深层的活动层**，执行严格的逐级返回：

```
操作菜单 (ActionMenu) / 确认弹层 (Confirmation)
  └── 行内编辑状态 (Inline Edit)
        └── 二级视图 (Storage / Groups / History / Settings / Help / Guide)
              └── 主搜索框清空 Query / 关闭面板 (Dismiss)
```

- **Backspace 返回**：仅当输入框完全为空且未处于文本编辑状态时，按 Backspace 退回上一层；严禁直接越级跳回主搜索。
- **横滑手势返回 (Swipe Back)**：在面板左侧边缘向右拖拽触发逐级返回，具备位移阈值防误触与渐进式视觉展开反馈。

### 4.3 上下文与选区无损保持

- 从二级页面、操作菜单或编辑状态返回父级时，必须完整恢复：
  1. 离开前的搜索 Query 与输入框光标/选区。
  2. 离开前列表所选的项标识（ID）。
  3. 选中项重新进入视口：自动调用 `scrollIntoView({ block: 'nearest' })`。
- 绝不允许返回后丢失上下文或强制重置滚动条至顶部。

## 5. 共享核心组件契约

### 5.1 搜索栏 (`SearchBar`)

- **布局结构**：`Logo 聚焦按钮` + `胶囊搜索输入框` + `尾部 SearchDismissButton (esc 徽标)`。
- **输入胶囊**：获得焦点时呈现柔和蓝色外框。尾部提供可点击的 `esc` 按钮，点击即清空或关闭面板。
- **检索高亮 (`HighlightedText`)**：
  - 命中词采用纯粗体（字重 600）强调，直接继承所在文本的颜色。
  - 背景完全透明，无内边距，严禁使用彩色背景色块切断文字。
  - 严格关闭浏览器的拼写纠错。

### 5.2 候选列表与条目 (`SearchResultItem`) <a id="候选项呈现"></a>

- **结构规范**：
  - **图标槽**：32px 无框圆角矩形槽（浅色模式 `#f1f3f4`，深色模式 `#35363a`），内嵌 16px 单色类型图标。
  - **文本区域**：主标题 + 副标题/URL/说明，超出部分优雅截断。
  - **状态徽标**：当前活动标签页固定展示「当前 / Current」单色胶囊徽标。
  - **快捷键槽**：右侧展示规范键帽。
- **选中视觉**：选中行采用柔和蓝色背景（浅色模式 `#e8f0fe`，深色模式 `#394457`），左侧圆角槽呈现主题色强调。
- **键盘遍历契约**：
  - **单步移动**：`↑` / `↓` 以及 `Ctrl+P` / `Ctrl+N`（无其他修饰键）。
  - **翻页浏览**：`PageUp` / `PageDown` 以及 `Option+↑` / `Option+↓`。
  - **首尾跳转**：`Cmd+↑` / `Cmd+↓` (macOS) 或 `Ctrl+↑` / `Ctrl+↓` (Windows/Linux)。
  - 选中项变更后统一调用 `scrollIntoView({ block: 'nearest' })`。

### 5.3 统一底栏 (`PaletteFooter`) <a id="面板布局与操作组件"></a>

底栏固定高度（44px）、不可伸缩，是面板所有操作与状态反馈的唯一聚集地。**严禁各业务视图在正文滚动区域底部另设主提交按钮**。

```
+-----------------------------------------------------------------------------------+
| [导航/返回] [位置标题] [上下文/状态]                 [主操作 ↵] [次操作] | [Actions ⌘K] |
+-----------------------------------------------------------------------------------+
```

- **左侧槽位**：
  - `navigation`：唯一的 26px 单色图标按钮（返回或设置）。`mousedown` 阶段阻止冒泡，避免外部点击先关弹层后误退父页。
  - `title`：只读的位置名称（如 `Settings`、`Tab Groups`）。
  - `context`：只读补充信息（如来源域名、组内成员数量），与标题保持 16px 外边距。
  - `status`：短暂操作状态反馈（出现时临时替换 `context`，不新增独立槽位）。
- **右侧槽位**：
  - `primary`：主操作按钮（文字在前、键帽在后，500 字重）。若操作具破坏性，标明 `danger: true` 并显示红色。
  - `secondary`：可选的次要操作按钮，规则与主操作对齐。
  - `actions`：操作菜单开关（`Actions ⌘K`），前面带分隔线；无菜单时不加分隔线。
- **按钮激活防护**：底栏按钮仅响应普通 Enter / Space 激活；输入法组合态、按键连击重复或带有额外修饰键时严禁触发。

### 5.4 统一操作菜单 (`ActionMenu`)

- **唤起途径**：
  1. 列表条目上点击鼠标右键（`onContextMenu`）。
  2. 点击底栏的 `Actions` 按钮。
  3. 按下快捷键 `Cmd+K` (macOS) 或 `Ctrl+K` (Windows/Linux)。
- **呼出行为规范**：
  - 呼出时自动将对应列表条目设为当前选中项，并记录原输入框光标位置。
  - 焦点立即限制在菜单内，支持方向键、`Ctrl+P/N` 导航及输入关键词快速过滤菜单项。
  - **与底栏联动**：菜单打开期间，底栏 `PaletteFooter.primary` 的文案、键帽与危险态实时跟随当前菜单中高亮的动作更新。
- **关闭与退出**：按 Esc 或点击外部关闭菜单后，焦点安全返回原列表项，完整恢复原 Query 和选区。

## 6. 核心视图交互规范

### 6.1 主命令面板 (Omni Palette) <a id="整理操作与来源删除"></a> <a id="收藏标签页"></a>

- **空状态呈现**：直接呈现跨查询综合推荐列表（包含基于 14 天半衰期衰减的使用权重），不渲染多余的占位标题留白。
- **统一候选归一**：单主搜索框融合 标签页 (Tab)、书签 (Bookmark)、历史记录 (History)、系统命令 (Command)、直达网址 (URL) 与 Google 搜索。
- **排序与执行法则**：
  - 精确字面匹配优先级高于错拼或别名；命令与内置动作具备中英文别名匹配支持。
  - 默认单击或 Enter 执行主动作（跳转标签页、在当前页打开网址/书签）；次要操作支持新标签页打开。
- **学习机制与忘记**：学习权重仅在同相关性等级内微调，绝不跨越类别等级；支持通过 ActionMenu 显式选择「忘记 / Forget」单项清除该项的学习历史。

### 6.2 最近标签页切换器 (Tab Switcher)

- **快捷键模式（Hold & Release）**：
  - 按住启动修饰键并连续按按键单步选择条目。
  - 面板与蒙层延后 **150ms** 显示（快速松开直接切页，完全不闪烁面板）。
  - 松开修饰键直接确认切换至当前选中标签页。
- **搜索模式过渡**：
  - 点击搜索按钮或外层指针交互即可激活搜索胶囊，无缝转入列表搜索模式。
  - 一旦进入搜索模式，立即取消松键自动确认语义，改为标准 Enter 或点击确认。
- **悬停保护**：指针悬停在条目上仅呈现点击描边，绝对不修改松开修饰键时的确认目标，彻底规避鼠标指针误停导致的目标漂移。

### 6.3 标签组管理 (Tab Groups)

- **组层级列表**：展示组名、原生颜色徽标与成员标签数量。单击或 Enter 进入成员详情页。
- **组级管理动作**：
  - **展开 / 折叠**：切换 Chrome 原生标签组折叠状态。
  - **重命名**：就地触发单行文本编辑，保存或取消均保留当前选中项与列表滚动位置。
  - **解散分组 (Ungroup)**：移除分组容器，完整保留组内所有标签页在标签栏中。
  - **关闭整组 (Close Group)**：必须弹出共享确认层（`GroupConfirmation`），显示组名与真实成员数；执行前重新核对窗口与固定标签状态，跳过固定标签页。
- **成员详情二级页**：展示组内全部标签页，支持直接切换、移出分组与单页关闭；Esc 或底栏返回安全回到组列表。

### 6.4 页面存储管理 (Storage View)

- **双栏交互结构**：左侧为只读 Key / Cookie 列表，右侧为只读原始 Value 预览区。
- **明确的操作语义分工**：
  - **单击候选项**：仅更新当前选择并刷新右侧预览，绝不执行复制或页面跳转。
  - **鼠标悬停**：不改变选择、不改变右侧预览，保证用户阅读与比对长内容时的绝对稳定性。
  - **普通 Enter / 底栏「复制值」**：将当前项的原始字符串写入系统剪贴板。
  - **双击条目 / ActionMenu**：进入存储详情查看弹窗。

### 6.5 设置面板 (Settings View)

- **内嵌设置搜索**：顶部区域复用统一搜索胶囊，对设置项标题、说明与别名执行 AND 分词过滤，空结果提供快速清空按钮。
- **紧凑面板整体比例**：
  - 正文按钮、下拉选择框与开关控件统一保持 **32px** 高度。
  - 基础设置行高 **48px**，正文水平边距 **16px**，卡片内边距 **12px**，文字与键帽严格垂直居中。
- **自动收起 (Tucked Away)**：
  - 开启后在当前卡片展开收起时长分档（1/3/12 小时、1/3/7 天）与当前运行状态。
  - 关闭设置时立即停止后台检查，并将受管理的全部成员标签安全移回普通标签栏。

### 6.6 内置帮助与配置指南 (Help & Guide) <a id="内置使用帮助"></a> <a id="ctrltab-配置指南"></a>

- **使用帮助 (`HelpView`)**：随构建打包的只读文档，顶部提供全文搜索胶囊，支持章节内容与正文即时高亮匹配。
- **Ctrl+Tab 配置指南 (`BindingGuide`)**：
  - 独立只读说明页，展示为当前扩展 ID 生成的单行配置指令。
  - 底栏提供一键复制命令，明确引导用户在 Chrome 快捷键设置控制台中显式粘贴执行。
  - 严禁提供任何可运行任意不受信代码的入口。

## 7. 契约核对清单

任何新增功能或修改 UI 的 PR，必须对照以下契约清单逐项核对：

| 核对维度 | 必查契约规范 |
| :--- | :--- |
| **输入法与按键** | `isComposing` 与 `keyCode === 229` 期间无任何功能响应；Enter 长按重复或带修饰键不触发主动作。 |
| **鼠标与指针** | 列表 `onMouseMove` 具备屏幕物理坐标防抖；结果行支持文字拖选且松开不触发动作。 |
| **焦点与 Tab** | 面板无焦点时按 Tab 能恢复搜索框焦点；搜索框左侧 Logo 点击能恢复焦点；已有控件聚焦时不拦截 Tab 链。 |
| **返回与路由** | Esc 仅由 `NavigationRoot` 统管；通过 `BackLayer` 逐级退出；返回父级后原 Query、光标、选中项与视口滚动完整恢复。 |
| **底栏与菜单** | 仅使用统一 `PaletteFooter`，无正文底独立按钮；`ActionMenu` 当前高亮与底栏主动作及危险态实时同步。 |
