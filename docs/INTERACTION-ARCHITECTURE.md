# 面板布局与操作组件

内部标识统一使用 zing：消息 source、runtime port 名称、注入标记、DOM/ARIA ID、CSS 类和动画名与产品名一致。偏好、脚本和排序记录继续使用原存储键，无需数据迁移。浏览器测试配置使用 ZING_CHROMIUM_PATH、ZING_VIMIUM_PATH。

主搜索、脚本新建和编辑共用同一套操作呈现，避免每个功能各自添加底部按钮。此边界基于已经存在的页面和行为；不引入全局命令注册器或路由框架。

- `PaletteFooter` 渲染固定高度、不可收缩的底栏。页面提供左侧内容/状态、主操作（标签、键帽、可用性、回调）以及操作菜单开关。业务页面不能在滚动正文末尾另放主要提交按钮。
- `ActionMenu` 渲染统一操作面板，负责焦点、方向键与 Ctrl+N/P、翻页、首尾跳转、Enter 执行、Cmd/Ctrl+K 切换和菜单内 Tab 焦点限制；通过 BackLayer 登记 Esc 返回。页面提供过滤后的动作、查询、选中项与回调；主搜索保留现有搜索排序算法，编辑器使用简单动作筛选。
- 页面保留自己的业务状态、执行/保存逻辑及退出菜单后的编辑焦点。编辑器只记住真实表单字段，忽略复制代码时创建的临时 textarea，避免复制后光标丢失。
- 脚本编辑的主操作为保存：macOS `Cmd+Enter`，其他平台 `Ctrl+Enter`。普通 Enter 保持表单/代码编辑语义。复制、删除从 Cmd/Ctrl+K 进入，删除仍经默认聚焦取消的确认框。
- 主搜索、脚本编辑、脚本执行结果与 Storage 列表/详情共用 PaletteFooter 和 ActionMenu。Storage 保留自己的数据读取与复制逻辑，菜单统一提供高亮、键盘导航、滚动和焦点行为；设置按其页面语义保留现有操作区。

## 位置与浏览器承载方式

位置由 `content.tsx` 和 `.zing-app.overlay` / `.palette` 统一控制；子页面不能决定自己是右上角弹窗还是居中浮层。普通网页为内容区水平居中、偏上的浮层，新建/编辑切换时沿用相同坐标。

Chrome 内置页等禁止注入的页面使用原生 action popup。该窗口位置由 Chrome 决定，不能通过页面 CSS 改成网页中央。

后台启动握手必须收到面板的明确 `true` 回复。页面可能只有最近标签切换的轻量监听器；`sendMessage` 没有抛异常，或返回 `undefined`，不能说明面板已安装。需要补注入后再打开浮层。成功打开应清除旧的每标签页 popup 设置，恢复工具栏的正常启动路径。

## 统一返回路由

`NavigationRoot` 是面板唯一的 Esc 捕获入口。监听器安装在实际承载 UI 的 ownerDocument.defaultView，而非代码运行环境的全局 window；普通网页还覆盖承载 iframe 的父窗口，处理焦点落回宿主时的按键。卸载时移除监听器。页面与菜单不得再各自添加 Esc 按键分支。

`BackLayer` 只登记返回回调，不添加 DOM 容器。优先级由 React 嵌套深度决定，不依赖 effect 的执行或注册顺序。每次 Esc 仅调用最深的活动层：主搜索 → 设置 → 脚本管理 → 编辑 → 操作菜单；Storage 列表/详情/菜单、脚本选择/执行结果、设置下拉框及删除确认同样接入。主搜索是唯一关闭整个面板的返回层。

每次独立按键同步提交一次返回，阻止后续冒泡和浏览器默认行为；长按产生的 repeat 不再弹出下一层，输入法组合期间的 Esc 留给输入法。返回回调更新页面状态，页面自身恢复搜索词、选中项和编辑光标。执行中的脚本返回选择列表后，旧请求可能继续运行，但不得覆盖新页面或触发自动复制。

Backspace 也进入同一返回路由，但保留编辑语义：只有显式标记 `data-back-on-empty` 的搜索框为空，或焦点位于非编辑控件时才返回。搜索框有内容时正常删字；名称、代码、执行结果及其他编辑区域不触发返回。带修饰键、输入法组合和长按重复不触发返回；主搜索层的 Backspace 不关闭面板。焦点从面板自己的 Document/ShadowRoot 解析，不能依赖被闭合 Shadow DOM 重定向后的 window 事件 target。

`.palette` 与菜单保留 `tabIndex=-1` 以承接鼠标焦点，但 Esc 不依赖这些容器或任何输入框获得焦点。即使焦点位于 iframe body，仍通过同一路由返回。

## 验收边界

除了直接加载 UI 的功能测试，还要从后台真实命令回调驱动全新普通网页的启动，断言浮层存在且未降级、面板水平居中、进入子页面后坐标不变。编辑器需验证菜单开关、选区恢复、普通 Enter 换行、保存快捷键、删除取消、较矮窗口底栏可见，以及真实闭合 Shadow DOM/iframe 与 Vimium 组合。

## 候选项呈现

Entry 的可选 category、shortcut、faviconPageUrl 仅承载呈现信息，不改变命令 ID、存储或后台接口。主搜索命令按 Tab / Script / Storage / Settings 添加本地化前缀，自建脚本归入 Script；根设置项避免显示重复前缀。标签页、书签保留网站原始标题。分类参与中英文检索，支持 `Script: new`，沿用严格匹配、命令意图优先和使用习惯排序，不另增分组标题或模式。

右侧键帽由共用 Shortcut 渲染，Mod 按平台显示 Command 或 Control。仅展示已支持的快捷键；非当前标签页操作不展示浏览器 Close/Reload 快捷键，原生 popup 中也隐藏这两个快捷键，避免指向错误目标。ActionMenu 使用相同绑定匹配执行动作，编辑器 Save 保留 Cmd/Ctrl+Enter。

标签页、书签与最近标签切换器使用共用 Favicon，读取 Chrome 扩展 `_favicon` 缓存资源；manifest 声明 favicon 权限及网页浮层所需的资源访问。内部页面、加载失败或加载完成前显示现有类型图标，不请求第三方图标服务。快捷键区域不收缩，长标题截断，保持窄窗口下可见。

## 响应速度与缓存边界

后台按需缓存扁平化书签及正在进行的读取，创建、修改、删除、移动、子项重排和导入完成时失效。读取过程中发生变化时丢弃旧树并跟随最新读取。缓存仅在内存中，后台重启后重新获取；标签页状态和快捷键每次仍实时读取，避免快速 Enter 操作过期的目标。

主搜索与操作菜单复用同一候选数组的归一化字段和 Fuse 索引，候选数据或语言改变时重建。排序继续实时使用当前查询和使用记录，不缓存排名结果。高亮组件只在文本或查询改变时重算，方向键选择无需重复计算所有行的高亮。

执行函数的可选 onPerformed 回调在 Chrome 操作成功后通知面板关闭；执行 Promise 仍等待后台串行写完使用记录。失败操作不提前回应，不记录使用；调用页面消失也不阻断后台写入。该内部接口已获用户确认，对外消息和存储结构不变。

最近标签切换的受管窗口使用后台握手携带的已排序标签列表，不再重复查询；独立打开的兜底窗口仍自行读取。松键、焦点丢失、目标关闭或跨窗口移动的校验保持不变。

性能基准使用合成数据与隔离 Chrome 配置：`./node_modules/.bin/tsx tests/search-benchmark.ts` 测量搜索算法；`npm run test:e2e -- --grep 'English performance'` 验证重复打开、慢存储下的及时响应、大书签库及最近标签窗口的重复查询。耗时用于同环境比较，不能当作所有机器的时延保证。

主面板首次等待快照时，150ms 后仍未返回才显示 Loading（包括读屏状态提示）；结果到达或读取失败立即取消计时，重试重新计时，卸载清理定时器。搜索框始终可输入，已有结果的后台刷新保留列表。本次只调整加载提示，不新增快照缓存、消息接口或存储结构。

## 列表与设置键盘一致性

脚本管理和脚本运行选择列表使用普通 Enter 确认；带修饰键、长按重复及输入法组合不触发编辑/执行。Ctrl+N/P 仅在无其他修饰键时导航，不吞掉 Shift 选区操作；设置下拉框同样支持 Ctrl+N/P，Esc 关闭后保留触发控件焦点。

脚本管理和运行选择页的搜索框固定可见，列表独立滚动；脚本管理的键盘选中项自动滚动到可见区域，编辑返回时保留查询、候选项与搜索选区；鼠标进入编辑也同步选中项。根面板 Tab 遍历排除 inert、禁用及 tabIndex 为负的控件，弹层背后的输入框不参与焦点循环。

## 脚本执行结果操作

成功结果以「复制结果」为底栏主操作，失败以「重新运行」为主操作；Cmd/Ctrl+K 菜单列出当前可用的复制与重新运行动作，底栏跟随菜单选中项。执行中禁用主操作和菜单，重复 Enter 或带修饰键 Enter 不再次执行。正文仅保留结果、执行状态、错误说明及权限引导；复制反馈位于固定底栏上方，失败以 alert 提示并保留结果以便重试。

菜单统一使用搜索高亮、Ctrl+N/P、Tab 焦点约束和 BackLayer 返回。关闭菜单恢复原控件及结果文本选区；执行完成聚焦底栏主操作，结果文本仍支持原生选中/复制。重新运行保留既有运行模式（包括自动复制），执行与复制回调校验当前运行版本；返回选择页后的旧结果不得覆盖界面或自动复制。结果仍只存当前面板，后台接口、权限与存储结构不变。
