# JustOneHop · 交互架构与组件规范

本文档定义小范围瞬移（JustOneHop）的交互架构、设计契约与组件行为规范。所有视图、组件的新增与重构均以此为权威核对依据。设计取舍与演进决策见 [ADR 索引](adr/README.md)，用户操作流程见 [使用指南](USAGE.zh-CN.md) · [User Guide](USAGE.md)。

---

## 1. 核心设计原则

- **Human First（人本优先）**：鼠标操作、标准快捷键以及两者之间的任意交替，均为完整且平权的使用路径。任何功能均不得要求用户记忆隐晦前缀或模式组合。
- **操作必有反馈**：每次用户操作都必须有可感知、与真实结果一致的反馈，让用户知道操作是否被接收、是否完成以及结果是什么；反馈强度与操作影响匹配，不打断连续操作。具体契约见 §5.5。
- **Chrome Native（原生融合）**：复用 Chrome 原生能力（Tab Groups、`_favicon`、`sessions`）。视觉遵循 Chrome CR2023 设计语言：安静的单色圆角图标槽、柔和蓝色选中态、统一排版层次与协调比例。具有检索功能的区域使用内嵌胶囊搜索框；页面顶部按任务选择搜索或导航，不以输入框外观装饰普通标题。

## 2. 承载模型与几何规范 <a id="位置与浏览器承载方式"></a>

### 2.1 双承载模型

| 承载类型 | 适用环境 | 实现机制与交互边界 |
| :--- | :--- | :--- |
| **网页浮层 (Content Overlay)** | 普通 HTTP(S) 网页 | 通过隔离的 **Shadow DOM + 空白沙箱 iframe** 挂载至宿主顶层（Top Layer）。完全隔绝宿主页面样式与按键监听（兼容 Vimium）。页面导航或关闭时由宿主清理。 |
| **独立窗口 (Standalone Window)** | Chrome 原生受保护页（`chrome://`、Web Store、DevTools 等）及地址栏激活场景 | 通过 `chrome.windows.create` 创建无工具栏、无地址栏的紧凑独立弹出窗口。跨应用切换时保留会话；退出规则见下文。 |

- **背景与层次**：网页 Command Palette 与 Tab Switcher 均不压暗宿主页面，以面板边框与阴影区分层次，避免打开与关闭时整页亮度跳变；透明背景仍隔离页面交互，点击面板外关闭浮层。
- **暂停与继续**：命令面板及其二级视图在切换应用或窗口被遮挡时保留搜索词、选择和当前视图，不主动抢焦点；返回可继续操作。
- **会话结束**：显式退出、执行跳转、切走来源标签页、来源页导航或关闭时结束面板。网页浮层的快捷键配置指南允许跨标签查看；Hop Badge 编辑页在整个编辑期间也允许反复切换标签，保留会话和未保存草稿，返回来源标签可继续编辑；重新进入编辑页后同样适用，无需再次点击外部链接。离开相应任务页后恢复普通规则。
- **独立窗口外部交互**：在 Chrome 内将焦点从面板移到浏览器窗口仍关闭；从其他应用返回来源窗口的焦点交接保留面板，不自动激活它。
- **快捷切换器例外**：快捷键启动的 Tab Switcher 仍在失焦或页面隐藏时取消，避免恢复焦点后误执行松键确认。来源网页正在保留跨标签编辑任务时，Tab Switcher 使用独立窗口，不替换原任务浮层；确认、取消及反复启动均保留原任务和草稿。

### 2.2 几何与视口契约 <a id="紧凑面板的整体比例"></a>

- **尺寸上限**：两种承载的面板内容矩形统一以 **`750px × 516px`（CSS 像素）** 为上限，随来源标签页视口缩小并适配页面缩放；独立窗口的系统标题栏与边框另计。
- **网页浮层锚定**：相对网页视口水平居中、偏上显示，窄视口保留可用边距。
- **独立窗口锚定**：内容矩形相对来源浏览器窗口外框水平居中，顶部留白从该窗口顶部计算；命令面板与 Tab Switcher 遵守同一规则。
- **定位边界**：两种承载各有锚点，不要求屏幕坐标重合，也不固定在显示器屏幕中心。侧栏等浏览器布局改变视口时，浮层位置随视口适配。
- **子视图禁止私设几何**：所有二级页面、操作菜单与确认层均严格填满面板可用空间，禁止自行改变面板外框尺寸。

### 2.3 性能与加载感知 <a id="响应速度与缓存边界"></a>

- **无感加载阈值**：异步读取标签页、历史或书签快照时，仅在等待时间超过 **150ms** 后才呈现 Loading 状态（含读屏提示），快操作严禁闪烁空白或加载圈。
- **输入无阻断**：后台快照尚未就绪期间，键盘输入框必须保持响应，用户输入的按键不得丢失。

## 3. 全局键盘与指针交互模型

### 3.1 输入法 (IME) 与按键防护

- **输入法合成保护**：在 `isComposing` 为真或 `keyCode === 229` 期间，Enter、Escape、Backspace 等按键全权留给输入法候选，禁止触发面板内的执行、返回、清空或切换操作。
- **修饰键与长按保护**：
  - 单次普通 Enter 触发列表主动作。
  - 带有修饰键（如 Shift / Alt）或长按连击 (`event.repeat`) 的 Enter 严禁触发列表主动作。
  - 编辑输入框内的 Enter 保留编辑语义，不向外层列表冒泡。

### 3.2 指针与文本选区契约

- **指针坐标防抖**：采用悬停高亮的列表，其 `onMouseMove` 必须比对物理屏幕坐标（`screenX / screenY`）。当用户使用键盘快速滚动列表时，静止的指针绝对不得抢占选中项。
- **原生文本拖选保护**：
  - 搜索结果（`SearchResultItem`）中的标题、说明、URL 等文本支持原生鼠标拖动选择复制。
  - 用户拖选文本后松开鼠标，严禁触发行点击主动作、页面跳转或写入搜索学习权重。
  - 单纯的左键单击仍正常执行主动作；未发生文本选区拖拽时不得强行要求双击。
- **悬停与选中解耦**：
  - **Storage 列表**：鼠标悬停不改变选中项，亦不切换右侧预览，保证阅读稳定。
  - **Tab Switcher**：鼠标悬停仅展示可点击外框反馈，绝对不修改松开修饰键时的确认目标。

### 3.3 搜索焦点生命周期与恢复契约

以下搜索焦点规则仅适用于当前活动视图具有搜索入口的情况。无搜索的表单页进入时聚焦首个可编辑字段；单步任务页聚焦可用主操作，纯阅读页聚焦可访问的内容区域。Tab／Shift+Tab 遍历当前视图可用控件，不将焦点送回被覆盖的父级搜索框，也不展示搜索聚焦提示。

- **失焦感知与引导**：监听双级 window focus/blur。当 Chrome 地址栏持有焦点导致网页无法接收按键时，搜索框呈现「点击搜索框开始输入」引导文案；引导与输入文字、占位文字和退出按钮各占独立空间，窄屏可截断文案但不可重叠。
- **双重焦点恢复机制**：
  1. **Logo 聚焦按钮 (`SearchFocusButton`)**：主搜索与没有父页的独立帮助窗口，搜索框左侧 Logo 用于聚焦。点击或聚焦后按 Enter / Space 立即恢复搜索框输入焦点，完整保留已输入的 Query、光标位置与选区。有父页的普通二级搜索页（设置、历史、存储、标签组与帮助）统一使用旋转徽章逐级返回；需要输入时直接点击搜索框。
  2. **无焦点按 Tab 恢复**：当面板内没有有效控件持有焦点时，按普通 Tab 键自动恢复输入框焦点（搜索框右侧动态显示「按 Tab 聚焦搜索框」提示）；当已有控件（如按钮、列表）聚焦时，遵循 Tab 顺序跳转；唯一补全例外见 §5.1，Shift+Tab 始终保留反向焦点导航。

## 4. 统一导航与返回路由体系 <a id="统一返回路由"></a>

### 4.1 统一 Esc 捕获中心

- 全局仅由 `NavigationRoot` 在宿主 owner window 统一安装单点 Esc 捕获监听，并在卸载时安全移除。
- 严禁各业务视图、二级页面或弹层各自绑定全局 Esc 监听。

### 4.2 分层返回堆栈 (`BackLayer`)

基于 React 树嵌套深度自动管理返回堆栈，每次 Esc 仅调用**最深层的活动层**，执行严格的逐级返回：

```
操作菜单 (ActionMenu) / 确认弹层 (Confirmation)
  └── 行内编辑状态 (Inline Edit)
        └── 二级视图 (Storage / Groups / History / Settings / Help / Guide)
              └── 主搜索框清空 Query / 关闭面板 (Dismiss)
```

- **Backspace 返回**：仅当输入框完全为空且未处于文本编辑状态时，按 Backspace 退回上一层；严禁直接越级跳回主搜索。
- **横滑手势返回 (Swipe Back)**：在面板左侧边缘向右拖拽触发逐级返回，具备位移阈值防误触与渐进式视觉展开反馈。

### 4.3 上下文与选区无损保持

- 从二级页面、操作菜单或编辑状态返回父级时，必须完整恢复：
  1. 离开前的搜索 Query 与输入框光标/选区。
  2. 离开前列表所选的项标识（ID）。
  3. 选中项重新进入视口：自动调用 `scrollIntoView({ block: 'nearest' })`。
- 绝不允许返回后丢失上下文或强制重置滚动条至顶部。

## 5. 共享核心组件契约

### 5.1 页面顶部与搜索栏 (`SearchBar`)

- **顶部按任务选择**：Header 是页面顶部区域，不必是输入框。主搜索、设置框架、历史等具有检索需求的视图使用搜索栏；独立的编辑、导入、配置引导和无检索需求的详情视图使用轻量导航区，不强加搜索框。有父页的普通二级页面，以顺时针旋转 90° 的瞬移徽章作为顶部返回入口，底栏不重复放置同义返回按钮。
- **搜索型页面**：顶部保留真实搜索入口，遵守下列搜索栏契约；不在搜索框上方叠加标题栏，位置名称沿用底栏。设置、历史、存储列表、标签组列表与面板内帮助的搜索左侧徽章旋转 90° 表达返回语义，点击或 Enter／Space 退出最深活动层。进入二级页时徽章从正向旋转至 90°，返回首页时从 90° 转回正向；默认与自定义徽章一致，减少动态效果时直接呈现最终朝向。没有父页的独立帮助窗口保留聚焦图标与明确关闭入口；Tab Switcher 的图标仍用于启用搜索，沿用专用返回／取消路径。
- **独立任务／详情型页面**：标签组重命名、配置指南、恢复核对和存储详情等有父级的任务在左上角提供顺时针旋转 90° 的瞬移徽章，具备「返回」名称及 Esc 提示，响应最深活动层的返回；底栏不重复放置同义返回按钮。顶部无需占满整条胶囊，也不为不存在的搜索保留占位提示或搜索蓝框。独立根页面不显示虚假的返回入口，保留明确的关闭路径。
- **正文层次**：页面标题、简短说明、预览与表单属于正文；简单单步任务可居中呈现，多字段编辑和长内容采用便于扫描的对齐方式。预览图形可以放大，但实际大小预览须明确标注。普通标题、预览和说明不使用输入框外观；真实字段应有独立标签。
- **共享内容尺度**：设置分类及子页、帮助、配置指南、恢复核对、存储预览与详情的正文四周留白统一为 **16px**，窄屏保持同一尺度；内容卡片内部留白与相邻模块间距为 **12px**，卡片圆角 **12px**。设置项标题 **14px**，说明正文 **13px**、行高约 **1.55**；检查时间等次级信息可用 **12px**。列表沿用紧凑结果行契约，代码值保留等宽排版，不因正文统一而改变搜索、结果行或固定底栏的尺寸。
- **跨视图视觉角色**：使用系统字体；任务标题 **20px / 600**，字段与章节标题 **14px**，正文及正文操作 **13px**，辅助说明 **12px**。数据条目名称保持紧凑标题，不作为展示标题。相同正文动作在设置内嵌页与独立页中均使用 **32px** 胶囊按钮；字段使用 **32px** 高度与 **8px** 圆角，多行代码字段保留自适应高度。卡片 **12px**、面板 **16px** 圆角，形状表达层级；键盘聚焦须有可见的 **2px** 焦点轮廓，禁用态不出现可执行的悬停／按下反馈。字体、字重、行高、间距、圆角、边框、焦点、表面色、阴影与状态按共享角色定义；紧凑元信息使用 **11px**，普通辅助说明使用 **12px**，窄屏不另行缩小同角色文字。危险操作在悬停和按下时保留危险前景色。基础尺度与语义角色的维护决策见 [ADR 0031](adr/0031-semantic-design-tokens.md)。
- **共同边界**：两类页面保留相同面板外框与固定底栏，正文在剩余空间内滚动；窄屏优先保留返回、字段与主要动作，不为装饰扩大面板。主提交与操作结果仍遵守 §5.3／§5.5，返回仍遵守 §4，不因顶部形态变化而跳过层级或丢失上下文。

以下为具有检索功能的搜索栏契约：

- **布局结构**：`图标按钮（默认 Logo；有父页的普通二级页为旋转返回徽章，主搜索为聚焦按钮）` + `胶囊搜索输入框` + `尾部 SearchDismissButton (esc 徽标)`。普通搜索胶囊中，图标容器到左边缘留白 14px、到输入文字起点留白 10px，以平衡圆弧边缘的视觉紧凑感；窄屏两侧均为 8px。图形在固定容器中居中，不按 Emoji 字形或图片透明留白单独补偿。操作菜单采用极简纯输入框，不设图标与尾部键帽，避免干扰候选项。
- **自定义搜索图标**：支持单个 Emoji（含组合）或本地图片，默认使用品牌 Logo。主搜索、二级搜索与 Tab Switcher 的搜索入口统一应用，两种承载一致；不改变点击区域、占位尺寸及各入口的聚焦、进入搜索或返回语义，无障碍名称须反映实际动作。自定义图标保留自身颜色，图片保持比例并静态显示；不可显示时回退默认 Logo。
- **输入胶囊**：主搜索、普通二级页与 Tab Switcher 的搜索胶囊在获得焦点且输入为空时呈现柔和蓝色外框；有内容时恢复普通边框与背景，清空后重新显示，保留输入光标及按钮自身的键盘焦点标识。尾部按钮默认显示 `esc` 键帽；有搜索内容时，鼠标悬停按钮或键盘聚焦显示 `×`，点击仅清空本层搜索并恢复输入焦点，保留当前视图。搜索为空时保留 `esc`，点击仅退出最深活动层，在主搜索层关闭面板。切换不改变占位尺寸；悬浮说明与无障碍名称反映清空或退出的实际动作，清空不标为 Escape 快捷键。键盘 Esc 始终遵守逐层退出契约。
- **主搜索查询补全**：以本机成功查询提供至多一个前缀补全，未输入部分以浅色提示；接受前不改变查询、列表排序或 Enter 主动作。仅在光标位于末尾且无选区时提供，输入法组合期间和删除文字后暂停提示；继续输入后可重新提供。危险命令不作为建议来源，隐身模式不读取或记录补全历史。
  - 搜索框内有提示时，普通 Tab、右方向键或 Ctrl+E 接受补全并保留输入焦点；没有提示时保留原有按键语义，Shift+Tab 始终反向导航，长按不重复接受。
  - **短期继续搜索**：非空主搜索有至少两个不同的可用页面候选，且成功打开标签页、书签或历史结果后，同一来源窗口 10 分钟内重新打开面板时，空输入提示最近一次符合条件的查询，底栏显示「继续搜索 Tab」。接受前仍展示首页并沿用 Enter 主动作；输入匹配前缀时该查询优先，否则使用普通补全。命令、网址直达、网络搜索与隐身不产生短期记录；记录不跨窗口或浏览器重启，忘记对应习惯或重置时清除，到期后失效。
  - 底栏次操作提供可点击的「补全 Tab」；列表上下选择不改写查询。提示在同一输入下保持稳定，但忘记或清除相关历史后立即失效。两种承载一致，二级视图与 Tab Switcher 保留各自筛选语义。
- **检索高亮 (`HighlightedText`)**：
  - 命中词采用纯粗体（字重 600）强调，直接继承所在文本的颜色。
  - 背景完全透明，无内边距，严禁使用彩色背景色块切断文字。
  - 设置搜索仅筛选与定位设置项，标题、说明、按钮与选项保持完整原文，不对命中词高亮。
  - 严格关闭浏览器的拼写纠错。

### 5.2 候选列表与条目 (`SearchResultItem`) <a id="候选项呈现"></a>

- **结构规范**：
  - **图标槽**：32px 无框圆角矩形槽（浅色模式 `#f1f3f4`，深色模式 `#35363a`），内嵌 16px 单色类型图标。
  - **文本区域**：主标题 + 副标题/URL/说明，超出部分优雅截断。主搜索与全部历史中，标题和简写地址相同但完整 URL 不同的候选须显示参数、片段等地址差异；差异部分优先获得可见空间，悬停可查看完整 URL，不合并不同目的地。
  - **状态徽标**：当前活动标签页固定展示「当前 / Current」单色胶囊徽标。
  - **快捷键槽**：右侧展示规范键帽。
- **选中视觉**：选中行采用柔和蓝色背景（浅色模式 `#e8f0fe`，深色模式 `#394457`），左侧圆角槽呈现主题色强调。
- **键盘遍历契约**：
  - **单步移动**：`↑` / `↓` 以及 `Ctrl+P` / `Ctrl+N`（无其他修饰键）。
  - **翻页浏览**：`PageUp` / `PageDown` 以及 `Option+↑` / `Option+↓`。
  - **首尾跳转**：`Cmd+↑` / `Cmd+↓` (macOS) 或 `Ctrl+↑` / `Ctrl+↓` (Windows/Linux)。
  - 选中项变更后统一调用 `scrollIntoView({ block: 'nearest' })`。

### 5.3 统一底栏 (`PaletteFooter`) <a id="面板布局与操作组件"></a>

底栏固定高度（44px）、不可伸缩，统一承载页面身份、主次操作、操作菜单与结果反馈。普通二级页统一由顶部旋转徽章返回，底栏不重复返回入口；没有父页的独立帮助窗口保留关闭，Tab Switcher 保留专用返回／取消。**严禁各业务视图在正文滚动区域底部另设主提交按钮**。

```
+-----------------------------------------------------------------------------------+
| [位置标题] [pet 槽] [hint／上下文／状态]  [主操作 ↵] [次操作] | [Actions ⌘K] |
+-----------------------------------------------------------------------------------+
```

- **左侧槽位**：
  - `title`：位置名称（如 `JustOneHop`、`Settings`、`Tab Groups`）。首页纯文本标题点击直达设置；二级视图保留一级清晰标题，不使用多级嵌套面包屑；与后方提示组件保持呼吸间隔。
  - **固定槽位**：位置标题与 pet 各占固定宽度；支持 pet 的页面即使隐藏 pet 仍保留占位；Tab Switcher 不提供 pet，其松键操作说明保留完整可读宽度。pet、hint 与操作反馈垂直居中于同一水平线，提示展开、反馈出现与 pet 显隐不改变文字起点或右侧操作位置。
  - **共享文字区**：hint、`context` 与 `status` 共用 pet 右侧的一个槽位。`context` 提供只读补充信息（如来源域名、组内成员数量）；展开的 hint 不替换或遮挡上下文；页面提供上下文时，hint 在 pet 上方以提示浮层展开。任何操作反馈优先于 hint 和上下文。
  - `status`：成功提示到期后恢复仍符合展开条件的 hint 或上下文；错误保留至关闭、重试或解决，不被 hint 覆盖。窄屏优先保留反馈和右侧操作，长反馈单行截断并可查看完整文案，不增高底栏。
- **右侧槽位**：
  - `primary`：主操作按钮（文字在前、键帽在后，500 字重）。若操作具破坏性，标明 `danger: true` 并显示红色。
  - `secondary`：可选的次要操作按钮，规则与主操作对齐。
  - `actions`：操作菜单开关（`Actions ⌘K`），前面带分隔线；无菜单时不加分隔线。
- **按钮激活防护**：底栏按钮仅响应普通 Enter / Space 激活；输入法组合态、按键连击重复或带有额外修饰键时严禁触发。

### 5.4 统一操作菜单 (`ActionMenu`)

- **唤起途径**：
  1. 列表条目上点击鼠标右键（`onContextMenu`）。
  2. 点击底栏的 `Actions` 按钮。
  3. 按下快捷键 `Cmd+K` (macOS) 或 `Ctrl+K` (Windows/Linux)。
- **呼出行为规范**：
  - 呼出时自动将对应列表条目设为当前选中项，并记录原输入框光标位置。
  - 焦点立即限制在菜单内，支持方向键、`Ctrl+P/N` 导航及输入关键词快速过滤菜单项。
  - **与底栏联动**：菜单打开期间，底栏 `PaletteFooter.primary` 的文案、键帽与危险态实时跟随当前菜单中高亮的动作更新。
- **关闭与退出**：按 Esc 或点击外部关闭菜单后，焦点安全返回原列表项，完整恢复原 Query 和选区。

### 5.5 操作反馈与结果确认

- **覆盖所有入口**：主搜索、二级视图、操作菜单及两种承载遵守同一反馈规则；鼠标、键盘与交替操作获得等价反馈。
- **即时交互反馈**：输入、搜索、焦点移动、选中、展开、返回和页面跳转，以可直接感知的内容、焦点或目标页面变化反馈，无需逐次显示成功文案。禁用操作须能获知原因；可触发但未产生变化的操作须说明当前状态，不得表现为无响应。
- **明确的结果确认**：设置变更、复制、保存、删除和标签整理等执行型操作，除更新相关状态外，必须提供简短的文字结果。pet 显隐开关以保存后的开关状态和小动物显隐确认成功，不重复显示成功文案；保存失败仍显示错误，延迟保存仍显示执行中。语言与主题切换即使已改变界面，也须确认具体选项，例如「语言已切换为简体中文」「主题已切换为深色」；语言切换成功提示使用切换后的语言，跟随系统的设置须明确表达「跟随系统」。
- **反馈位置与连续性**：面板内的操作结果统一显示于底栏 `status`，临时替换 `context`，不得遮挡内容、改变面板尺寸、抢焦点或要求额外确认。反馈沿用 §5.3 的共享文字槽，切换主题、保存、复制与失败结果均保持同一文字起点；窄屏不因反馈出现移除标题或 pet 占位，返回按钮与操作入口仍保留。菜单关闭或返回父视图后，结果在仍打开的面板内保持可读；成功提示短暂展示后恢复上下文，不因下一次无关输入立即消失。执行跳转或关闭来源页等会结束会话的操作遵循既有退出契约，以可见的目标变化反馈，不为展示提示延迟退出。
- **异步与真实性**：等待超过 150ms 时提供执行中状态；成功仅在操作完成、需要保存的设置已保存后显示，控件值改变本身不代表保存成功。部分完成须说明实际完成范围与未完成项；连续操作的反馈须对应实际结果，较早完成的请求不得覆盖较新操作的状态。
- **失败与恢复**：失败必须明确提示未完成的操作、可理解的原因及可用的下一步，不得静默吞掉或显示成功；设置保存失败时，界面不得把未保存值呈现为已保存。错误保留至用户关闭、重试或后续操作明确解决，不按成功提示的短时规则自动消失。
- **可访问性与克制**：结果文本须可被读屏感知，不仅依赖颜色、图标或动效。同一次操作只提供一份结果反馈，不叠加重复提示；危险操作的事前确认不能代替执行后的结果反馈。

## 6. 核心视图交互规范

### 6.1 主命令面板 (Omni Palette) <a id="整理操作与来源删除"></a> <a id="收藏标签页"></a>

- **空状态呈现**：直接呈现跨查询综合推荐列表（包含基于 14 天半衰期衰减的使用权重），不渲染多余的占位标题留白。
- **统一候选归一**：单主搜索框融合 标签页 (Tab)、书签 (Bookmark)、历史记录 (History)、系统命令 (Command)、直达网址 (URL) 与 Google 搜索。
- **排序与执行法则**：
  - 中文内容支持无声调全拼和连续首字母检索，至少两个拉丁字母，可与中文、英文及数字分词组合；命中高亮对应原中文字符。完整字面及全词字面命中优先于拼音、首字母和错拼，学习权重不能越级；命令与内置动作具备中英文别名匹配支持，首字母不解除危险操作的显式意图保护。
  - 默认单击或 Enter 执行主动作（跳转标签页、在当前页打开网址/书签）；次要操作支持新标签页打开。
- **学习机制与忘记**：学习权重仅在同相关性等级内微调，绝不跨越类别等级；支持通过 ActionMenu 显式选择「忘记 / Forget」单项清除该项的学习历史。

### 6.2 最近标签页切换器 (Tab Switcher)

- **来源归属**：在原生命令面板内再次触发切换快捷键，使用该面板来源浏览器窗口的标签页；不将面板自身或无关窗口作为来源。
- **快捷键模式（Hold & Release）**：
  - 按住启动修饰键并连续按按键单步选择条目。
  - 面板延后 **150ms** 显示（快速松开直接切页，完全不闪烁面板）；网页承载不压暗背景，以面板边框与阴影区分层次，避免反复切换造成整页亮度跳变；面板外点击仍可取消。
  - 松开修饰键直接确认切换至当前选中标签页。
- **搜索模式过渡**：
  - 点击搜索按钮或外层指针交互即可激活搜索胶囊，无缝转入列表搜索模式。
  - 一旦进入搜索模式，立即取消松键自动确认语义，改为标准 Enter 或点击确认。
  - 标题与网址可按中文拼音或连续首字母筛选；字面命中排在拼音命中之前，各级内保留 MRU 顺序，空查询保留原始 MRU。
- **悬停保护**：指针悬停在条目上仅呈现点击描边，绝对不修改松开修饰键时的确认目标，彻底规避鼠标指针误停导致的目标漂移。

### 6.3 标签组管理 (Tab Groups)

- **组层级列表**：展示组名、原生颜色徽标与成员标签数量。单击或 Enter 进入成员详情页。
- **组级管理动作**：
  - **展开 / 折叠**：切换 Chrome 原生标签组折叠状态。
  - **重命名**：就地触发单行文本编辑，保存或取消均保留当前选中项与列表滚动位置。
  - **解散分组 (Ungroup)**：移除分组容器，完整保留组内所有标签页在标签栏中。
  - **关闭整组 (Close Group)**：必须弹出共享确认层（`GroupConfirmation`），显示组名与真实成员数；执行前重新核对窗口与固定标签状态，跳过固定标签页。
- **成员详情二级页**：展示组内全部标签页，支持直接切换、移出分组与单页关闭；Esc 或顶部旋转徽章安全返回来源视图。

### 6.4 页面存储管理 (Storage View)

- **双栏交互结构**：左侧为只读 Key / Cookie 列表，右侧为只读原始 Value 预览区。
- **明确的操作语义分工**：
  - **单击候选项**：仅更新当前选择并刷新右侧预览，绝不执行复制或页面跳转。
  - **鼠标悬停**：不改变选择、不改变右侧预览，保证用户阅读与比对长内容时的绝对稳定性。
  - **普通 Enter / 底栏「复制值」**：将当前项的原始字符串写入系统剪贴板。
  - **双击条目 / ActionMenu**：进入存储详情查看弹窗。

### 6.5 设置面板 (Settings View)

- **持续可见的设置框架**：整体顶部固定跨分类搜索胶囊，左侧瞬移徽章顺时针旋转 90° 充当统一的返回上一级入口；下方左侧为约 **148px** 宽的分类导航，右侧呈现当前内容；分类为「外观 / Appearance」「快捷键 / Keyboard」「实验室 / Labs」「帮助 / Help」。默认进入外观，语言、主题与搜索图标归于外观；帮助分类直接显示帮助正文。分类内容和图标编辑等设置内子页均保留搜索与分类导航，不叠加多余的标题栏；页面身份、主次操作与结果反馈统一由固定底栏承载。搜索胶囊尾部清空／退出控件仍遵守 §5.1。
- **一级标题与精简底栏**：设置分类与子页的底栏左侧统一展示「设置 / Settings」，不展示多级面包屑或返回箭头；顶部 90° 旋转徽章按最深活动层逐级返回。首页底栏左侧展示「JustOneHop / 小范围瞬移」，点击文字直达设置。
- **分类与返回层级**：普通分类切换直接替换内容，不逐次叠加返回栈；从分类页返回退出设置，从子页返回其来源分类或搜索结果。Esc、顶部旋转徽章返回与横滑遵守同一最深活动层规则，操作菜单和确认层优先退出。主搜索可通过中英文关键词直达相关设置或子页。
- **跨分类检索与恢复**：搜索始终覆盖全部分类，对设置项标题、说明与中英文别名执行 AND 分词过滤；非空查询临时展示跨分类结果，不改变搜索前的分类或子页，空结果提供快速清空按钮。清空查询恢复搜索前的分类或子页、未保存草稿及原内容上下文，不把一次检索当作离页。
- **搜索结果子页**：从搜索结果打开子页时保留来源检索上下文；返回恢复查询、输入选区、选中结果和滚动位置。子页中的搜索仍为框架级跨分类搜索，临时检索后清空可继续原子页任务。
- **鼠键与窄屏**：分类、搜索结果、字段、主次操作与返回均可用鼠标、纯键盘及两者交替完成。Tab／Shift+Tab 按可见顺序遍历控件，包含左侧每个分类按钮；Tab 移动焦点不切换分类，Enter／Space 激活聚焦分类，方向键仍可在分类间移动并切换；过滤后的设置项保留原控件操作方式与 Tab 顺序，文本编辑保留原生按键语义。当前分类具有可访问名称与选中状态，单色图标配柔和蓝色选中态，不仅靠颜色表达位置。窄屏以可访问的分类选择器替代左侧栏，保留相同分类、搜索、子页与返回语义。
- **按需键盘提示**：底栏导航区域后提供小动物入口，默认收起提示；首页与历史、存储、标签组列表显示列表导航，设置、详情、帮助与表单页显示 Tab／Shift+Tab 控件导航。点击或 Enter／Space 切换小动物完整露出／潜伏，提示跟随小动物一起显示／隐藏，不维护独立的切换状态；主动收起后即使指针仍停在入口也保持潜伏，重新悬停才恢复偷看；操作反馈显示期间提示暂时让位；提示不占用返回层级，Esc 与页面返回按当前视图原有规则处理，不单独改变小动物状态或将焦点移到小动物。展开状态不随焦点转移自动收起，点击文案正文不收起。悬停只让小动物探头偷看，不完整露出或展开文案，离开后结束悬停偷看；点击才完整露出并显示文案。点击后持续悬停时保持露出及已展开的文案，鼠标离开后约 3 秒潜伏，并同步收起提示文案。潜伏时约每 8 秒短暂偷看，耳朵可间歇轻动，偷看不自动展开文案。窗口失焦或后台挂起暂停装饰动效与定时器，普通输入不反复推迟偷看。小动物入口在首页、设置分类和设置子页的同宽面板中保持固定位置，不随标题长度变化；展开不挤动标题、返回或主操作，也不遮住可操作控件；底栏没有页面上下文时，提示文字优先在底栏同排展开；页面提供上下文或空间不足时，文字在宠物入口上方以有清晰边界的提示浮层展开，并保持在面板内；系统减少动态效果时取消装饰动效。外观设置提供「隐藏宠物」开关，默认显示，本机保存并同步到各面板；隐藏时移除小动物及其提示入口但保留固定槽位，不改变反馈位置或键盘操作能力。主搜索和设置搜索均支持中英文检索此开关。
- **设置结果确认**：语言、主题、开关与时长等设置变更均遵守 §5.5；除 pet 显隐由开关自身确认成功外，保存成功后在底栏提示具体生效值，失败时明确说明未保存。
- **瞬移徽章设置**：外观分类提供入口，主搜索与设置搜索均可用中英文关键词找到。编辑页正文呈现标题、说明、预览、字段与恢复默认，底栏承载保存／佩戴及结果反馈。提供佩戴效果预览，支持 Emoji、PNG／JPEG／WebP 图片与恢复默认；进入时默认聚焦「选择图片」，Shift+Tab 可进入 Emoji 字段，Esc 返回上一级。图片选择成功且有待保存变更时聚焦底栏「佩戴徽章」，可直接按 Enter 保存；读取失败或没有变更时聚焦「选择图片」。底栏显式保存后在本机生效，不跨设备同步。临时搜索与清空保留草稿；通过返回、分类导航或打开其他目标明确离开徽章页时放弃未保存草稿，再进入显示已保存值。返回恢复来源搜索、焦点与滚动；保存失败保留草稿及原生效值。
- **紧凑面板整体比例**：
  - 搜索、分类导航和底栏保持可用，内容在剩余区域滚动；两种承载均维持 §2.2 的 **750 × 516 CSS 像素**上限，不为侧栏或子页扩大外框，窄屏优先保留字段和主要动作。
  - 正文按钮、下拉选择框与开关控件统一保持 **32px** 高度。
  - 侧栏文字 **13px**、点击行高至少 **40px**；设置项标题 **13px**、说明 **12px**，说明使用舒展行距，设置行随内容增高，文字与控件垂直居中。
  - 正文与卡片遵守 §5.1 的共享内容尺度；相关的简单设置共用卡片与分隔线，自动收起与排序等独立模块分卡承载。普通分类页与搜索结果均不重复分类标题。搜索期间侧栏与窄屏分类选择器显示匹配分类：原分类仍有结果时优先保留，否则显示导航顺序中的首个匹配分类；无结果时保留原分类。此提示不改变搜索前的分类上下文，清空后恢复原分类。标签与对应控件同排对齐，较长的辅助说明不挤占操作位置；操作的影响说明紧邻对应动作。
- **自动收起 (Tucked Away)**：
  - 原生收起组默认使用固定名称「收起来 / Tuck Away」，不在名称中附加成员数量；用户自定义名称保持不变。
  - 已确认的收起组只要组名与所在窗口不变，就继续管理并供后续批次复用；改颜色、加入或移出标签不解除归属，保留当前颜色并管理当前成员。撤销仅移出最近收起批次，手动加入的成员不纳入该批次；关闭自动收起则移出全部受管理成员。在 Chrome 原生界面改名或将组移到其他窗口后停止管理，通过本扩展重命名仍保留管理。完整浏览器重启后仍须核对恢复归属，不仅凭同名认领其他组。
  - 卡片依次展示名称与开关、开启后的时长设置、当前状态、可展开的规则。时长标签与选择器同排，英文使用完整时间单位；状态先显示结论和简短数量概况，刷新入口位于状态右侧；检查时间与规则入口组成次级信息行，窄屏可自然换行。规则位于核心控件之后，按短条目说明执行条件、保护范围和关闭后的结果。
  - 开启后在当前卡片展开收起时长分档（1/12 小时、1/3/7 天）与当前运行状态；已有合法非预设时长保留至用户重新选择。
  - 到期标签在电脑空闲（60 秒无操作或锁屏），或 Chrome 连续失去焦点 30 分钟后才可自动收起；失焦路径复用每 5 分钟的周期检查，返回 Chrome 重置等待并停止后续收起。
  - 状态区分未到期、受保护、到期待检查／等待失焦满 30 分钟／等待电脑空闲或离开 Chrome、恢复归属阻塞；上次失败与上次完成检查分别呈现，成功检查后清除失败状态。刷新状态不触发收起、不重置页面计时。
  - 同一窗口跨批次收起沿用首次收起前的标签栏左右顺序，新成员插入对应位置，已有成员不因新批次重排；用户调整组内顺序后，以当前标签栏建立新基准。后台休眠保留顺序，完整浏览器重启或缺少记录时以恢复后的顺序为准。
  - 一次自动整理已完成的部分保持同一撤销范围；中途停止不影响已完成部分的撤销。
  - 关闭设置时停止自动收起，并将受管理的全部成员标签安全移回普通标签栏；部分移回失败时保留重试，关闭状态下仍显示待移回数量与刷新入口，不把开关已关闭等同于页面已全部移回。

### 6.6 内置帮助与配置指南 (Help & Guide) <a id="内置使用帮助"></a> <a id="ctrltab-配置指南"></a>

- **使用帮助 (`HelpView`)**：随构建打包的只读文档，独立打开时顶部提供全文搜索胶囊，支持章节内容与正文即时高亮匹配；嵌入设置时沿用框架级设置搜索，正文完整呈现帮助内容。默认视图提供前往 GitHub 完整使用指南的直达入口，可用鼠标点击或 Tab 聚焦后 Enter 打开，链接具有可见焦点；各章节采用结构化分段与分隔排版，保障长文本浏览与快速扫读的可读性。
- **Ctrl+Tab 配置指南 (`BindingGuide`)**：
  - 独立只读说明页，展示为当前扩展 ID 生成的单行配置指令。
  - 底栏提供一键复制命令，明确引导用户在 Chrome 快捷键设置控制台中显式粘贴执行。
  - 严禁提供任何可运行任意不受信代码的入口。

## 7. 契约核对清单

任何新增功能或修改 UI 的 PR，必须对照以下契约清单逐项核对：

| 核对维度 | 必查契约规范 |
| :--- | :--- |
| **输入法与按键** | `isComposing` 与 `keyCode === 229` 期间无任何功能响应；Enter 长按重复或带修饰键不触发主动作。 |
| **鼠标与指针** | 列表 `onMouseMove` 具备屏幕物理坐标防抖；结果行支持文字拖选且松开不触发动作。 |
| **顶部与任务** | 有检索需求才显示搜索框；独立无搜索任务／详情页使用轻量顶部导航，标题与字段归正文；普通二级页使用顺时针旋转 90° 的顶部徽章逐级返回，底栏提供固定标题与 pet 提示；独立帮助根窗口与 Tab Switcher 保留专用关闭／搜索路径。主提交与结果仍归底栏。 |
| **设置上下文** | 分类切换不叠返回栈；临时跨分类搜索清空后恢复原分类或子页与草稿；明确离开图标页放弃未保存草稿；搜索结果子页返回恢复检索上下文；窄屏选择器与侧栏语义一致。 |
| **焦点与 Tab** | 有搜索的活动视图无焦点时按 Tab 能恢复搜索框焦点；具有聚焦语义的左侧 Logo 点击能恢复焦点，普通二级页的旋转徽章保持返回语义；已有控件聚焦时遵循 Tab 链，仅主搜索存在可接受提示时 Tab 补全；Shift+Tab 不补全；无搜索页聚焦字段、主操作或阅读区域，不抢回父级搜索焦点。 |
| **返回与路由** | Esc 仅由 `NavigationRoot` 统管；通过 `BackLayer` 逐级退出；返回父级后原 Query、光标、选中项与视口滚动完整恢复。 |
| **底栏与菜单** | 仅使用统一 `PaletteFooter`，无正文底独立按钮；`ActionMenu` 当前高亮与底栏主动作及危险态实时同步。 |
| **操作反馈** | 每次操作有可感知反馈；设置等执行型操作明确提示实际结果；异步状态、部分完成与失败如实表达；反馈不抢焦点，鼠键与双承载等价且读屏可感知。 |
| **承载与几何** | 内容尺寸上限 750×516 CSS 像素；浮层锚定网页视口，独立窗口锚定来源窗口；快照等待 150ms 阈值前不闪烁 Loading。 |
