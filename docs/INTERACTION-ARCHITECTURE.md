# 交互实现参考

本文描述当前组件职责与实现约束；设计动机及取舍见 [ADR 索引](adr/README.md)，使用方法见 [使用指南](USAGE.md)。源码是接口的权威定义，本文不记录验收流水。

## 交互设计约束

产品遵循 README 的 [Human first 交互原则](../README.md#交互原则)：鼠标和熟悉的快捷键都是正常使用路径，不要求用户先学习按键。新增或调整功能时，需同时考虑可发现的点击入口、快捷键提示、操作反馈与返回后的上下文。

鼠标按钮、菜单项与快捷键应调用同一操作逻辑，遵守相同的可用性和执行中状态。验收覆盖鼠标完成流程、键盘完成流程，以及两者交替操作；不能只验证快捷键能触发功能。本文的契约是新增或修改列表、子页面和操作弹窗时的逐项核对依据，不表示现有实现的所有边界均已验收；验证范围与证据见 [测试指南](TESTING.md) 和 [验收记录](ACCEPTANCE.md)。

### 通用列表与操作契约

- 候选行左键单击、普通 Enter 与底栏主操作执行同一主动作，使用同一目标和可用性判断。配备 `ActionMenu` 的列表提供 `onContextMenu`：先 `event.preventDefault()`、选中该项并保存输入框光标，再打开对应菜单。
- 列表的 `onMouseMove` 比对物理坐标 `event.screenX / event.screenY`，使键盘滚动时静止的指针不抢选中项。Tab Switcher 悬停只展示可点击描边，不改变松开修饰键时的确认目标。
- 所有关键词过滤列表（主搜索、Storage、Tab Group、Script Library、Script Runner 及 ActionMenu）使用 `HighlightedText` 渲染命中高亮。每个菜单动作同时提供 `icon` 与中英文 `keywords`，筛选同时匹配 `title` 和 `keywords`，支持跨界面语言检索。
- 所有列表支持 ↑/↓ 与无额外修饰键的 Ctrl+P / Ctrl+N；选中项变化后调用 `scrollIntoView({ block: 'nearest' })`。长列表支持 PageUp / PageDown、Option+↑/↓ 翻页和 Cmd/Ctrl+↑/↓ 首尾跳转。
- `isComposing` 或 `keyCode === 229` 期间，Enter / Escape / Backspace 留给输入法，不执行业务或返回。带修饰键或 `event.repeat` 的 Enter 不执行主动作；明确定义的 Cmd/Ctrl+Enter 保存除外，编辑字段的普通 Enter 保留编辑语义。

### Chrome 原生视觉

表面遵循 Chrome CR2023 Omnibox / Tab Search：内嵌胶囊搜索槽在聚焦时浮起并显示蓝框；未选中项使用无框圆角图标槽（浅色 `#f1f3f4`、深色 `#35363a`）和单色类型图标，避免按类别添加杂色或层层嵌套边框。选中项使用柔和蓝底（`#e8f0fe` / `#394457`），左侧为 3.5px 圆头指示条（`#0b57d0` / `#8ab4f8`）；危险态保留红色警示。网站图标的原生缓存来源见[候选项呈现](#候选项呈现)。

## 面板布局与操作组件

内部标识统一使用 zing：消息 source、runtime port 名称、注入标记、DOM/ARIA ID、CSS 类和动画名与产品名一致。偏好、脚本和排序记录继续使用原存储键，无需数据迁移。浏览器测试配置使用 ZING_CHROMIUM_PATH、ZING_VIMIUM_PATH。

主搜索、脚本新建和编辑共用同一套操作呈现，避免每个功能各自添加底部按钮。此边界基于已经存在的页面和行为；不引入全局命令注册器或路由框架。

- `PaletteFooter` 渲染固定高度、不可收缩的底栏。左侧 API 统一为 `navigation?: { kind: 'settings' | 'back'; label: string; tooltip: string; disabled?: boolean; onAction: () => void }`、`title?: string`、`context?: ReactNode` 与 `status?: ReactNode`。组件根据 `navigation.kind` 自己渲染唯一的 26px 单色图标按钮，统一尺寸、圆角、悬浮态和禁用态；`label` 提供可访问名称，`tooltip` 提供悬浮提示，`onAction` 调用共享设置操作或页面现有返回回调。页面不再通过 `leading` 或 `title.onBack` 拼装控件。按钮后依次是只读位置名称和 `·` 分隔的补充信息；位置名称统一为 11.5px / 500 的弱化文字，主搜索传 `zing`，Storage 传存储类型名称（如 `Local Storage`），标签组传 `groupLabel`。标题旁不得另加品牌装饰、类型图标或组色图标。
- `context` 承载只读背景（站点来源、成员数量），显式使用 11px 字号、400 字重、16px 行高的弱化文字；主搜索 `App` 与 Tab Switcher 的 `RecentSwitcherView` 均传 `context={<NavigationHint />}`，继承同一排版，共用本地化「选择 / Navigate」与 `↑ Ctrl+P ↓ Ctrl+N`，悬浮提示均为 `navigationHelp`；不得各自拼装。二级列表页仍显示站点来源或成员数量。快捷键共用 `key-chord` 与 `formatShortcut` 的语义结构（一个 `kbd` 对应一个完整快捷键组合：符号修饰键直接拼接如 `⌘T` / `⌘⇧T` / `⌘K`，文字修饰键以 `+` 连接如 `Ctrl+P` / `Ctrl+K`，Mod 按平台显示 ⌘/Ctrl），但左侧导航键的 `kbd` 继承上下文的字体与颜色，无边框、背景、内边距或最小宽度，宽度自动、高度 16px，左侧补充信息不显示键帽框。右侧主操作与 Actions 键帽保持 20px 高及原有边框、背景。短暂 `status` 出现时替换 `context`，占据同一位置与分隔结构，不增加独立槽位，不挤走位置名称。右侧 `primary` 保留标签、键帽、可用性、回调与危险态；可选 `secondary?: { label: string; keys: string[]; disabled?: boolean; onAction: () => void }` 提供次要操作，与主操作共用按钮规则，均文字在前、键帽在后。`actions` 仍是可选菜单开关；`isMac?: boolean` 默认为 `false`，只用于 Actions 的平台快捷键显示。业务页面不能在滚动正文末尾另放主要提交按钮。
- `ActionMenu` 渲染统一操作面板，负责焦点、方向键与 Ctrl+N/P、翻页、首尾跳转、Enter 执行、Cmd/Ctrl+K 切换和菜单内 Tab 焦点限制；通过 BackLayer 登记 Esc 返回。页面提供过滤后的动作、查询、选中项与回调；主搜索保留现有搜索排序算法，编辑器使用简单动作筛选。菜单打开时，`PaletteFooter.primary` 的文案和行为跟随当前高亮动作；关闭、删除、放弃恢复等动作标记 `danger: true` 时，底栏也传入 `danger: true`，保持相同的危险提示。
- 页面保留自己的业务状态、执行/保存逻辑及退出菜单后的编辑焦点。编辑器只记住真实表单字段，忽略复制代码时创建的临时 textarea，避免复制后光标丢失。
- 脚本编辑的主操作为保存：macOS `Cmd+Enter`，其他平台 `Ctrl+Enter`。普通 Enter 保持表单/代码编辑语义。复制、删除从底栏「操作」按钮或 Cmd/Ctrl+K 进入，删除仍经默认聚焦取消的确认框。
- 主搜索、脚本编辑、脚本执行结果与 Storage 列表/详情共用 PaletteFooter 和 ActionMenu。Storage 保留自己的数据读取与复制逻辑，菜单统一提供高亮、键盘导航、滚动和焦点行为；设置同样复用 PaletteFooter，返回与位置名称放在底栏左侧。
- 列表型二级页（Storage、标签组）不渲染 header：位置名称走底栏字符串 `title`，返回走 `navigation.kind: 'back'`；主搜索用 `navigation.kind: 'settings'` 调用共用设置操作。返回按钮调用页面现有返回回调，与 Esc 逐层返回语义一致，匹配最深活动 `BackLayer` 的返回行为；适用的 Backspace 同样每次只退最深一层（先关菜单，再退编辑层，最后回搜索），不能直接跳回主搜索；`label` 说明真实行为（如 `返回 · Local Storage`），不能只报地名。`disabled` 不得仅因业务忙碌而阻断鼠标返回，必须与键盘路径的可用性一致。只读站点来源、成员数量走 `context`，不是第二个可点目标。设置保留与主搜索一致的搜索输入 header，底栏使用返回按钮、Settings／设置标题及 Tab / Shift+Tab 控件导航提示；脚本库/运行、收起恢复核对暂保留原 header。
- 面板尺寸由 `.palette` 统一给出：常规总高 516px（含边框），网页浮层受可用视口高度约束，独立窗口填满视口；页面不得分别硬编码高度。正文以 `flex: 1; min-height: 0` 占满剩余空间并内部滚动，使 44px 底栏在主搜索、列表/详情和编辑层之间保持位置；列表切层时搜索框与底栏均保持位置。候选行共用 `.result` 的 40px 高度、26px 图标槽和 `.entry-copy` 的单行文字布局；Storage 名称与值预览并排，长值走详情层。
- Tab Switcher 的网页浮层与独立窗口共用 `RecentSwitcherView`，首行复用主搜索的 `.search-bar` 输入胶囊，列表复用 `.results`、`.result` 与 `.entry-copy`，标题和 URL 使用 `HighlightedText`。输入框初始为空且原生 `disabled`，不显示输入光标或编辑蓝框，焦点留在可聚焦列表，使用本地化 `recentSearch` 占位文字与可访问名称；默认由列表持有 `aria-activedescendant`，点击搜索图标、输入区域或 Ctrl/Cmd+F 后才启用并聚焦输入，以 `combobox` 的 `aria-controls` / `aria-activedescendant` 关联列表与当前选中项；搜索栏右侧提供取消按钮。实际启动快捷键仍放在 `header` 的 `title` 属性，未绑定时不提供该提示。底栏直接复用 `PaletteFooter`，不另加 `recent-help` 行：`title` 在快速切换时使用本地化 `recentRelease`（如「松开 Ctrl 切换」，按 `releaseKey` 显示对应修饰键），显式进入搜索后改为 `recentSwitcher`，`context={<NavigationHint />}` 与根 `App` 相同，共用本地化「选择 / Navigate」、`↑ Ctrl+P ↓ Ctrl+N` 和 `navigationHelp` 悬浮提示，继承 11px / 400 / 16px 的共享样式。右侧 `primary` 是「切换 ↵」，未加载、无有效选中项或关闭期间禁用；`secondary` 是「取消 esc」，调用共享取消回调。浮层 `.recent-overlay .recent-switcher` 用 `flex: 1; min-height: 0; height: auto` 填满父 `.palette` 的可用空间，避免单独的 516px／最大高度造成底栏溢出或底部空白；独立窗口仍为 `100vh`。
- 底栏骨架为「左＝可选控件 + 位置／提示 + 补充信息／状态，右＝主操作、可选次要操作与操作菜单」；设置／返回入口不重复，Tab Switcher 的搜索栏右侧提供取消入口。列表页的搜索胶囊几何由 `.search-bar` / `.storage-search` 共享的规则给出，包含窄屏间距；新增列表页必须复用，不得另写一份胶囊样式。宽度 ≤520px 时仅隐藏补充信息 `.palette-footer-context`（包括主搜索与 Tab Switcher 的导航提示），不隐藏 `status`；Tab Switcher 的松键提示或搜索状态标题位于 `title`，窄屏仍保留。复制成功、执行中及危险操作等状态继续在原位置替换上下文，必要时可截断。导航按钮、位置名称与右侧操作始终保留，按钮不收缩，长标题先于操作控件截断。分区参考 Raycast [A fresh look and feel](https://www.raycast.com/blog/a-fresh-look-and-feel) 中左侧命令身份／状态、右侧上下文操作的思路；共享导航按钮、弱化位置名称与窄屏策略是 zing 自己的适配，决策见 [ADR 0009](adr/0009-list-page-footer-breadcrumb.md)。

## 位置与浏览器承载方式

本节描述当前实现。后续定位目标已改为所在显示器屏幕水平居中、从屏幕顶部计算垂直位置，具体垂直偏移未定，工作仍暂停且未解决；目标与保留普通网页浮层的约束见 [ADR 0010 的待实现目标](adr/0010-content-anchor-panel-geometry.md#待实现目标)。

网页浮层的位置由 `content.tsx` 和 `.zing-app.overlay` / `.palette` 控制，独立窗口通过 `src/panelGeometry.ts` 复用同一内容区几何；子页面不能决定自己的承载方式或另设位置。普通网页当前为内容区水平居中、偏上的浮层，新建/编辑切换时沿用相同坐标。

`panelRect(viewport)` 对齐网页浮层 CSS：宽度为 `min(750, viewport.width - 48)`，宽度 ≤520 时改为减 20；顶部 inset 为 `clamp(28, viewport.height × 0.16, 150)`，窄屏为 24；高度为 `min(516, viewport.height - inset - 24)`，水平居中，底部至少预留 24px。几何函数将极小视口的宽高下限保护为 1px。这里的 750×516 是面板内容矩形，不含独立窗口的系统标题栏和边框。

Command Palette 与 Tab Switcher 的独立窗口共用 `nativePanelBounds(owner, tab, frame, zoom)`。Chrome 返回的来源 `tab.width/height` 与窗口 `left/top/width/height` 均为屏幕逻辑像素（DIP），不是页面缩放后的 CSS 像素。按窗口外框和标签页宽高水平对称、底边对齐估算内容区，来源尺寸缺失时使用保守回退值。内容宽高先除以 `chrome.tabs.getZoom` 返回的缩放比例换算为 CSS 视口，再调用 `panelRect`，将结果乘回缩放比例并加上估算的内容原点得到屏幕坐标。创建时默认暂估框架为 `{ left: 0, top: 44, width: 0, height: 44 }`；这只是首帧外框估算，不是固定窗口总高。

`popup.tsx`（仅独立窗口入口）与 `switcher.tsx` 在 UI 渲染前调用 `alignPanelWindow`；切换器也在发送 `ready` 交接前完成该步骤。它重新读取来源窗口、标签页与当前 popup，核对窗口归属；popup 以 automatic / per-tab 缩放跟随来源页，不修改其他扩展页面的缩放。自身边框由 Chrome API 的 popup 外框尺寸减去 popup 标签页内容尺寸计算，两者均为 DIP，避免将缩放后的 DOM `innerWidth/innerHeight` 与原生窗口尺寸混减；左右按总宽差的一半、顶部按总高差减去半宽差计算，更新窗口位置和外框大小。边框校准失败时保留创建时的位置与尺寸。该步骤测量的是 popup 自身的框架，来源内容区的屏幕原点无法直接测量，仍依赖上述估算；垂直标签栏、停靠 DevTools 和系统边框可能造成偏差，不能承诺像素级对齐。独立窗口保留系统标题栏。决策与取舍见 [ADR 0010](adr/0010-content-anchor-panel-geometry.md)。

Chrome 原生页（chrome / chrome-search / chrome-untrusted / devtools）的 Command Palette 使用上述独立窗口，复用同一 App、底栏与返回层级；主层 Esc、重复启动快捷键或失焦关闭。后台在 session storage 保存窗口令牌、来源窗口和标签页，解析该窗口消息时恢复来源上下文，并核对来源仍为原窗口的活动标签页。来源被外部关闭时面板也关闭；通过 zing 自身关闭操作删除来源时，按下述整理会话接续规则更新来源。

普通网页地址栏仍持有焦点、网页 `document.hasFocus()` 为 false 时，以及 Web Store 等其他禁止注入的页面，仍使用 action popup。该弹窗位置由 Chrome 决定，地址栏兜底行为不变。

后台启动握手必须收到面板的明确 `true` 回复。页面可能只有最近标签切换的轻量监听器；`sendMessage` 没有抛异常，或返回 `undefined`，不能说明面板已安装。需要补注入后再打开浮层。成功打开应清除旧的每标签页 popup 设置，恢复工具栏的正常启动路径。

## 统一返回路由

`NavigationRoot` 是面板唯一的 Esc 捕获入口。监听器安装在实际承载 UI 的 ownerDocument.defaultView，而非代码运行环境的全局 window；普通网页还覆盖承载 iframe 的父窗口，处理焦点落回宿主时的按键。卸载时移除监听器。页面与菜单不得再各自添加 Esc 按键分支。

`BackLayer` 只登记返回回调，不添加 DOM 容器。优先级由 React 嵌套深度决定，不依赖 effect 的执行或注册顺序。每次 Esc 仅调用最深的活动层：主搜索 → 设置 → 脚本管理 → 编辑 → 操作菜单；Storage 列表/详情/菜单、脚本选择/执行结果、设置下拉框及删除确认同样接入。Command Palette 中只有主搜索层的返回会关闭整个面板；Tab Switcher 使用 `NavigationRoot` + `BackLayer` 将 Esc 路由到取消回调；启动时在异步初始化前挂载返回路由，加载期间也可取消。

每次独立按键同步提交一次返回，阻止后续冒泡和浏览器默认行为；长按产生的 repeat 不再弹出下一层，输入法组合期间的 Esc 留给输入法。返回回调更新页面状态；从 ActionMenu、详情或重命名、换色、脚本编辑等内嵌编辑态返回列表时，页面恢复原搜索词、选中项与保存的光标／选区（`setSelectionRange(...caret.current)`）。执行中的脚本返回选择列表后，旧请求可能继续运行，但不得覆盖新页面或触发自动复制。

Backspace 也进入同一返回路由，但保留编辑语义：二级页面搜索框标记 `data-back-on-empty`，只有这类搜索框为空，或焦点位于非编辑控件时才返回。搜索框有内容时正常删字；名称、代码、执行结果及其他编辑区域不触发返回。带修饰键、输入法组合和长按重复不触发返回；主搜索层的 Backspace 不关闭面板。面板可能运行在闭合 Shadow DOM + 沙箱 iframe、独立窗口或原生 popup 中，焦点从面板自身的 `getRootNode()` / `ownerDocument` 解析，不能依赖全局 `window` 或被闭合 Shadow DOM 重定向后的事件 target。

`.palette` 与菜单保留 `tabIndex=-1` 以承接鼠标焦点，但 Esc 不依赖这些容器或任何输入框获得焦点。即使焦点位于 iframe body，仍通过同一路由返回。

## 验收边界

除了直接加载 UI 的功能测试，还要从后台真实命令回调驱动全新普通网页的启动，断言浮层存在且未降级、面板水平居中、进入子页面后坐标不变。编辑器需验证菜单开关、选区恢复、普通 Enter 换行、保存快捷键、删除取消、较矮窗口底栏可见，以及真实闭合 Shadow DOM/iframe 与 Vimium 组合。

## 候选项呈现

Entry 的可选 category、shortcut、faviconPageUrl 仅承载呈现信息，不改变命令 ID、存储或后台接口。主搜索命令按 Tab / Script / Storage / Settings / Chrome Pages 添加本地化前缀，自建脚本归入 Script；根设置项避免显示重复前缀。标签页、书签保留网站原始标题。分类参与中英文检索，支持 `Script: new`，沿用严格匹配、命令意图优先和使用习惯排序，不另增分组标题或模式。

右侧键帽由共用 Shortcut 渲染，一个 `<kbd>` 容纳完整快捷键组合（如 `⌘T`、`⌘⇧T`、`⌘↵`、`Ctrl+↵`），Mod 按平台显示 Command 或 Control。仅展示已支持的快捷键；非当前标签页操作不展示浏览器 Close/Reload 快捷键，原生 popup 中也隐藏这两个快捷键，避免指向错误目标。ActionMenu 使用相同绑定匹配执行动作，编辑器 Save 保留 Cmd/Ctrl+Enter。

标签页、书签与最近标签切换器使用共用 Favicon，读取 Chrome 扩展 `_favicon` 缓存资源；manifest 声明 favicon 权限及网页浮层所需的资源访问。内部页面、加载失败或加载完成前显示现有类型图标，不请求第三方图标服务。快捷键区域不收缩，长标题截断，保持窄窗口下可见。

## Chrome 内置页面

`chromePages.ts` 定义七个固定目标与各自的执行 ID、中英文别名、标题和单色图标，候选项归入 `chromePages` 分类，显示「Chrome 内置页面 / Chrome Pages」前缀。它们仅在搜索时出现，分类也参与中英文检索和冒号前缀解析；不增加搜索模式或二级列表。精确命令意图沿用主搜索排序，各目标使用独立 `command:<action>` 学习身份。`settings / 设置` 和 `shortcut / 快捷键` 保留 zing 自身设置语义。

后台按执行请求的来源窗口查找目标，精确比较规范化 URL（无路径时视为 `/`），保留子路径、查询参数和片段的差别；已有标签页按活动页优先、标签位置其次选择，执行前重读所属窗口及当前／待导航地址。无匹配则在来源窗口新建，不覆盖网页或跨窗口复用。主搜索和现有扩展快捷键按钮共用该导航函数；原生独立面板沿用来源窗口恢复机制。点击、Enter、底栏与菜单共享成功关闭／失败留在面板的流程。固定地址映射不接受调用方提供任意 URL，不新增权限或读取目标页数据。

## 扩展重新加载

`reloadExtension` 使用现有分类呈现机制：`category: 'zing'` 与动作名称分别提供，统一生成 `Zing: Reload`／`Zing: 重新加载`，不把扩展名称拼入动作标题；分类参与搜索并支持中英文冒号。该命令无标签页目标和专属快捷键；空输入不展示，查询须包含 zing／extension／扩展指向，单独 reload／刷新继续表达标签页刷新。沿用主搜索的点击、Enter、底栏和菜单执行路径及输入法／修饰键保护，不新增权限。

后台经过现有消息来源、面板来源和窗口校验后，先枚举标签页完成预检并确认接收请求，再关闭自身 popup.html／switcher.html 页面，向普通页发送 `close-for-reload` 并等待已注入浮层清理，最后调用 `chrome.runtime.reload()`。内容脚本仅接受自身扩展发送的关闭消息；未注入页面无接收者属于正常情况。显式清理避免 runtime 失效后旧浮层残留，不依赖固定延时等待响应；重载命令不写使用记录。普通网页不刷新、关闭或重新创建，已保存本机数据保留。重载完成后用户重新唤起面板，命令不构建源码。

## 响应速度与缓存边界

后台按需缓存扁平化书签及正在进行的读取，创建、修改、删除、移动、子项重排和导入完成时失效。读取过程中发生变化时丢弃旧树并跟随最新读取。缓存仅在内存中，后台重启后重新获取；标签页状态和快捷键每次仍实时读取，避免快速 Enter 操作过期的目标。

主搜索与操作菜单复用同一候选数组的归一化字段和 Fuse 索引，候选数据或语言改变时重建。排序继续实时使用当前查询和使用记录，不缓存排名结果。高亮组件只在文本或查询改变时重算，方向键选择无需重复计算所有行的高亮。

执行函数的可选 onPerformed 回调在 Chrome 操作成功后通知面板，页面按操作意图决定关闭或刷新；执行 Promise 仍等待后台串行写完使用记录。关闭来源页时先完成接续，再向仍存在的调用方确认；接续不等待学习写入。失败操作不提前回应，不记录使用；调用页面消失也不阻断后台写入。

### 整理操作与会话接续

`paletteActions.keepsPaletteOpen` 将关闭（含批量）、固定、静音、分组更新／移出组与撤销收起归为保留面板；非来源页的刷新和收起也保留。切换、打开与恢复内容属于导航，成功后关闭；来源页刷新／收起仍退出。鼠标、Enter、底栏与菜单使用同一执行路径。完成整理先关闭菜单，再刷新快照并恢复搜索焦点／选区，状态反馈替换底栏 context；失败保留错误供重试。

主搜索与标签组通过 `useResultSelection` 保持选中身份，消失时优先原结果顺序中的下一个幸存项，再找上一项；后台重排不能把仍存在的选择换成首项。来源 ID 改变或跨承载接续后使用显式无选择状态，更新快照或移动鼠标不自动重新选中；方向键、查询修改、点击或右键明确指定结果后继续。输入法、重复 Enter 与修饰键 Enter 仍不执行。主搜索与标签组共享执行中状态，返回仍可用，但返回主搜索不会允许重叠操作。执行期间暂停通知触发的快照读取，并废弃此前未完成读取；成功整理或执行失败后都重新读取，首次加载的重试也走同一版本检查，防止旧来源或旧列表覆盖完成后的结果。操作已成功但刷新失败时明确提示已完成，避免误导重复执行。

`Execution.paletteState` 仅携带主搜索及可选标签组的 query、selection、caret；不包含存储值或脚本结果。后台只为显式关闭命令且实际移除了来源页时接续：已有独立面板保留窗口、重新绑定同一来源窗口的活动页；网页浮层或 action popup 则使用现有独立面板承载。`palette-state` 请求恢复接续界面，来源校验仍绑定窗口令牌。临时状态沿用 session storage，新面板读取一次后即清除；不增加权限、持久化用户数据或全站注入。执行中的用户显式退出发送 `cancel-palette-continuation`，后台按原始调用方文档／标签页或原生令牌匹配提前登记的执行记录，取消接续但不撤销已请求的浏览器操作；承载文档正常销毁不等同于用户取消。来源窗口消失、最后一页关闭、接续期间切往其他窗口时不新建或抢回焦点；外部关闭来源仍取消。独立面板保留系统标题栏及现有几何估算，不改变暂停中的屏幕定位目标。决策见 [ADR 0012](adr/0012-continuous-tab-management.md)。

最近标签切换的受管窗口使用后台握手携带的已排序标签列表，不再重复查询；独立打开的兜底窗口仍自行读取。松键、焦点丢失、目标关闭或跨窗口移动的校验保持不变。

性能基准使用合成数据与隔离 Chrome 配置：`./node_modules/.bin/tsx tests/search-benchmark.ts` 测量搜索算法；`npm run test:e2e -- --grep 'English performance'` 验证重复打开、慢存储下的及时响应、大书签库及最近标签窗口的重复查询。耗时用于同环境比较，不能当作所有机器的时延保证。

主面板首次等待快照时，150ms 后仍未返回才显示 Loading（包括读屏状态提示）；结果到达或读取失败立即取消计时，重试重新计时，卸载清理定时器。搜索框始终可输入，已有结果的后台刷新保留列表。快速切换浮层的蒙层与面板也共用 150ms 延迟展示，确认中取消展示，快速操作直接完成，切换不等待视觉延迟；避免白屏或蒙层闪烁。延迟展示本身不引入快照缓存、消息接口或存储结构。

## 列表与设置键盘一致性

设置保留 56px 顶部区域，复用搜索图标、输入胶囊和聚焦样式，提供「搜索设置」输入框。`settingsSearch.ts` 从两份语言包的名称、说明、分区名和别名建立本地索引，不区分大小写、空白分词后按 AND 字面匹配；空输入展示全部，未命中行不渲染，空分区隐藏，文字使用 `HighlightedText` 且关闭拼写容错，与筛选语义一致。无结果显示状态和清空按钮，清空后聚焦输入框。普通进入聚焦搜索，主搜索直达仍聚焦指定控件；Tab / Shift+Tab 按 DOM 顺序只遍历可见控件，搜索框的 Enter 不执行设置操作。搜索输入标记 `data-back-on-empty`，沿用统一 Esc / Backspace 返回路由。脚本库返回设置时保留筛选词并恢复原入口焦点和可见位置。使用共享 PaletteFooter 在底部左侧显示返回按钮与 Settings／设置标题，正文按「通用（General）」「键盘（Keyboard）」「实验性功能（Experimental Features）」分为三个独立纯白圆角模块卡片，卡片上方为带 14px 单色图标的弱化模块标题，卡片内部各项以独立设置行与轻分隔线上下排列：语言与主题共用通用卡片，名称／说明在左，等宽选择框在右，极窄空间允许换行；键盘卡片两行左侧以纯文案陈述功能名称与作用，右侧统一以单个 `<kbd>` 键帽（如 `<kbd>⇧⌘P</kbd>`、`<kbd>Ctrl+Tab</kbd>`）加动作按钮呈现；自动收起、搜索排序和脚本收藏共用实验性功能卡片，说明控制在单行内，右侧下拉框与次级操作按钮统一为 30px 中性边框按钮。各控件保留独立标签和原搜索直达焦点，分区不引入额外模式或折叠层。设置底栏标题后以 `context` 固定显示 `<kbd>Tab</kbd>` / `<kbd>Shift+Tab</kbd>` 控件导航提示，说明向前／向后移动焦点，与列表的选择提示区分；全项目统一一个 `kbd` 对应一个快捷键组合，沿用弱化无框样式。窄屏仍保留这条设置提示。

脚本管理和脚本运行选择列表使用普通 Enter 确认；带修饰键、长按重复及输入法组合不触发编辑/执行。Ctrl+N/P 仅在无其他修饰键时导航，不吞掉 Shift 选区操作；设置下拉框同样支持 Ctrl+N/P，Esc 关闭后保留触发控件焦点。

脚本管理和运行选择页的搜索框固定可见，列表独立滚动；脚本管理的键盘选中项自动滚动到可见区域，编辑返回时保留查询、候选项与搜索选区；鼠标进入编辑也同步选中项。根面板 Tab 遍历排除 inert、禁用及 tabIndex 为负的控件，弹层背后的输入框不参与焦点循环。

Tab Switcher 默认禁用输入框并聚焦列表，通过搜索图标按钮、输入区域外层 `pointerdown` 或标准 Ctrl/Cmd+F 显式启用搜索，暂停本次会话的修饰键松开确认；初始列表聚焦不触发此状态。进入搜索后可松开启动修饰键正常输入，用普通 Enter、行点击或底栏主操作确认；再次点击搜索图标或按 Ctrl/Cmd+F 都恢复输入焦点。独立窗口加载期间的导航按原始按键语义与重复启动步骤依次缓冲，列表挂载后按实际可见高度重放翻页，再处理已缓冲的松键。`recentSearch.ts` 在本次会话的来源窗口候选内按标题／URL 筛选：不区分大小写，空白分词后按 AND 匹配，保留 MRU。查询变化保留仍可见的选中标签，否则选首项；选中标签被关闭或移走时，仅在源页仍可见时回退到源页，否则保持无选择，直到导航、点击或修改查询。无匹配或无选择时，Enter、松键与底栏主操作均不激活标签页。输入框控制列表，↑/↓、Ctrl+P/N、Tab / Shift+Tab 循环选择，PageUp/PageDown 或 Alt+↑/↓ 翻页，Ctrl/Cmd+↑/↓ 跳首尾，选中项滚动到可见区域。所有带修饰键、重复、输入法组合或 `keyCode === 229` 的 Enter 均不执行；普通 Enter 确认当前选择，未进入搜索时松开启动修饰键也可确认。

## 脚本执行结果操作

成功结果以「复制结果」为底栏主操作，失败以「重新运行」为主操作；Cmd/Ctrl+K 菜单列出当前可用的复制与重新运行动作，底栏跟随菜单选中项。执行中禁用主操作和菜单，重复 Enter 或带修饰键 Enter 不再次执行。正文仅保留结果、执行状态、错误说明及权限引导；复制反馈位于固定底栏上方，失败以 alert 提示并保留结果以便重试。

菜单统一使用搜索高亮、Ctrl+N/P、Tab 焦点约束和 BackLayer 返回。关闭菜单恢复原控件及结果文本选区；执行完成聚焦底栏主操作，结果文本仍支持原生选中/复制。重新运行保留既有运行模式（包括自动复制），执行与复制回调校验当前运行版本；返回选择页后的旧结果不得覆盖界面或自动复制。结果仍只存当前面板，后台接口、权限与存储结构不变。

## 技术栈与权限分工

- React + TypeScript；Fuse.js 做中英文模糊搜索，Lucide 图标，esbuild 构建。
- 语言包在 `public/_locales/`：manifest 使用 Chrome 原生 i18n，面板复用相同文案并优先读取手动语言选择；`en` 是默认回退语言。构建时将 `zh_CN` 复制为 `zh_TW`，共用一份中文文案。
- 页面内容脚本使用隔离的 Shadow DOM 和原生 modal dialog，在浏览器 top layer 中显示；内部空白沙箱框架隔离键盘事件，兼容 Vimium 的字母快捷键和 Esc。框架不加载外部页面或执行脚本，UI 仍由原内容脚本渲染。
- Service worker 负责读取浏览器状态和执行命令。每次执行会重新核对标签页所属窗口、当前位置与固定 / 静音状态。
- `activeTab`、`scripting`：仅用户唤起时注入命令面板。
- `userScripts`：用户主动选择已保存脚本时，在隔离的 USER_SCRIPT 环境运行一次；不注册自动执行脚本。执行前核对当前页面，并绑定具体文档，防止导航期间误在新页面执行。
- `tabs`：读取标签页标题、URL、状态并执行标签管理。
- `bookmarks`：读取书签供搜索。本版本不增删书签。
- `sessions`：恢复最近关闭内容。
- `cookies`：读取 Cookie，包含 HttpOnly；不增删或修改 Cookie。
- `content_scripts.matches`：普通 HTTP(S) 页面及其匹配子框架预加载轻量修饰键监听，只在内存保存 Control/Alt/Meta 状态，按需转发松键；不记录输入文字、不拦截网页快捷键、不上传数据。未增加全站 `host_permissions`，Cookie 仍逐站授权。
- `optional_host_permissions`：声明可按需申请 HTTP(S) 网站权限；首次查看 Cookies 时只请求授权页列出的具体域名，不预先授予所有网站访问权。
- `storage`：仅在本机保存语言、主题偏好、脚本收藏及搜索选择记录，不使用云端同步。搜索记录最多 500 条，90 天未使用的记录不再参与排序，并在下次记录时清理；频次权重每 14 天减半，让新习惯逐渐取代旧习惯。

## 标签组

当前窗口的原生组进入统一搜索，显示 `Tab Group: 名称 · 数量`（中文为「标签组」）；成员标签页显示组名和颜色，组名参与搜索但不改变标签页的使用记录身份。进入组管理页后继续搜索成员，鼠标或 Enter 切换，Ctrl+N/P 和方向键选择。底栏与 Cmd+K 共用切换、关闭、移出组、展开/折叠、重命名、颜色操作；重命名和颜色编辑属于下一层，Esc/非输入状态 Backspace 每次仅返回一层。

快照增加当前窗口组信息和标签页 groupId；执行接口增加 updateGroup、ungroupTab，使用已有 tabGroups 权限。执行前核对窗口与成员归属，拒绝对已移组的候选项执行旧操作。组被外部删除或移出窗口时显示已不可用，仍可返回搜索；不自动认领同名组。

在 zing 内修改受管理的 Tucked Away 名称或颜色，会在串行生命周期队列内同步预期状态及恢复记录，后续新增成员不覆盖自定义名称/颜色。Chrome 外部的手动改名/换色仍沿用保守规则，停止自动管理。组置顶不在本次范围内。


## 鼠标与键盘混用（2026-10-16）

Command Palette、标签组管理页（`TabGroupView`）、页面存储列表（`StorageView`）及收起恢复页（`TuckRecoveryView`）的候选项右键均直接打开该项的共享操作菜单，选中项与菜单目标同时更新；关闭菜单恢复搜索词、光标与输入焦点，继续支持 Ctrl+N/P。与底栏和 Cmd+K 使用相同动作集合、图标、中英跨语言关键词及危险操作红色提示。`StorageView` 单击候选项与按 Enter 一致（直接选中并复制原始值），双击或从操作菜单进入详情。

Tab Switcher 的确认和取消提示是可点击按钮，聚焦按钮后 Enter 遵循按钮自身行为；列表普通 Enter 确认当前选择，未进入搜索时松开修饰键同样确认。鼠标悬停用独立描边提示可点击，不改变键盘选择，避免指针偶然停在列表上改变松键目标；点击行直接切换。长标题可悬停查看完整标题。空快捷键不显示多余分隔符。

面板视觉尺寸：Command Palette 与 Tab Switcher 的内容矩形均以 750×516 为上限，独立窗口按来源标签页内容区估算锚点并校准自身边框，外框尺寸另含系统标题栏与边框，详见[位置与浏览器承载方式](#位置与浏览器承载方式)。两者共用 56px 高的搜索栏与输入胶囊；常规横向内边距 24px，窄屏 18px，输入字体 14.5px，候选行 40px，列表内边距为 4px 8px 8px。切换器候选标题与 URL 使用 `.entry-copy` 同行布局，溢出省略，底栏复用 `PaletteFooter` 的背景、44px 高度与按钮样式。新增或修改二级页面时按本文的通用契约与对应组件章节核对，验证范围按 [测试指南](TESTING.md) 选择。
