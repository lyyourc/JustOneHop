# 0005 · 主动运行保存的脚本并隔离结果

状态：已采纳。记录日期：2026-10-15，基于现有实现与历史验收补录；不代表这些决策在同一天首次作出。

## 背景

脚本收藏只提供复制，不能满足在当前网页读取值并复制结果的工作流。同时不能让保存或搜索脚本隐式执行代码，也不能在页面导航后执行到新文档。

## 决策

使用 Chrome userScripts，在独立 USER_SCRIPT 环境中运行用户明确选择的已保存脚本；不注册自动执行。后台接收脚本 ID 与目标页面标识，读取保存的代码，验证目标并绑定具体 documentId。

结果仅在当前面板内显示，可复制或重新运行。前台返回后忽略旧运行结果并停止后续自动复制；后台避免同一标签页并发执行。内置 Ctrl+Tab 配置保持手动复制执行。

## 取舍与影响

需要支持 execute 的 Chrome 版本和用户脚本开关。可以操作 DOM 与页面存储，但不提供网页 MAIN world 变量、扩展 API 或油猴 GM_*。返回面板不能保证终止已经启动的网页脚本；代码自身仍可能发起请求或修改页面。

## 未采用的方案

不在扩展自身环境或网页 MAIN world 执行任意保存代码，不将本地脚本收藏扩展为油猴兼容层，也不持久化执行结果。
