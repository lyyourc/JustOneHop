# 0005 · 主动运行保存的脚本并隔离结果

状态：已被 [ADR 0017](0017-remove-script-library.md) 替代（2026-10-18）。记录日期：2026-10-15，基于现有实现与历史验收补录；不代表这些决策在同一天首次作出。

以下保留原决策及取舍作为历史记录，脚本收藏与已保存 UserScript 的执行功能已移除，文末原实现路径及旧使用章节仅为历史引用。Ctrl+Tab 配置说明和跨页保留行为由独立 `BindingGuide` 承接，当前契约见 [ADR 0017](0017-remove-script-library.md) 与[配置指南](../USAGE.md#ctrltab-配置)。旧 `saved-script:*` 数据原样保留，不读取、使用或自动删除。

## 背景

脚本收藏只提供复制，不能满足在当前网页读取值并复制结果的工作流。同时不能让保存或搜索脚本隐式执行代码，也不能在页面导航后执行到新文档。

## 决策

使用 Chrome userScripts，在独立 USER_SCRIPT 环境中运行用户明确选择的已保存脚本；不注册自动执行。后台接收脚本 ID 与目标页面标识，读取保存的代码，验证目标并绑定具体 documentId。

结果仅在当前面板内显示，可复制或重新运行。前台返回后忽略旧运行结果并停止后续自动复制；后台避免同一标签页并发执行。内置 Ctrl+Tab 配置保持手动复制执行。

## 取舍与影响

需要支持 execute 的 Chrome 版本和用户脚本开关。可以操作 DOM 与页面存储，但不提供网页 MAIN world 变量、扩展 API 或油猴 GM_*。返回面板不能保证终止已经启动的网页脚本；代码自身仍可能发起请求或修改页面。

## 2026-10-18 · 配置说明跨页保留

Ctrl+Tab 的「复制并打开」及菜单打开快捷键页不再主动关闭说明。网页浮层在配置说明挂载期间通过 host context 暂停 `visibilitychange` 的隐藏销毁，多次切走／切回不解除；离开或卸载说明时清理，保留 Settings 的原导航栈。该生命周期由说明组件的 layout effect 与 cleanup 持有，不按单次导航或可见性重置；持久页面保留原视图；工具栏弹窗和原生独立面板会因失焦销毁，故在切换前由后台在来源窗口创建或复用 `popup.html#binding` 标签页，直接展示同一只读配置说明。该标签页不自动执行代码，不新增权限或持久状态；普通快捷键设置入口不创建说明页。此承载例外仅服务一次性配置，不改变普通主面板的失焦行为或定位目标。

## 未采用的方案

不在扩展自身环境或网页 MAIN world 执行任意保存代码，不将本地脚本收藏扩展为油猴兼容层，也不持久化执行结果。
