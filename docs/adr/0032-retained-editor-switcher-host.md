# 0032 · 跨标签编辑期间的快捷切换器承载

状态：已采纳。日期：2026-10-23。

## 背景

Hop Badge 编辑和快捷键配置指南需要暂时访问其他标签页。快捷切换器与命令面板共用网页浮层承载时，替换浮层会结束原任务，单纯允许来源标签失活不能保留草稿。

## 决策

来源网页存在需要跨标签保留的任务时，快捷切换器使用既有独立窗口承载，保留原网页任务。确认切换、取消和重复启动均不结束原任务；离开任务后恢复普通承载选择。定位与尺寸沿用 [0010](0010-content-anchor-panel-geometry.md)，按键交接、松键确认和取消沿用切换器既有契约。

## 取舍

该场景接受独立窗口的系统边框与焦点交接，以避免销毁草稿或同时维护两个网页模态浮层。不增加新的承载类型，不改变普通网页上的默认切换器。
