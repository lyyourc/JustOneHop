# 架构决策记录（ADR）

[返回 README](../../README.md)

## 维护方式

- 有影响长期实现的选择、明确的替代方案和取舍时，新增编号；普通修复、视觉微调和测试结果不单独建 ADR。
- 每份只讨论一个决策主题，标明状态与记录日期；历史补录注明依据，不虚构原始决策时间。
- 决策改变时新增记录，并在旧记录标明被哪份替代，保留原有理由；当前操作和接口说明同步修改对应参考文档。
- 更改本文件中的描述不等于获得接口变更授权；实现变更仍遵守项目的确认规则。
