# ADR 0014 · 最近一周历史混搜与显式全部时间搜索

- 状态：已采纳
- 日期：2026-10-17
- 更新：0003 的搜索来源、0007 的历史请求等待边界；0011 的原生页面命令仍仅负责跳转

## 背景

用户希望找回从任意入口访问、已经关闭且没有收藏的页面。Chrome 历史接口支持按关键词和时间范围查询；异步响应不能让候选不断插入，或把 Enter 的目标替换成另一项。用户明确选择安装时申请权限，并要求默认搜索最近一周、等待预算 100ms。

## 决策

使用必需 `history` 权限与 `chrome.history.search`，主搜索范围为最近七天，最多返回 100 个匹配页面。100 是返回上限，不是只搜索最近 100 个页面。历史不加入浏览器状态快照，也不维护跨次打开的缓存或持久索引。

UI 对整个请求（含消息传递）设置 100ms 等待预算。每轮查询仅提交一次合并结果，超时后保留其他来源结果并忽略迟到响应；查询切换也使旧响应失效。等待时保留上一轮列表但禁止执行，输入和返回可用。无匹配、超时和读取失败分别说明。

明确搜索历史功能（如 `history / 历史 / 搜索历史`）时将入口置顶并进入空的历史搜索框，返回保留主搜索命令词；普通关键词继续携带原词。在普通关键词下固定在第 7 条插入「搜索全部历史」，不足六个普通结果则置于末尾；无普通结果时成为唯一候选。这个导航入口不参与排名，包含入口后的总展示上限仍为 100 条。它承接用户主动接受等待的意图，在二级列表保留关键词并用 `startTime: 0` 搜索全部时间；超过 150ms 展示加载状态，15 秒未完成提供重试。仍设置 100 个返回上限并明确提示截断，不承诺无限分页。

历史条目进入已有相关性等级，主搜索与全部历史子页均在同词同级内先比较学习权重，再优先匹配的标签页、书签，历史之间再比较最近访问。仅删除与匹配标签页／书签同 URL 的历史候选，不改变原有标签页与书签之间的重复关系。URL 比较保留路径、查询和片段。打开在来源窗口新建标签页，仅接受 HTTP(S)。无痕来源不读取普通历史，也不记录选择。

历史与主搜索共用 `SearchResultItem` 呈现和文字选择语义：普通单击、Enter 与底栏主操作仍打开页面，拖选结果文字后松开鼠标不导航、不学习。两处 Actions 均为带 URL 的候选提供「复制 URL / Copy URL」，复制完整 URL（含查询参数与片段），不打开页面、不写学习；成功后保留面板、query、selection 与输入 caret／选区。入口与焦点契约见[交互架构](../INTERACTION-ARCHITECTURE.md#候选项呈现)。

### 2026-10-27 · 历史读取与页面操作的校验边界

历史查询读取浏览器历史，不操作来源页，因此不要求来源文档地址、标签页地址快照与当前地址相等或同源。地址变化不应使主搜索与全部历史查询失败；仍验证扩展身份、面板上下文、来源标签与窗口有效性，并拒绝无痕来源。打开结果会改变浏览器页面，继续单独校验来源标签、窗口、预期地址与导航状态，避免旧结果操作已经变化的页面。

### 2026-10-17 · 历史学习修订

用户搜索 `c2c-web` 并选择 `g.echo.tech/c2c-web` 历史结果后发现没有学习，暴露出原「历史不学习」决策打断了同一页面的偏好连续性。现仅在显式选择并成功打开后记录 query + 完整 URL，历史与标签页共用既有 `tab:<URL>` 身份，打开后变为标签页仍继承习惯；查询参数、片段差异保留，书签仍按 `bookmarkId` 独立。主搜索与全部历史子页对有适用学习记录的结果统一显示右侧历史小图标；hover / focus 的 tooltip 仅含一句排序原因和删除动作标题「忘记此搜索词的偏好 / Forget Preference for This Query」，图标同时变为 X，点击直接忘记。不常驻 Habit boost／Remembered 文字，Actions 不保留排序解释或 forget 动作。键盘选中行的图标可 Tab 聚焦、Enter / Space 忘记，也支持 Shift+Backspace 忘记当前选中项；输入法组合（含 `keyCode === 229`）、repeat 或额外 Ctrl / Alt / Meta 均不触发快捷键，无选中项或无适用记录不执行，列表不可执行或更深层开启时也不触发。图标与快捷键共用删除逻辑，不触发打开页面、输入删字或返回；图标键盘激活同样遵守输入法、重复和额外修饰键保护。从历史或标签页展示忘记均清除同一归一化 query + URL 偏好；空首页命令的标题为「忘记此命令的偏好 / Forget This Command’s Preferences」，仍清除该命令所有 query（含空查询）的记录。

删除成功后对应图标消失，执行忘记的当前列表保留查询、顺序、选中身份与滚动位置，并恢复输入焦点与选区；修改查询或重新打开面板时才按新偏好排序。其他面板继续按现有 storage 事件同步记录及对应图标。页面关闭、新历史结果等真实数据变化仍正常更新列表；本面板设置中的全量重置会解除本地保序并恢复默认排序。失败保留记录并反馈错误供重试。统一删除范围与存储语义见 [ADR 0003](0003-unified-search-and-local-learning.md#学习身份与可解释排序)。

不持久复制整个浏览历史，只在本机保存显式成功选择的 query、URL 及衰减权重／时间；历史 API 读取本身和失败不记录，无痕不记录选择。沿用学习记录最多 500 条、90 天未使用失效、权重每 14 天减半的规则，主搜索 100ms 等待与两种历史查询的 100 条上限不变。本节记录修订原因与当前决策，不改写旧构建的验收结论。

### 2026-10-22 · 拼音补充召回

Chrome 的字面查询无法召回仅在中文标题中命中的拼音，因此包含至少两个拉丁字母词的查询，在原时间范围内额外检查最近 1000 个页面，补入全拼或连续首字母匹配。保留原生关键词查询，使更早的字面命中不受补充扫描上限影响；合并去重并按统一相关性排序后仍最多返回 100 项。达到任一读取或返回上限均提示，可改用中文原文查找较早内容。不预加载、不新增持久索引或权限，隐身限制与等待预算不变。这接受了拼音无法覆盖超过扫描上限的旧页面的限制，换取有界本地工作量。

## 备选与代价

- 不采用最近 N 页预加载：会漏掉范围外的匹配，还需维护缓存更新和失效。
- 不采用逐批插入结果：破坏鼠标和快速 Enter 的目标稳定性。
- 不把全量入口放到第 100 条之后：不易发现；也不新增常驻提示条挤占面板高度。
- Chrome 的候选召回语义不等同于 zing 的本地模糊匹配；后续排序无法恢复未被 Chrome 返回的页面。
- Chrome API 无取消参数，超时是 UI 停止等待而非终止浏览器查询。历史查询故障不阻断标签页、书签与命令。
- 必需权限的 Chrome 提示涵盖读写能力，产品实现仅使用读取能力；已有用户升级新增权限可能需重新确认。

具体组件契约见交互架构，实际测试范围见验收记录。
