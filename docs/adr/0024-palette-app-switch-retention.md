# 0024 · 跨应用切换保留命令面板

状态：已采纳。日期：2026-10-21。部分替代 [0019](0019-two-palette-hosts.md) 的失焦关闭规则；承载与定位方案不变。

## 背景

搜索或管理标签页期间，用户可能暂时切换应用查看消息、复制内容，再回来继续。页面不可见既可能来自切换标签页，也可能来自窗口遮挡或应用切换；窗口失焦同样不能独立表示退出意图。用这些信号直接结束命令面板会丢失搜索与当前视图。

## 决策

- 命令面板及其二级视图跨应用切换保留会话，不主动恢复窗口焦点。
- 切走来源标签页、来源页导航或关闭时结束会话；网页配置指南继续允许跨标签查看。
- 独立窗口在 Chrome 内转向其他浏览器窗口时仍关闭；跨应用返回来源窗口时保留面板，允许系统完成窗口焦点交接。
- Esc、面板外点击、重复启动与动作完成后的原有退出语义保留。
- 快捷键启动的 Tab Switcher 继续失焦取消，其修饰键松开语义不适合跨应用挂起。

## 取舍

保留的是现有面板内存中的状态，不新增持久存储、权限或跨页面迁移。独立窗口在跨应用返回时可能仍在来源窗口后方，用户可直接选择该窗口继续；不通过自动聚焦打断用户当前操作。来源切换按浏览器标签生命周期识别，不能依赖页面可见性推断。
