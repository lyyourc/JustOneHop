# ADR 0011：Chrome 内置页面与当前窗口复用

- 状态：已采纳
- 日期：2026-10-17

## 背景

用户需要从统一搜索直达扩展管理、密码管理器等 Chrome 功能，并明确这类快速跳转的职责。Chromium 将相关实现称为 WebUI，但该术语描述实现技术；面向用户采用已确认的「Chrome 内置页面 / Chrome Pages」。

## 决策

通过固定页面映射扩展现有命令候选和后台执行流程，不新增路由框架。每个目标拥有独立命令身份和本机学习记录；中英文别名与分类均可直接检索，空搜索不展示。Chrome 设置与 zing 自身设置保持独立意图。

仅复用来源窗口内地址一致的页面，否则在该窗口新建标签页。保留子路径、查询参数和片段差别，避免从扩展详情或设置子页跳走；执行前核对候选页仍属于来源窗口且地址匹配。现有扩展快捷键入口共享同一导航行为。

只导航，不读取密码、历史或下载数据，不增加权限。不把 `chrome://inspect` 或调试协议连接称为「打开当前页 DevTools」；后者仍是单独的待解决需求。

## 取舍

相比每次新建，复用可避免重复标签；相比按主机名复用，完整目标匹配能保留用户正在操作的详情与筛选状态，但可能让同一类原生页面拥有多个不同地址的标签页。只在当前窗口查找，不会突然切换到别的工作窗口。浏览器原生页路由可能随版本变化，因此实际目标可达性由浏览器测试验证，不能仅依靠地址常量或模拟 API 判断。
