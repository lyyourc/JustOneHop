# ADR 0028：本机自定义搜索图标

- 状态：已采纳
- 日期：2026-10-22

搜索入口是高频可见位置，允许用户选择 Emoji 或本地图片可以提供轻量个性化。默认仍使用品牌标志；自定义仅影响搜索入口，不改变扩展工具栏、管理页图标及按钮功能。补充 ADR 0023 的搜索框图标来源。

选择所有搜索入口共享同一偏好，避免主搜索、二级搜索和 Tab Switcher 之间出现外观跳变。保持现有槽位和操作语义，允许用户选择的图标保留彩色，列表类型图标继续遵守原有视觉规范。

采用预览后显式保存，便于检查图片和组合 Emoji、放弃草稿及恢复默认。偏好沿用本机扩展存储；图片转换为有界的小尺寸静态 PNG，不请求远程图片，不增加权限、同步服务或裁剪编辑器。代价是 Emoji 外观取决于系统字体，用户图片不自动重染色，无法保证每张图片在深浅背景上都有相同辨识度。

组件行为见 [交互架构](../INTERACTION-ARCHITECTURE.md)，验证边界见 [验收记录](../ACCEPTANCE.md)。
