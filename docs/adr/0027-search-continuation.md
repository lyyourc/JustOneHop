# 0027 · 短期查询作为补全提示

- 状态：已采纳；补充 [0026](0026-local-query-completion.md)
- 日期：2026-10-22

## 背景与决策

打开一个搜索结果后，用户可能回来继续选择其他页面。将「继续搜索」加入结果列表会引入一类新的候选；改为复用现有浅色补全提示，接受前保留首页和 Enter 语义。

每个来源浏览器窗口保存最近一次符合条件的查询：非空主搜索至少有两个不同的可用页面，且成功打开标签页、书签或历史结果。10 分钟内，空输入显示完整查询提示，匹配前缀时优先于长期习惯补全。命令、直接网址、Google 搜索及隐身不产生短期记录。

短期记录采用浏览器会话存储，后台休眠后仍可恢复，浏览器重启后清除；与长期学习分别保存但共用忘记和重置入口。快照只提供来源窗口记录，接受提示不记录一次新的选择。

## 取舍

保留首页默认动作，用户显式接受后才恢复查询。过期时间限制旧意图的干扰；每个窗口只保存一条，不提供独立的搜索历史列表。继续搜索只覆盖主搜索页面选择，二级视图沿用自身返回和查询恢复规则。
