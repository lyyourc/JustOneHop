# ADR 0016 · 来源页删除即结束面板

- 状态：已采纳
- 日期：2026-10-18
- 部分替代：[ADR 0012](0012-continuous-tab-management.md) 的来源关闭后接续、独立面板新建／重绑与跨承载状态传递；非来源页整理保留面板规则继续适用

## 背景

0012 为连续整理引入关闭来源页后的会话接续：网页浮层转为独立面板，已有独立面板重绑到同一窗口的活动页。用户的 Human First 判断是，结束当前页后应回到 Chrome 自然选中的相邻页；额外 popup 会抢走焦点，保留搜索不应成为改变这一浏览器习惯的理由。

来源页是本次唤起绑定的标签页，不一定是关闭命令所选的目标。对另一页执行「关闭其他」或「关闭右侧」时，也可能连带删除 source，因此生命周期必须按实际删除结果判断。

## 决策

任何 source 实际被删除，都结束当前 zing 会话。直接 close、批量操作连带删除、Chrome 外部关闭采用同一规则；关闭来源窗口或最后一页同样结束。即使批量操作部分失败，只要来源已删除，就不能保留该会话。

网页浮层、action popup 与已有独立面板遵循同一规则。来源删除后绝不另建接续面板，也不复用或重绑已有独立面板到接替标签页；不转移查询、选择或输入位置，迟到请求不得恢复已结束面板。焦点交给 Chrome 自然选中的相邻页，用户需要继续使用时重新唤起 zing。

只关闭非来源页（含未删除来源的批量关闭）仍保留面板、查询和输入光标／选区；所选结果消失时按原顺序选择下一幸存项，末尾选择上一项。固定、静音等整理及导航成功后退出的既有规则不变。鼠标、键盘、底栏与菜单共用同一生命周期判断，固定标签页保护不变。

## 旧接续迁移与边界

旧 continuation 底层已移除。为兼容旧调用方，`Execution.paletteState` 接受但忽略，`palette-state` 返回 `undefined`，`cancel-palette-continuation` 为 no-op；不保存或恢复接续状态，不创建、重绑或聚焦任何窗口。窗口会话仍保存 token、source 与 popupId，供正常独立面板使用，不包含接续状态；后台 wrapper 继续负责关闭操作的来源验证。这些兼容空入口不提供会话接续能力，也不构成浏览器验收声明。

窗口承载与定位不变：普通网页保留浮层，Chrome 内置页使用独立面板，地址栏等受限场景保留工具栏弹窗兜底；系统标题栏和 [ADR 0010](0010-content-anchor-panel-geometry.md) 的内容区几何估算及限制不变，暂停中的屏幕定位目标不在本轮恢复。

0012 保留原有背景与取舍，并标记部分被本记录替代；当前文档不再将会话接续描述为可用功能。书签结果按所选 ID 删除的范围见 [ADR 0015](0015-native-tab-bookmarks.md)，这类成功整理继续保留搜索上下文。

## 备选与代价

- 保留自动接续会使用户在结束当前页后额外面对 popup，并让既有面板改变来源，因此停止采用。
- 只处理直接关闭 source 会遗漏批量连带删除；必须覆盖实际删除来源的所有路径。
- 只关闭非来源页时也退出，会打断连续整理，因此仍保留这一场景的搜索上下文。
- 来源删除后搜索上下文不再接续，用户需重新唤起面板；接受这一代价，以保持 Chrome 的自然焦点与相邻页行为。
