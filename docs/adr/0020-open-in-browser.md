# ADR 0020：主搜索地址直达

- 状态：已采纳；搜索与修饰键适用范围由 [ADR 0021](0021-google-search.md) 补充
- 日期：2026-10-18

> 以下保留原决策及理由。0021 增加普通文字的 Google 搜索候选，并将新开修饰键扩展到该候选；下文「不加入网页搜索」与「仅地址候选」描述原始范围，当前行为以 0021 为准。地址解析、去重与来源保护继续沿用。

## 背景

用户希望像地址栏／Open in Browser 一样，输入地址后能在当前页或新标签页打开，并明确 macOS 使用 Command+Enter 新开。既有主搜索只检索浏览器对象与命令，普通 Enter 执行选中项，修饰键 Enter 默认被拦截。

## 决策

在主搜索按原始输入生成「访问网址 / Go to URL」候选；如果本轮匹配的标签页、书签或历史结果已有相同规范化完整 URL，就不再生成重复候选，否则置于普通匹配之前。去重保留协议、路径、参数和片段区别，不以同域名或字符串包含判断。复用结果行、底栏和 ActionMenu。普通点击／Enter／底栏主操作导航来源页；macOS Command+Enter、Windows/Linux Alt+Enter 及可点击的次要操作在来源窗口新开并激活。仅地址候选声明此修饰键例外，不扩展到普通命令、书签或历史。

首版支持 HTTP(S)、裸域名、localhost 与 IP／端口；域名补 HTTPS，localhost／回环补 HTTP。使用共享解析函数，拒绝脚本等其他协议、凭据、控制字符、空白与反斜线；展示规范化目标，后台只接受已规范化的绝对 HTTP(S) URL。普通文字仍走本地搜索，不加入网页搜索或在线联想，不新增权限或持久状态；地址动作不写学习。

来源使用本次会话绑定的 tabId、windowId 与 expectedUrl。后台独立核对 sender 映射和实时状态，来源变化时拒绝，不导航面板自身或重绑相邻页。固定来源页禁用原地跳转，仍允许新开。新开始终创建，不复用现有同 URL 页。成功发起导航后退出，失败保留输入并反馈。

## 取舍

- 已有相同完整地址结果时沿用其切换／打开动作，不额外占一个结果位置；不同路径等仍提供访问入口。名称直接描述「访问网址」，避免在浏览器中重复强调打开浏览器。
- 沿用主搜索历史查询最多 100ms 的批次提交，确保看到并执行同一输入的结果，暂不引入独立的即时地址批次。
- 使用独立地址动作而非改写书签／历史默认语义，避免已有 Enter 使用习惯变化。
- HTTP(S) 范围不等同于完整 Chrome Omnibox，Chrome 内置页仍走既有命令。
- 窄屏次要按钮采用已有图标折叠方式，完整名称、快捷键保留在 tooltip 和操作菜单。

## 验证

按测试指南验证解析、来源校验、快捷键和定向浏览器链路；实际构建、用例及限制记录在验收文档，本决策本身不代表验收通过。
