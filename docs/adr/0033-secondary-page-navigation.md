# ADR 0033：普通二级页统一顶部返回与底栏提示

- 状态：已采纳；验证范围见验收矩阵
- 日期：2026-10-24
- 关系：覆盖 ADR 0009 的普通列表页底栏返回位置，扩展 ADR 0030 的顶部徽章与精简底栏至普通二级页；保留 ADR 0029 的任务／详情顶部形态

## 背景与决策

设置采用顶部旋转徽章返回后，存储、历史与标签组仍以同一徽章聚焦搜索、在底栏返回，用户跨页时需要重新判断相同入口的用途。普通二级页面统一使用顺时针旋转 90° 的顶部徽章逐级返回，底栏不再重复返回入口；返回首页时徽章转回正向。搜索仍通过真实输入框进入，无焦点时沿用 Tab 恢复。

底栏统一承载固定标题、pet 与共享提示／反馈槽。列表页按需展示列表导航，详情、帮助和表单页展示控件导航；本机隐藏 pet 的偏好适用于这些页面。来源域名、数量与操作结果仍使用共享文字区，操作反馈优先。固定槽位使跨页位置稳定，代价是长标题需要截断、窄屏辅助上下文可能不显示。

## 2026-10-27：展开键盘提示保留页面上下文

来源域名、历史范围与组内成员数量帮助用户确认当前页面，展开键盘提示不应使这些说明消失。有页面上下文时，键盘提示使用 pet 上方的提示浮层；无上下文时仍优先同排显示。这样保留说明与底栏按钮的位置，代价是展开期间占用面板底部上方的少量空间。操作结果与错误继续优先于键盘提示；窄屏上下文的既有空间限制不变。

## 语义边界

没有父页的独立帮助窗口保留搜索聚焦与明确关闭入口，不展示虚假的返回。Tab Switcher 的徽章用于启用搜索，关系到松开修饰键确认流程，保留专用搜索、返回与取消路径，不套用普通二级页的按钮语义。

菜单与确认层优先退出、查询与选区恢复、输入法保护、减少动态效果及双承载边界沿用交互架构；迁移入口不改变操作执行与存储权限。
