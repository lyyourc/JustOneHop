# 0017 · 移除脚本收藏与 UserScript，独立保留快捷键配置指南

- 状态：已采纳
- 记录日期：2026-10-18
- 替代：[ADR 0005](0005-explicit-user-script-execution.md)；其中 Ctrl+Tab 配置说明跨页保留的行为迁入本决策
- 部分更新：[ADR 0002](0002-shared-actions-and-navigation.md)、[ADR 0003](0003-unified-search-and-local-learning.md)、[ADR 0009](0009-list-page-footer-breadcrumb.md) 中的脚本页面、搜索入口及相关交互契约

## 背景

产品决定移除脚本收藏及已保存 UserScript 功能。Ctrl+Tab 配置仍服务于 Tab Switcher，应可直接从设置访问，不再依赖脚本列表或通用代码编辑、运行能力。

## 决策

移除脚本收藏列表、新建／编辑／删除、脚本名称搜索、运行选择、执行结果及运行并复制结果的入口和实现。主搜索、首页推荐、设置与内置帮助不再宣传这些功能；移除相应数据读取、消息接口、执行逻辑和 `userScripts` 权限。其余浏览器命令、页面存储与标签切换沿用既有权限和交互边界。

`BindingGuide` 是独立只读组件，由设置「键盘 → Tab Switcher」直接打开，并由 `popup.html#binding` 复用。`settings:binding` 仅在搜索时提供，以 Ctrl+Tab／bind Ctrl+Tab／设置 Ctrl+Tab 等别名定位 Settings 的配置控件，不经过脚本库。指南复用现有底栏、操作菜单与返回路由，保留「复制并打开」、单独复制命令、单独打开 Chrome 快捷键页及操作反馈。配置命令填入当前扩展 ID，用户仍须在 Chrome 快捷键页的 Console 显式粘贴执行；扩展不执行任意用户代码，也无需开启「允许用户脚本」。

继续保留配置说明的跨页生命周期：普通网页浮层在指南挂载期间通过 `BindingNavigation` 暂停隐藏销毁，可反复切走与切回；离开指南时恢复正常行为及设置上下文。持久页面保留原指南；工具栏 popup 与会失焦关闭的独立面板，在跳转前于来源窗口创建或复用非激活的 `popup.html#binding` 标签页。复制失败不导航，退出后的旧复制回调不得继续导航。普通快捷键修改入口、其他面板生命周期及定位不受影响。

## 旧数据与历史记录

旧版 `saved-script:*` 数据原样留在本机，不读取、不使用、不迁移、不覆盖，也不自动删除。不增加清理任务或破坏性迁移，不因移除入口而清空扩展存储中的其他数据。

历史 ADR 保留原决策及理由，并标注替代范围；既有验收记录仍只证明当时构建与用例，不追溯改写或视作移除后的验收。采纳本决策及更新文档不等于已经完成实现验证。

## 取舍与未采用方案

- 不再支持保存、复制或运行任意脚本，减少相应页面、协议与权限维护；需要这些能力的用户须使用其他工具。
- 保留只读的一次性快捷键配置用途，避免为了配置 Tab Switcher 继续维护通用脚本库。
- 旧数据可能继续占用少量本机空间；接受这一代价，避免在移除功能时不可逆删除用户内容。
- 不保留隐藏的运行入口、旧执行接口或自动清理迁移；不把 Ctrl+Tab 配置命令改成扩展自动执行。
