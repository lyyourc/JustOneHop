# 0003 · 统一搜索、相关性优先与本机学习

状态：已采纳；脚本搜索与首页入口于 2026-10-18 由 [ADR 0017](0017-remove-script-library.md) 移除。记录日期：2026-10-15，基于现有实现与历史验收补录；不代表这些决策在同一天首次作出。

以下保留原决策及修订历史，其中脚本候选、Script Library 默认推荐与脚本学习边界不再代表当前可用功能；首页去掉 Script Library 后，其余默认入口顺序与最多 10 项上限保持不变。当前搜索与推荐契约见[交互架构](../INTERACTION-ARCHITECTURE.md)。

## 背景

切换命令与标签搜索模式增加了记忆负担。宽泛模糊匹配曾让 iam 命中 New Tab；同词常选结果又需要更容易找到。

## 决策

移除 `>` 模式与模式按钮，标签页、书签、命令和脚本在同一入口检索。命令使用分类前缀，网站结果保留原始标题；关闭类命令通过明确关键词或操作菜单进入。

按精确命令/别名、完整标题、名称前缀、词边界、名称包含、辅助字段及有限模糊匹配区分相关性。三个字符以内不扩展错字（中文拼音与首字母召回见下文修订）；中文、网址、目录、拼音和辅助关键词不扩展错字。长英文名称的容错限定在相近长度的单词，多词逐词验证。

2026-10-16：网站域名也作为名称参与字面相关性排序（忽略开头的 `www.`），避免中文页面标题使 `sls` 等服务名只能获得辅助字段的低优先级。路径、查询参数和书签目录仍是辅助字段，域名不增加错字容忍。精确意图、完整标题和同词使用习惯优先级不变；其余同等相关结果中，命令名称匹配优先，再优先固定标签页、已打开标签页、书签，之后才比较 Fuse 分数与原始顺序。固定状态不跨相关性等级提权，也不让未命中的页面进入结果。当时空搜索与 Tab Switcher 的 MRU 不受此次相关性调整影响；首页随后由下述 2026-10-18 推荐决策取代。

2026-10-20（页面名称精确匹配）：`justonehop` 查询中仓库首页的标题以作者名开头，反而落在大量标题以仓库名开头的文档之后。为识别页面本身，HTTP(S) URL 最后一个非空路径段与完整归一化查询相等、且标题包含该查询时，新增位于完整标题与名称前缀之间的相关性等级。忽略大小写与末尾斜线；祖先路径、查询参数、片段、部分名称及无标题佐证的路径仍按原等级处理。主搜索与全部历史共用规则，适用于标签页、书签、历史；保留多词 AND 和同级学习，不增加域名特例、同源打散、缓存或权限。

2026-10-22（中文拼音与首字母）：中文名称与辅助内容可按无声调全拼或连续首字母检索，从汉字音节起点匹配，允许末音节尚未输完；至少两个拉丁字母，避免单字母召回大量无关中文。使用随包的本地词典处理常见词组读音，不依赖网络，也不穷举所有多音字组合。字面相关性等级完整保留，拼音命中位于全部词均有字面命中的结果之后、英文错拼之前，学习不能越级。匹配与高亮使用相同语义，中文命中仍显示原文；已有危险意图门槛不因首字母放宽。Tab Switcher 搜索中先字面、再拼音，两组内保留 MRU，空搜索保持原 MRU。

仅成功执行记录使用习惯；同一查询的频率与近期使用影响同一相关性等级内结果的先后，不能跨等级或把无关项重新引入。空搜索采用下述跨查询聚合的混合推荐；Tab Switcher 单独保留 MRU。记录只在本机保存，支持按范围忘记与全量重置；无痕不记录选择。

2026-10-18（首页推荐修订，取代此前「最近标签页在前、常用命令在后」及仅调整默认入口顺序的方案）：空搜索只有一组「推荐 / Suggested」，页面与命令混排，最多 10 项。冷启动依次为 Settings、Help、Tab Switcher、Script Library、Search All History、New Tab、Reload Tab、Pin/Unpin、Local Storage、Cookies；条件满足时保留安全的撤销收起／恢复收起组入口，仍受 10 项上限约束。关闭类危险命令及仅搜索项不进入首页；静音切换、恢复关闭标签页、Session Storage 保持仅搜索，静音仍有标签页菜单入口。Settings 子项仍只定位控件。

页面仅在已有 zing 成功选择记录时参与推荐，从当前窗口标签页与书签召回，不以 MRU 冷启动补位、不预加载历史。完整 URL 去重并排除当前 URL，优先当前窗口已打开标签页；仅首页合并 `tab:<URL>` 与相同 URL 的已学习书签，跨查询汇总频次与衰减权重，含显式空查询。沿用每 14 天减半、90 天未使用失效及最多 500 条记录。有词搜索仍按 query + target、同词同相关性等级排序，书签身份独立，不迁移或合并底层记录。

首页推荐分数在打开面板／来源会话开始时捕获，查询往返、子页返回、学习及忘记不重排当次首页，下次打开刷新；真实数据移除仍更新候选。本面板设置的全量 Reset 立即恢复默认首页与排序。首页 Cmd/Ctrl+↑/↓ 跳首尾，不再分组跳转；立即 Enter 执行第一条推荐，不承诺回到上一页。无痕首页仅默认入口，不读取普通窗口习惯。不新增权限、收藏、隐藏、「不再推荐」或推荐管理页。

「Zing: Tab Switcher」是可搜索的 UI 导航入口，打开当前 host 内的共享切换子页，不学习入口本身；初始搜索可用，显式点击／Enter／底栏确认，没有松键确认，取消／Esc／底栏返回恢复父 query、selection、caret。原快捷键切换路径不变，见 [ADR 0006](0006-recent-tab-switcher.md)。此修订记录批准的行为，不扩展旧验收的构建或用例范围。

2026-10-17：用户输入 `clo` 却只看到恢复关闭内容，原因是关闭安全门要求完整词。明确动作意图现在包含有界前缀：`clo / clos / close`、`guan / guanb / guanbi` 及中文「关闭」；不把 `cloud / closed / disclose`、单独类别名或关闭动作错字视为关闭意图。为自然的逐字输入保留结果发现，空首页仍不展示危险操作，批量关闭继续保护固定页。扩展重载指向同样支持 `ext` 起的 extension 前缀。添加 `close / 关闭` 精确别名，让完整关闭意图优先指向当前页。

多词查询继续按 AND 校验，词首相关性不再要求整段连续或固定词序，`des not / not des` 优先命中 `Design Notes` 而非 `Redesign Notebook`。匹配别名提示覆盖前缀、换序及已有英文容错。原实现将名称前缀至辅助字段合并为一个学习组，导致历史 URL 路径选择压过名称；现按每个等级比较后再使用习惯。同等级的固定／已打开标签偏好保持不变；此次查询匹配调整不涉及首页或 Tab Switcher。

2026-10-17（样本场景复核）：继续使用 Fuse.js，不引入第二个匹配库。以代表性工作标签、书签目录、组名和本机选择历史测试日常词汇，补齐 page／页面、last／上一个、dark／深色、English／英文等明确别名，不做全局停用词删除或无约束语义猜测。别名建立索引时统一归一化，提示仍保留原始大小写。普通相关性与学习权重相同的命令以覆盖全部查询词的最短名称／别名优先于 Fuse 聚合分数，避免较多别名人为放大排名；有限英文错字候选中，完整单词命令优先于长名称的局部词命中。设置目标只导航到控件，不直接修改值。样本不来自个人 Chrome 数据，不能代表全部真实查询的准确率。

2026-10-17（状态与边界补验）：固定／静音的别名由目标当前状态生成，不再把相反状态的精确取消意图索引为可执行切换动作；通用功能词仍用于发现当前动作。主搜索和菜单沿用同一候选生成逻辑，命令 ID、后台实时状态校验及学习身份不变。

### 学习身份与可解释排序

标签页与历史的 `usageTarget` 使用 `entry.url` 生成同一个 `tab:<URL>`，不从 keywords 取值；完整 URL 保留查询参数与片段差异，历史打开后变为标签页或「已收起」状态均不改变学习身份。书签仍按 `bookmark:<bookmarkId>` 独立记录。设置子项使用独立的 `command:settings:<section>`；旧 `command:settings` 不拆分、不向子项迁移，仅保留给通用设置，避免把过去的通用入口偏好猜作具体设置意图。

主搜索与全部历史子页把各自同批候选分别按有习惯和无习惯的规则排序，在结果截断与固定入口插入前比较位置。仅有适用学习记录的结果在右侧显示历史小图标，不常驻「习惯前移 / Habit boost」「已有记录 / Remembered」文字。hover / focus 图标时，tooltip 只用一句短文说明实际前移或已有记录但本次未前移，再显示对应的删除动作标题；完整删除语义留在使用文档，不在 tooltip 展开。图标同时变为 X，点击直接忘记。非零权重不等于实际提位；有词搜索仍守同词同级边界，首页图标则基于页面聚合权重。

排序原因与忘记操作统一由结果图标承载，右键、底栏 Actions 与 Cmd/Ctrl+K 菜单不保留冗余说明或动作。键盘选中行的图标可 Tab 聚焦，Enter / Space 只执行忘记，不触发行主动作；也可在主搜索与全部历史列表按 Shift+Backspace 忘记当前选中项。两种入口共用删除逻辑与执行状态；快捷键不接受额外 Ctrl / Alt / Meta，输入法组合（含 `keyCode === 229`）、长按 repeat、无选中项或无适用记录均不执行，菜单等更深层开启或列表不可执行时也不触发。有效触发不删输入文字、不触发 Backspace 返回；图标键盘激活同样遵守输入法、重复和额外修饰键保护。

有查询时，「忘记此搜索词的偏好 / Forget Preference for This Query」仅删除归一化 query + target，历史与标签页展示共用该偏好，任一处忘记均对两者生效；空首页命令的「忘记此命令的偏好 / Forget This Command’s Preferences」删除该 target 在所有 query 下的记录，含空查询。首页页面的「忘记此页面的偏好 / Forget This Page's Preferences」将完整 URL 与同 URL 已学习书签在所有 query 下的记录作为一个范围原子删除，不按身份分多次写入。归一化沿用去首尾空白、转小写与合并连续空白。删除与写入、重置共用后台串行队列，其他面板按现有 storage 事件同步记录及对应图标。

删除成功后对应图标消失，执行忘记的当前列表保留查询、顺序、选中身份与滚动位置，并恢复输入焦点与选区；有词搜索修改查询后重排，首页即使查询往返或子页返回也保持当次顺序，直到下次打开。页面关闭、新历史结果等真实数据变化仍正常更新列表；本面板设置中的全量重置解除本地保序，立即恢复默认排序及首页入口。失败保留记录并在当前列表反馈错误供重试。

这些入口只删除学习记录，不删除页面或书签，不永久屏蔽学习；之后选择仍可重新学习。设置说明通过结果右侧历史图标及 tooltip 提供查看原因、忘记偏好的发现路径，保留全量重置，不新增开关或单独记录管理页。学习范围为普通标签页、浏览历史、书签、浏览器命令、设置与 Storage 入口；脚本、帮助、Tab Switcher 导航入口、标签组导航、收起恢复核对和扩展重载未接入。2026-10-18 起，页面成功选择显式传入空查询 `''` 也写记录；未提供 query 的切换器执行不学习，缺省查询不得自动转为空串。

2026-10-17（历史学习修订）：用户指出搜索 `c2c-web` 并打开 `g.echo.tech/c2c-web` 历史结果后没有学习。此前排除历史使同一页面随历史／标签页展示而失去偏好连续性，现改为显式成功打开后按 query + 完整 URL 记录，复用既有标签页身份和同词同级排序。仅在本机保存该选择的 query、URL 及衰减权重／时间，沿用最多 500 条、90 天未使用失效及 14 天权重减半；不复制整个浏览历史，历史 API 读取本身、失败及无痕均不记录。此处修订决策，旧验收仍只适用于当时构建与用例，不追溯改写；历史查询边界见 [ADR 0014](0014-history-search.md)。

### URL 复制与结果文字选择

主搜索与全部历史子页的带 URL 候选（标签页、历史、书签等）通过 Actions 提供「复制 URL / Copy URL」，复制候选的完整 URL，保留查询参数与片段，不使用截断说明或检索 keywords。复制属于次要动作，不导航、不写学习记录；成功后保持面板打开，保留 query、选中身份和输入 caret／选区。右键、底栏 Actions 与 Cmd/Ctrl+K 使用同一动作集合。

两处搜索复用同一结果行：拖选结果文字后松开鼠标不执行主动作、不导航、不学习；普通单击仍执行，与 Enter 和底栏主操作一致。这样可直接选择文字或复制完整地址，同时保留单击打开的使用习惯。具体组件与焦点契约见[交互架构](../INTERACTION-ARCHITECTURE.md#候选项呈现)。

## 取舍与影响

放弃宽松模糊搜索的部分召回率，换取可预期的结果。使用习惯不能作为相关性过滤的替代。取消、失败、无痕操作不学习；菜单次要动作不训练该网页的主搜索偏好。

## 未采用的方案

不保留双模式，不以使用频率覆盖相关性，也不上传查询或用远端排序。
