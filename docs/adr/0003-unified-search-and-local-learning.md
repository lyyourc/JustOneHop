# 0003 · 统一搜索、相关性优先与本机学习

状态：已采纳。记录日期：2026-10-15，基于现有实现与历史验收补录；不代表这些决策在同一天首次作出。

## 背景

切换命令与标签搜索模式增加了记忆负担。宽泛模糊匹配曾让 iam 命中 New Tab；同词常选结果又需要更容易找到。

## 决策

移除 `>` 模式与模式按钮，标签页、书签、命令和脚本在同一入口检索。命令使用分类前缀，网站结果保留原始标题；关闭类命令通过明确关键词或操作菜单进入。

按精确命令/别名、完整标题、名称前缀、词边界、名称包含、辅助字段及有限模糊匹配区分相关性。三个字符以内只接受连续字面命中；中文、网址、目录、拼音和辅助关键词不扩展错字。长英文名称的容错限定在相近长度的单词，多词逐词验证。

2026-10-16：网站域名也作为名称参与字面相关性排序（忽略开头的 `www.`），避免中文页面标题使 `sls` 等服务名只能获得辅助字段的低优先级。路径、查询参数和书签目录仍是辅助字段，域名不增加错字容忍。精确意图、完整标题和同词使用习惯优先级不变；其余同等相关结果中，命令名称匹配优先，再优先固定标签页、已打开标签页、书签，之后才比较 Fuse 分数与原始顺序。固定状态不跨相关性等级提权，也不让未命中的页面进入结果。空搜索和 Tab Switcher 的 MRU 顺序不受影响。

仅成功执行记录使用习惯；同一查询的频率与近期使用影响相关结果的先后，但不能越过精确意图或把无关项重新引入。空搜索保留最近标签页，汇总常用命令。记录只在本机保存，并支持重置。

## 取舍与影响

放弃宽松模糊搜索的部分召回率，换取可预期的结果。使用习惯不能作为相关性过滤的替代。取消、失败、无痕操作不学习；菜单次要动作不训练该网页的主搜索偏好。

## 未采用的方案

不保留双模式，不以使用频率覆盖相关性，也不上传查询或用远端排序。
