# 0012 · 整理操作保留面板与关闭来源页后接续

状态：部分被 [ADR 0016](0016-source-close-ends-palette.md) 替代（2026-10-18）。记录日期：2026-10-17。原决策更新 [ADR 0007](0007-refresh-and-loading.md) 的成功后一律关闭策略，以及 [ADR 0001](0001-local-extension-and-overlay.md) 的来源关闭边界。

以下保留原决策及取舍作为历史记录，不代表会话接续仍可用。0016 替代本 ADR 的来源关闭后接续、独立面板新建／重绑、跨承载状态传递及接续后清空选择规则：任何 source 实际被删除（含批量连带与外部关闭）都结束 zing。非来源页整理保留面板、导航成功关闭及共享选择／焦点规则继续适用；窗口承载与定位不变。

## 背景

连续关闭、固定或静音标签页时，每次执行都关闭 zing 会打断搜索与选择。标签组视图已有局部保留行为，但主搜索没有同一规则。普通网页浮层随宿主文档销毁；仅删除 UI 的 onClose 调用无法保留关闭当前页的工作现场，接替网页也未必具有 activeTab 注入授权。

## 决策

按意图区分执行后的去向：整理列表原地刷新，导航到页面则让出界面。保留搜索、光标与仍存在的选中项；删除选中项后按原顺序选下一幸存项，末尾回到上一项。主搜索和标签组共用选择逻辑，菜单完成后收起并恢复输入焦点。成功确认与使用记录写入保持分离，失败不计入学习。

显式关闭命令删除来源页时，由后台在操作完成后接续同一来源窗口。已有独立面板更新来源；浮层／工具栏弹窗转为现有独立面板，不尝试为新网页申请访问权限。只传输主搜索和标签组的搜索词、选择与光标。接续后清空选择，要求显式导航、输入或点击后才能继续，避免「关闭当前页」随来源改变而在重复 Enter 时误关另一页。

执行携带可选 PaletteState；原生窗口令牌继续决定来源归属，临时状态沿用 storage.session。无新权限、服务端、遥测或持久化数据。删除最后一页或整个来源窗口时结束；接续期间切到其他窗口不抢回焦点；外部关闭来源也结束。后台在接续期间协调来源解析与移除事件，避免自身操作被当作外部取消。

## 取舍与边界

关闭宿主网页后，从无系统边框的浮层转成有标题栏的独立窗口，是现有权限下连续操作的代价。普通网页初次启动仍用浮层，地址栏等启动兜底仍用工具栏 popup；本决策不改变通用承载方式，也不恢复暂停中的屏幕定位工作。几何沿用 ADR 0010 的估算及限制。

刷新当前网页会销毁浮层；收起当前页会切换活动页。这两种操作仍退出，未纳入关闭后的接续。切换标签页、打开书签／Chrome 页面／新标签页和恢复关闭内容同样退出。无匹配结果保留空状态，不自动关闭。

## 未采用的方案

- 所有成功操作都关闭：无法支持连续整理，也与标签组管理语义不一致。
- 所有操作都保留：切换或打开后会遮挡用户希望访问的页面。
- 为接替网页增加全站注入权限：超出现有权限最小化边界。
- 所有普通网页改用独立窗口：改变了已有浮层体验；仅在关闭承载页的接续时使用它。
- 保留「关闭当前页」选中态直接指向接替页：同一 Enter 会在没有重新选择时改变目标。
