# 0026 · 主搜索本地查询补全

- 状态：已采纳
- 日期：2026-10-22

## 背景

统一搜索已通过候选列表帮助用户选择目标，但重复输入较长查询仍有成本。再增加一组历史查询候选会与标签页、书签结果重复，增加辨认和选择步骤。

## 决策

在主搜索框中提供一个浅色前缀补全提示，列表继续只按实际输入匹配目标。接受补全与执行结果是两个独立动作：Tab、右方向键、Ctrl+E 或底栏「补全」接受，Enter 始终执行当前结果。

Tab 仅在搜索框有可接受提示时用于补全；无提示和其他控件保留焦点导航，Shift+Tab 始终反向导航。提供底栏鼠标入口，用户无需记住补全快捷键。二级视图与 Tab Switcher 不扩展为历史查询补全。

复用本机成功选择历史，按衰减频次和最近使用时间选择前缀建议。成功的网址导航及网页搜索保存仅供查询补全的记录，不提升任何结果排名；与现有学习记录共用容量、过期和清除机制。输入与接受提示本身不写入记录，危险命令不提供建议，隐身模式不读取或保存补全历史。

## 取舍

- 单提示保持紧凑，但不提供多个历史查询的轮换选择；继续输入可以缩小前缀。
- 只有显式接受后查询才变化，保留现有 Enter 直达路径，代价是与某些地址栏自动采用补全的行为不同。
- 共用历史使清除和容量保持一致；清除排序习惯也会清除查询补全，网址与搜索查询记录会占用现有容量。
- 不连接在线建议服务，不从未执行的输入或页面标题生成预测。已有本地习惯可立即复用，新的查询需成功执行一次后才成为建议来源。
