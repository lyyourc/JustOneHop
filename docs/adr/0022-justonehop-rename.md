# ADR 0022：产品与内部命名统一更名

- 状态：已采纳
- 日期：2026-10-18

因原名称重名，产品中文名为「小范围瞬移」，英文名为 JustOneHop。按用户最终要求，内部消息、端口、DOM/CSS、注入标记、品牌专用存储键、包名及测试环境变量同步使用 justonehop／JUSTONEHOP，不保留旧品牌搜索别名或兼容层。

品牌专用存储键重新开始，不迁移旧会话、收起恢复与时钟记录；已有收起组仍是 Chrome 原生组，新版本不自动继承管理关系。通用 preferences 和 searchUsage 键不含品牌，继续使用。未删除用户旧数据。

所有当前界面与使用文档使用新名称，历史 ADR 与验收记录保留当时名称和证据路径；其中旧技术标识以本记录及当前源码为准。布局、图标和功能不随改名重新设计。
