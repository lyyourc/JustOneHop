# ADR 0015 · 原生标签页收藏与明确取消范围

- 状态：已采纳
- 日期：2026-10-18
- 扩展：0003 的搜索动作、0007 的书签缓存失效、0012 仍适用的保留面板整理操作；来源删除生命周期遵循 [0016](0016-source-close-ends-palette.md)

## 背景

用户需要在搜索与标签页菜单中收藏或取消收藏页面，不必先切换目标或打开书签管理器。同一 URL 可能出现在多个目录，也可能受组织管理；快照与确认后的书签集合还可能被 Chrome 或其他窗口修改，取消必须具有清楚、稳定的作用范围。

## 决策

复用已有 `bookmarks` 权限和 Chrome 原生书签，不建立 zing 收藏库。新增书签默认存入 Other bookmarks，按原始完整 URL 去重，保留路径、查询参数和片段差异；是否同步由 Chrome 设置决定，zing 不增加账号或同步服务。

主搜索 `bookmark tab / 收藏标签页` 作用于来源页，主列表与标签组成员的右键、底栏 Actions 和 Cmd/Ctrl+K 菜单作用于所选标签页，普通点击与 Enter 仍切换页面。两种收藏动作均为 `searchOnly`，取消保留 `danger`。`model` 将中性状态查询 `bookmark / bookmark tab / 收藏 / 收藏标签页` 与明确添加、取消意图区分，按当前状态为中性查询显示收藏或 Unbookmark。明确添加的 `add bookmark / save bookmark / 添加书签` 只提供添加，已收藏时呈现不可执行的「已收藏」状态；取消可从菜单或明确的 `unbookmark / remove bookmark / 取消收藏 / 删除书签` 意图进入。明确添加词、单独 `书签 / tab / close` 或错字不放行取消，明确取消不会反向添加。

收藏在实时树已有相同 URL 时不重复创建。标签页 `unbookmarkTab` 取消单条直接执行；同 URL 多条先显示数量、完整 URL 与目录，默认焦点为取消，确认范围为全部匹配 ID。集合中包含任一 managed 书签时整批拒绝，不先删除可写部分。支持 HTTP(S)、file、FTP、chrome 地址，其他协议不提供该动作。

书签搜索结果菜单新增 `removeBookmark`，显示「取消收藏 / Unbookmark」，右键、底栏 Actions 与 Cmd/Ctrl+K 共用该危险操作；普通点击与 Enter 仍打开页面。它只按所选 `bookmarkId` 删除单个条目，不要求该 URL 存在标签页，不转为标签页取消收藏，也不收集同 URL 的其他 ID 或触发多条确认。同 URL 的其他书签全部保留。managed 检查仅沿所选条目及其祖先执行；其他同 URL 条目受管理不阻止删除所选可写条目。请求携带预期完整 URL，实时目标已不存在或 URL 变化时拒绝旧请求，不能追随已改变的目标删除。标签页取消收藏的全部同 URL 规则保持不变。

后台串行化书签写入并校验来源。标签页收藏／取消重新校验窗口、标签页、预期完整 URL、待导航地址以及适用的组归属，并从实时树核对确认 ID 集合；书签结果删除则核对所选 ID、预期完整 URL 与 managed 祖先，不要求对应的目标标签页。目标或集合变化时拒绝旧请求，刷新后核对重试；不将后来新增的匹配项自动纳入删除范围。每次删除前再次检查。Chrome 不提供批量事务，中途失败须如实提示可能已部分删除，不声称回滚成功。

上述所有书签操作成功后保留面板、查询和输入光标／选区，刷新快照并使用现有底栏反馈；删除所选书签后按共享规则选择相邻幸存项。`App` 主搜索收藏成功后设 `selection = null`，避免第二次 Enter 直接删除；用户用方向键主动选择或点击结果后继续，菜单收藏保留原标签页选中。确认取消逐层返回原上下文；原生书签事件更新缓存与打开的面板，不保存第二份持久书签数据。

早期反馈修订曾将明确添加词也当作当前状态发现入口，并以清空主搜索选择防止连续 Enter 误删；后续又将 `book` 至 `bookmark`、`unbook` 至 `unbookmark` 的独立前缀（可带 Tab／标签页分类）纳入明确意图，并提升对应命令至最高相关性层级。多词页面查询、过短词与错字不享受此提升，裸 `书签` 保留管理器优先。

### 当前决定补充（2026-10-18）

中性 `book / bookmark / 收藏` 仍按状态发现添加或取消；明确的 `add bookmark / save bookmark / 添加书签` 不得因已收藏而变为删除，应显示不可执行的「已收藏」。明确取消（含 `unbook` 前缀）在未收藏时也不得提供添加。此决定替代早期将所有收藏词合并为状态入口的解释：清空选择只能防止连续 Enter，不能替代对明确添加意图的尊重。中性查询收藏成功后清空选择的保护仍保留；本补充是行为决策，不代表已完成验收。

## 备选与代价

- 独立收藏库会让搜索、Chrome 管理器与同步产生两套状态，因此直接使用原生书签；相应地，操作可能随 Chrome 同步到其他设备。
- 不按域名或去掉 query/hash 去重，避免将不同页面视作同一收藏。
- 标签页取消收藏不静默删除第一条重复项，也不跳过 managed 项后继续删除；完整范围需要多条确认与执行前校验。书签结果已有明确条目身份，因此只删除所选 ID，不能因 URL 相同扩大范围或被其他 managed 条目阻断。
- 不为新增收藏增加目录选择器；默认目录保持流程简短，后续可在 Chrome 书签管理器整理。
- 串行队列仅约束 zing 自身写入，不能锁住外部修改；实时校验减少误操作，仍须诚实处理部分失败。
