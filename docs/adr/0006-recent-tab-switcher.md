# 0006 · 标签切换浮层与独立窗口兜底

状态：已采纳。记录日期：2026-10-15，基于现有实现与历史验收补录；不代表这些决策在同一天首次作出。

## 背景

需要按住快捷键选择最近标签、松开确认，并让快速点按直接返回上一页。Chrome commands 不提供全局 keyup；窗口就绪前松开修饰键可能丢失。

## 决策

独立扩展小窗口显示启动时固定的 MRU 列表，打开和导航只移动高亮，松键、Enter 或点击才切页。Esc、失焦、源页失效取消；确认前再次校验目标。

普通 HTTP(S) 页面预加载轻量修饰键监听，在窗口接管前缓冲真实松键；若后台启动前已经松键，则直接确认。受限页面继续使用独立窗口兜底，不以计时器推测用户松键，不安装本机助手。

## 取舍与影响

2026-10-16 更新：普通网页复用 Command Palette 的浮层容器，位置和尺寸一致；独立窗口保留给原生页、无法聚焦网页及注入失败的情况。两种容器共用列表组件，仍在确认时才切页。浮层仅回传目标或取消，后台校验来源页、窗口和会话；不增加权限或持久存储。浮层就绪前的松键与重复快捷键会被缓冲。

两种容器的 `RecentSwitcherView` 共用主搜索的输入胶囊与列表布局，初始空输入且原生禁用，焦点留在候选列表；点击搜索图标、输入区域或 Ctrl/Cmd+F 后才启用并聚焦输入，按标题／URL 做不区分大小写的空白分词 AND 筛选，匹配文字高亮。筛选仅缩小本次会话的窗口候选，保留 MRU，不引入主搜索的学习排序或新权限。修改查询保留仍可见的选择，否则选首项；选中页被关闭或移走时，仅在源页仍可见时回退到源页，否则等待导航、点击或修改查询重新选择。无匹配或无选择不激活标签页。点击搜索框或标准 Ctrl/Cmd+F 显式进入搜索后暂停松键确认，可松开修饰键正常输入，再以普通 Enter、行点击或底栏确认；底栏由松键提示改为切换器名称。普通快速切换仍按松键确认。Esc 接入 `NavigationRoot` + `BackLayer`，在异步初始化前挂载，加载期间也可取消；完整按键规则见[当前交互](../RECENT-TABS.md#当前交互)。

快速点按防闪烁：网页浮层挂载后立即接收按键，面板和蒙层作为同一个视觉层延后 150ms 显示。期间松键立即确认并取消展示，即使后台切换响应较慢也不补显浮层。这个等待只控制视觉呈现，不推测松键、不延迟切换；持续按住才显示列表。Command Palette 和独立窗口兜底保持原行为。

独立窗口有系统边框。地址栏、受限页面、未注入页面或不匹配的 iframe 仍可能漏掉过早松键，需要 Enter。更新前打开的页面需要刷新；多显示器/多 Spaces 尚未完整验收。

## 2026-10-18 · 主面板内切换入口

首页改为最多 10 项的单组「推荐 / Suggested」，不再用 MRU 填充或承诺立即 Enter 回到上一页。提供可从首页及中英文主搜索直达的「Zing: Tab Switcher」，让最近标签切换也有完整鼠标路径。入口是 UI 导航，不记录使用习惯；点击、普通 Enter 或底栏主操作在当前 palette host 内嵌共享 `RecentSwitcherView`，不启动后台快捷键会话、不新开窗口。

内嵌子页搜索初始启用并聚焦，来源窗口其他标签按 MRU 展示、来源页置末，按标题／URL 筛选；仅点击候选、普通 Enter 或底栏「切换」确认，没有松键确认或快速点按展示延迟。未提供学习查询的切换仍不记录搜索习惯。取消、Esc、搜索尾部 esc 与底栏返回通过父面板 `BackLayer` 恢复原 query、selection、caret／选区与选中项可见位置；不建立第二个 `NavigationRoot`。共享列表、键盘保护和底栏契约，成功切换关闭主面板。

原快捷键启动的网页浮层／独立窗口、禁用搜索初态、松键握手与快速点按路径保持不变。复用组件而按入口区分确认与返回语义，不新增权限或持久状态。上述是行为与架构修订，历史验收仍仅适用于当时构建与用例。

## 未采用的方案

取代之前的原生 popup 和选中即预览方案。原生 popup 难以稳定承接切页焦点；即时切换偏离最终选中再确认的交互。本机助手与时间猜测均不纳入当前方案。
