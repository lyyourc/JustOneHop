# 0006 · 独立切换窗口与网页松键监听

状态：已采纳。记录日期：2026-10-15，基于现有实现与历史验收补录；不代表这些决策在同一天首次作出。

## 背景

需要按住快捷键选择最近标签、松开确认，并让快速点按直接返回上一页。Chrome commands 不提供全局 keyup；窗口就绪前松开修饰键可能丢失。

## 决策

独立扩展小窗口显示启动时固定的 MRU 列表，打开和导航只移动高亮，松键、Enter 或点击才切页。Esc、失焦、源页失效取消；确认前再次校验目标。

普通 HTTP(S) 页面预加载轻量修饰键监听，在窗口接管前缓冲真实松键；若后台启动前已经松键，则直接确认。受限页面继续使用独立窗口兜底，不以计时器推测用户松键，不安装本机助手。

## 取舍与影响

独立窗口有系统边框。地址栏、受限页面、未注入页面或不匹配的 iframe 仍可能漏掉过早松键，需要 Enter。更新前打开的页面需要刷新；多显示器/多 Spaces 尚未完整验收。

## 未采用的方案

取代之前的原生 popup 和选中即预览方案。原生 popup 难以稳定承接切页焦点；即时切换偏离最终选中再确认的交互。本机助手与时间猜测均不纳入当前方案。
