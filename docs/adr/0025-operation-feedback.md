# ADR 0025：所有操作提供可感知的结果反馈

- 状态：已采纳；统一反馈已实现，验证范围见[验收基准](../ACCEPTANCE.md)
- 日期：2026-10-21

## 背景

现有底栏已有操作状态槽位，但缺少覆盖所有操作的反馈契约。语言、主题等设置即使改变了界面，也无法仅凭外观变化确认保存是否完成；复制等操作更缺少直接可见的结果。用户需要知道操作是否被接收、是否完成及其实际结果。

## 决策

所有用户操作均须提供可感知反馈。搜索、选中和导航等即时交互以直接可见的状态或目标变化反馈；设置、复制、保存、删除与整理等执行型操作提供明确的文字结果。面板内统一复用底栏状态区域，保持焦点与连续操作，不额外增加确认步骤。

成功反馈以实际完成为前提；异步等待、部分完成与失败必须如实表达。语言与主题切换须确认具体选项，语言切换成功提示使用切换后的语言。具体黑盒契约统一维护于[交互架构 §5.5](../INTERACTION-ARCHITECTURE.md#55-操作反馈与结果确认)。

## 取舍

- 不对每次输入或选中显示成功提示，避免高频反馈淹没真正需要确认的结果。
- 设置的外观变化仍配合文字确认，以明确区分当前展示值与已保存结果。
- 复用底栏可保持布局稳定，但结果必须在菜单关闭与视图返回后仍可读，并避免连续异步操作相互覆盖。
- 会结束面板的跳转或来源页关闭遵守现有退出规则，以可见目标变化反馈，不为提示延迟退出。

本记录确立后续实现与评审的要求，不代表现有操作已全部满足或通过验收。
