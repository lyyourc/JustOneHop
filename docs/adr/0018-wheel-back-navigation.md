# 0018 · 面板内横滑复用逐层返回

状态：已采纳；实机原生手势未验证。记录日期：2026-10-18。补充 [ADR 0002](0002-shared-actions-and-navigation.md) 的返回入口，不改变 [ADR 0010](0010-content-anchor-panel-geometry.md) 的定位方案或暂停目标。

## 背景

面板已有点击、Esc 与适用的 Backspace 返回路径。横滑提供另一个可发现入口，但必须保持最深层返回、上下文恢复与文本滚动语义，避免惯性连续退出多层。

## 决策

- 使用 `@use-gesture/react` 的 `useWheel`，在 `NavigationRoot` 内真实 DOM surface 监听面板 wheel；使用实际承载文档中的节点，不依赖宿主全局 window 或无 DOM 的 `BackLayer`。
- 返回方向为 `deltaX < 0`（常见 macOS 自然滚动双指右滑）。达到距离阈值后显示蓝色箭头，子页、菜单或确认层立即调用最深活动层返回；继续拦截同一序列的惯性，静默 140ms 仅解锁下一手势。一次序列最多退一次，返回自身造成的层级变化不解除拦截。
- 关闭整个承载时仍等待 wheel 静默 140ms，包括主搜索关闭、快捷键 Tab Switcher 取消关闭和独立帮助关闭，避免残余惯性流入来源网页。
- 未达到阈值可反向、按键或点击取消，已执行的返回不撤销。键盘、点击或层级变化取消尚未执行的动作与提示，残余惯性不得重新触发。短滑、纵滑、缩放等不触发；可横向滚动的长文本／输入区域整段避让，即使到边界也不转成返回。
- 复用原返回回调与搜索、选择、滚动、光标／选区恢复。主面板先退最深层，根层关闭；内嵌 Tab Switcher 返回原主搜索；快捷键启动的 Tab Switcher 在网页浮层及独立窗口均取消关闭，不确认切换。
- 保留可点击返回和键盘入口，帮助文案补充横滑发现提示。不增加权限或持久状态，不实现未来拖动定位。

## 取舍与边界

子页返回后承载仍在，可立即响应并继续拦截惯性，免去额外等待；关闭承载会失去拦截面，因此保留静默等待。wheel 不能可靠识别手指数，也不提供可靠的惯性结束标记；140ms 仅是启发式序列边界，不能保证与系统原生手势完全一致。方案采纳及合成 wheel 验证均不能替代实机原生手势验证，当前不宣称后者已通过。

不在文本滚动边界接管，避免阅读长内容时意外退出；不另建导航栈，避免不同承载的返回与取消语义分离。
