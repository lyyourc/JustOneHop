# ADR 0030：设置保留跨分类搜索与分类导航

- 状态：已采纳；设置框架已实现，验证范围见验收矩阵
- 日期：2026-10-23
- 关系：局部覆盖 [ADR 0029](0029-task-page-headers.md) 对设置内子页顶部与返回位置的规定；保留其独立任务／详情页规则，延续 [ADR 0028](0028-custom-search-icon.md) 的显式保存语义

## 背景

设置是一个持续浏览、调整和检索的空间。将图标编辑等设置子页切换为独立任务页，会使跨分类搜索和分类入口消失，用户必须先退出当前任务才能寻找其他设置。ADR 0029 按单页任务决定顶部形态，适合独立任务；设置则需要让框架承担全局检索和位置感，正文承担当前任务。

## 决策与取舍

- 设置顶部固定跨分类搜索，下方以约 148px 左侧栏提供外观、快捷键、实验室、帮助四类入口，右侧显示内容。设置内子页继续保留这套框架；设置搜索胶囊左侧的瞬移徽章顺时针旋转 90° 充当返回入口，设置底栏不重复返回按钮。独立任务页的顶部返回采用同样徽章；普通二级搜索页的统一返回与底栏规则见 [ADR 0033](0033-secondary-page-navigation.md)。
- 底栏保持精简的一级标题展示（首页展示纯文本「JustOneHop」，设置展示「Settings」），去除多级嵌套面包屑，降低底栏信息密度与视线负担。侧栏承担分类导航，顶部徽章与 Esc 承担逐级返回来源，首页底栏左侧文字支持点击直达设置。
- 分类是并列目的地，普通切换不积累返回历史。子页保留真正的来源层级，从搜索结果进入子页后返回原检索上下文，避免返回键逐个回放浏览过的分类。
- 搜索临时展示全部分类中的匹配项；清空恢复原分类或子页及未保存草稿。明确通过返回、分类导航或其他目标离开图标页则放弃未保存草稿。这样既允许编辑中查找设置，也保留显式保存、明确离页即放弃的边界。
- 侧栏缩减了正文宽度，因此设置沿用与存储预览、详情和其他任务页一致的正文与卡片留白，通过信息分组和渐进展开维持可读性。时长等主要设置先于详细规则，当前状态与解释分层，避免为某个页面单独增加边距或把长说明挤在控件旁。
- 外观作为默认分类，集中语言、主题和搜索图标，避免为少量设置保留含义宽泛的通用分类；帮助作为并列目的地直接展示正文，减少一层入口。侧栏采用 Chrome 风格单色图标与柔和蓝色选中态；窄屏改用分类选择器，鼠标、键盘和交替操作均有完整路径。保持 750 × 516 CSS 像素尺寸上限，接受内容区域变窄及必要滚动，不通过扩大面板容纳导航。

保持全部设置为单列长列表虽无需侧栏空间，但分类定位与子页间探索不够直接；让每个子页沿用独立任务页顶部返回会中断设置级搜索。采用持续设置框架的代价是正文可用宽度减少、临时搜索需要保留原任务上下文，并存在独立任务页与设置内子页两类导航承载。通过明确框架边界、窄屏选择器和统一返回语义控制这些代价。

## 覆盖边界

本决策仅覆盖设置框架及其内部子页，包括搜索图标编辑、从设置打开的配置指南与帮助。独立打开的配置指南、收起恢复核对和存储详情继续遵守 ADR 0029；独立帮助保留全文搜索。保存、失败反馈、输入法保护、最深活动层返回与两种承载的几何边界沿用共享契约。

当前黑盒行为见 [交互架构 §6.5](../INTERACTION-ARCHITECTURE.md#65-设置面板-settings-view)，共享顶部与底栏例外见同文 §5.1、§5.3。采纳本决策不表示完成实现或浏览器验证，不沿用旧布局验收结论。
