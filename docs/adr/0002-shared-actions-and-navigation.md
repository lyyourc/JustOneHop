# 0002 · 共用操作组件与逐层返回

状态：已采纳；脚本页面适用范围于 2026-10-18 由 [ADR 0017](0017-remove-script-library.md) 更新。记录日期：2026-10-15，基于现有实现与历史验收补录；不代表这些决策在同一天首次作出。

下文脚本编辑与执行结果属于历史调用方，现已移除；共享底栏、操作菜单和逐层返回契约继续适用，独立 Ctrl+Tab 配置指南沿用这些组件。原文保留历史设计理由，不表示脚本功能仍可用。

## 背景

各页面分别维护按钮、菜单和 Esc 后，出现底部保存入口不明显、子页面返回失效、焦点落在标题或正文时行为不同等问题。用户希望操作一致，不需要重新学习每个页面。

## 决策

主搜索、脚本编辑、执行结果和 Storage 复用 PaletteFooter / ActionMenu。页面拥有业务状态、可用动作和焦点恢复；组件负责固定底栏、菜单搜索与导航。

NavigationRoot 统一捕获返回键，BackLayer 按 React 嵌套深度登记返回动作，每次只退出最上层。Esc 仅在主搜索关闭面板；Backspace 只在明确标记的空搜索框或非编辑控件返回，保留正常编辑语义。

### 2026-10-17 补充：搜索尾部返回统一

所有搜索输入尾部复用 SearchDismissButton，显示可点击 Esc 与明确动作说明；其鼠标调用 Navigation 的 useNavigateBack，与键盘共用 topLayer 判定，不复制页面 onBack 推断。这样主搜索、二级搜索、操作菜单及两种切换器不会因焦点或承载不同而退出不同层级。设置清空输入保留独立入口，操作菜单 Tab 包含 Esc 按钮。修复跨视图差异时先检查共享组件全部调用方，不通过页面特例补丁掩盖共用契约遗漏。

## 取舍与影响

页面必须登记层级并维护返回后的查询、选中项和文本选区。普通 Enter、保存快捷键和结果复制按当前页面语义执行，不能用全局 Enter 覆盖文本编辑。长按和输入法组合不能连续退出多层或误执行。

## 未采用的方案

不继续让页面各自监听 Esc、复制菜单实现；也不引入全局命令注册器或通用路由框架，现有页面规模只需要共享操作呈现和返回层级。
