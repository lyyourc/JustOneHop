# ADR 0023：品牌标志与图标来源

- 状态：已采纳
- 日期：2026-10-18

标志表达「小范围瞬移」：灰色虚线起点消散、蓝色实心落点出现并带一圈涟漪，不使用箭头或轨迹。蓝色只用于落点，图形不加满铺蓝底板。完整规范见 [docs/brand/LOGO.md](../brand/LOGO.md)。

扩展图标从 `docs/brand` 的 SVG 在构建时生成：16 / 32 px 使用裁边的简化浅色版，48 / 128 px 使用白色底板版，并新增 48 px 声明。取代 ADR 0022 中「图标不随改名重新设计」的状态，原旧图标 `public/icon.svg` 已删除。

Chrome 的扩展图标不随主题自动切换，目前只提供浅色工具栏版本；深色版本 SVG 已备好，按主题切换需另行评审。本次未做 Chrome 工具栏实测。
