# ADR 0023：品牌标志与图标来源

- 状态：已采纳
- 日期：2026-10-18

标志表达「小范围瞬移」：灰色虚线起点消散、蓝色实心落点出现并带一圈涟漪，不使用箭头或轨迹。完整规范见 [docs/brand/LOGO.md](../brand/LOGO.md)。

扩展图标从 `docs/brand` 的 SVG 在构建时生成。小尺寸版保持既有左右并排构图：左侧消散起点、右侧落点及涟漪。小尺寸适配仅裁去透明边并等比缩放，不为填满方形图标槽改变元素的相对位置、比例或品牌识别结构。工具栏在 16 / 32 / 48 / 128 px 全部使用透明简化版，扩展管理图标的 48 / 128 px 继续使用白色底板完整版。取代 ADR 0022 中「图标不随改名重新设计」的状态。

Chrome action 图标不会自动跟随主题。新增 `offscreen` 权限，以本地 `theme.html` 的 `MATCH_MEDIA` 原因监听 `prefers-color-scheme: dark`，由后台校验消息来源后串行调用 `chrome.action.setIcon`。面板关闭时仍可响应系统主题；后台重启时复用现有离屏页面并重新同步，不保存主题、不联网。实测离屏页面在模拟配色变化后读取值已更新，但 `change` 事件未送达，因此除事件监听外，复用 `alarms` 权限每 30 秒读取一次当前配色，并在窗口聚焦时立即同步；Chrome 休眠或调度可能延后闹钟，不承诺严格时间上限。安装、启动与窗口聚焦时检查离屏页面，创建并发合并，失败可在后续事件或闹钟重试。默认图标为浅色透明版。

此信号反映系统配色，不能读取 Chrome 自定义主题的实际工具栏背景、浏览器独立配色或无痕背景；不宣称与所有 Chrome 主题完全一致。工具栏不跟随面板强制浅／深色偏好，以免与浏览器背景脱节。

搜索框使用共享 `Logo`，直接内联同一小尺寸 SVG 并应用面板主题色。主搜索及二级搜索通过 `SearchFocusButton` 复用，Tab Switcher 保留自己的启用搜索行为但使用相同图形。按钮的焦点、选区保留和可访问名称保持原语义。

实际验证范围见 [验收记录](../ACCEPTANCE.md)，自动化结果不等同于日常 Chrome 工具栏人工验收。
