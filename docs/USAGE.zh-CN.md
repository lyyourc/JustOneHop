# 小范围瞬移 · 使用指南

[English](USAGE.md) · 简体中文 · [返回主页](../README.zh-CN.md)

**小范围瞬移（JustOneHop）** 是一款贴合 Chrome 原生体验的命令面板。无论你习惯键盘快捷键、鼠标点选，还是两者随时混用，都能在一个搜索框里轻松找网页、切标签、做整理。

## 1. 快速上手

<a id="使用帮助"></a>

在任意页面按下快捷键，或直接点击浏览器工具栏上的图标即可唤起面板：

- **macOS**：`⌘ + Shift + P`
- **Windows / Linux**：`Ctrl + Shift + P`

<picture>
  <img alt="统一搜索" src="store/zh-1-search.png" width="100%">
</picture>

刚打开还未打字时，首页会直接列出最常用的入口：**Tab Switcher（最近标签切换）**、**搜索全部历史**、**新建/刷新/固定/静音标签页**、**页面存储查看器**以及**设置与帮助**。

> [!TIP]
> 右键点击浏览器工具栏上的小范围瞬移图标，可以随时查看当前绑定的快捷键，或直接打开使用帮助。

## 2. 统一搜索：瞬移至任何内容

<a id="搜索与导航"></a>

想到什么就直接搜什么，支持中文、英文、全拼与拼音首字母：

![统一搜索演示](demo/zh-search.gif)

- **已打开的标签页**：输入标题或域名关键词，按 `Enter`（或鼠标点击）直接切过去。
- **书签与历史记录**：与标签页同框展示。按 `Enter` 在当前页打开，按 **`⌘Enter`**（Windows/Linux 为 **`Alt+Enter`**）在新标签页打开。需要找更早的网页？点击「搜索全部历史」或输入 `history`。
- **常用命令与浏览器页面**：直接输入 `新建标签`、`恢复标签`、`下载`、`扩展`、`密码`、`深色模式` 等日常词汇即可执行（若目标管理页已打开，会自动切过去而不重复开页）。
- **网址直达与 Google 搜索**：输入网址（如 `github.com` 或 `localhost:3000`）可直接跳转；没匹配到本地内容时，一键用 Google 搜索。

### 贴心细节

- **中文拼音混搜**：搜 `chanpinluxiantu`、`cplxt` 或 `notion luxian` 都能找到「产品路线图」。
- **输入补全与继续搜索**：搜过的词再次输入前缀时会出现浅色补全提示，按 **`Tab`**、**`→`** 或点底栏「补全」即可填入；刚从多个搜索结果里打开网页后，10 分钟内重新唤起面板还能直接「继续搜索」。
- **越用越懂你**：常选的结果会在同等相关性下自然靠前，右侧带有小钟表标记。想忘掉某条习惯？点标记上的 `×` 或按 **`Shift+Backspace`** 即可。

## 3. Alt+Tab 式切最近标签

<a id="3-最近标签页切换像-vs-code-一样顺手"></a>
<a id="最近标签页切换"></a>

想在刚刚看过的几个网页之间来回切换？**Tab Switcher** 按最近访问顺序（MRU）排列你的标签页：

<picture>
  <img alt="最近标签切换器深色模式" src="store/zh-2-switcher.png" width="100%">
</picture>

1. **按住修饰键不放**（macOS 默认 `Control`，Windows/Linux 默认 `Ctrl`）。
2. **点按触发键**（macOS 默认 `J`，Windows/Linux 默认 `,`）唤起列表，继续点按或用 `↑`/`↓` 选择目标页。
3. **松开修饰键**，立即切过去！

![最近标签页切换演示](demo/zh-switcher.gif)

- **中途打字筛选**：切换时发现标签太多？直接**用鼠标点搜索框**或按 **`⌘F`**（`Ctrl+F`），即可松开按键，打字筛选标题或网址。
- **纯鼠标也能用**：随时从面板首页点击 `Tab Switcher` 进入。

### 10 秒配置专属 Ctrl+Tab

<a id="ctrltab-配置"></a>

想用最顺手的 `Ctrl+Tab`？由于 Chrome 不支持在设置页直接敲击绑定该组合键，我们准备了一键配置向导：

1. 在面板中搜索 `ctrl tab`（或进入「设置 → 键盘 → Tab Switcher」）。
2. 点击底栏 **「复制并打开」**，自动复制配置脚本并打开 Chrome 快捷键设置页。
3. 按 **`⌘⌥J`**（Windows/Linux 为 **`Ctrl+Shift+J`**）打开控制台，粘贴并回车，即可一次性绑好 `Ctrl+Tab` 与 `Ctrl+Shift+Tab`。

## 4. 标签页连续整理与快捷操作 (`⌘K`)

<a id="整理标签页与继续操作"></a>

在任意标签页结果上**点击右键**、点底栏 **「操作」**，或按 **`⌘K`**（Windows/Linux 为 **`Ctrl+K`**），即可打开操作菜单：

![标签页操作演示](demo/zh-actions.gif)

- **固定 / 静音 / 刷新 / 复制链接 / 关闭标签页**
- **收藏或取消收藏（`⌘D` / `Ctrl+D`）**<a id="收藏与取消收藏标签页"></a>：不用切过去就能直接把目标网页存进书签。
- **原生标签组管理**：直接搜索标签组名称，即可查看组内网页、展开/折叠、重命名、解散分组（保留网页）或安全关闭整组（固定标签页始终受保护）。

> [!TIP]
> **为什么叫「连续整理」？**
> 只要操作的不是当前正在看的页面，执行关闭、固定或静音后**面板会保持打开，并自动选中相邻的下一项**。你可以一口气整理完好几个标签，不用反复重开面板。

## 5. 标签页收起 (Tab Tucking)：优雅地做减法

<a id="收起标签页"></a>

有些网页待会儿还要看、舍不得关，但留在标签栏又太挤？**收起标签页**会将它们移入 Chrome 原生折叠组「收起来」，不关网页、不丢状态：

- **手动收起**：搜 `收起标签页`（`tuck tab`），或在任意标签页的 `⌘K` 菜单中选择「收起标签页」。
- **空闲时自动收起**：在「设置 → 实验室 → 自动收起标签页」中开启。当电脑空闲或长时间未操作 Chrome 时，久未访问的网页会自动收起（当前页、固定页、正在播音的页面绝不会被误收）。
- **随时找回**：在主搜索或 Tab Switcher 里搜到该网页切过去，它就会自动回到日常标签栏；也可以搜 `撤销收起`（`undo tuck`）一键恢复最近一批。
- **整理收起组**：只要组名和所在窗口不变，改颜色、往组里添加标签后仍会继续管理并复用原组。手动加入的标签也会在选中或关闭自动收起时移回普通标签栏；「撤销收起」只恢复最近收起的批次。

## 6. 开发者利器：免开 DevTools 查看 Storage & Cookies

<a id="页面存储"></a>

想看一眼当前网站的 Token 或 Cookie，不用再按 F12 打开厚重的开发者工具。直接在面板里搜索：

- `local storage`（或 `本地存储`）
- `session storage`（或 `会话存储`）
- `cookie`（或 `cookies`）

左侧检索键名，右侧实时预览格式化高亮的 JSON 与 Cookie 属性；按 **`Enter`** 一键复制原始值。所有数据仅在内存中只读展示，Cookie 权限仅在你查看该站点时按需申请。

## 7. 导航、手势与个性化

<a id="面板位置底栏与返回"></a>

- **逐层返回不迷路**：按 **`Esc`**、点击左上角返回图标、在空输入框按 **`Backspace`**，或在触控板上**双指右滑（macOS）**，都会退回上一层并保留刚才的搜索词和选中位置。
- **个性化与设置**：点击首页底栏左侧的「小范围瞬移」（或按 `⌘,` / 搜索 `设置`），可切换深浅色主题、用 Emoji 或本地图片定制搜索栏图标，或点击底栏小动物开关键盘提示。
- **全场景可用**：在普通网页上以居中浮层展示；在 `chrome://`、应用商店等限制脚本的页面上，会自动切换为轻量独立小窗口。

## 8. 快捷键与鼠标操作速查

| 操作 | 鼠标 / 触控板 | macOS | Windows / Linux |
| --- | --- | --- | --- |
| **打开 / 关闭面板** | 点击工具栏图标 / `esc` | `⌘ + Shift + P` | `Ctrl + Shift + P` |
| **退回上一层** | 点击返回图标 / 双指右滑 | `Esc`（空框 `Backspace`） | `Esc`（空框 `Backspace`） |
| **上下选择** | 滚轮或悬停点击 | `↓` / `↑`（或 `Ctrl+N/P`） | `↓` / `↑`（或 `Ctrl+N/P`） |
| **打开选中项** | 单击结果行 | `Enter` | `Enter` |
| **在新标签页打开** | 点击底栏「新标签页打开」 | `⌘ + Enter` | `Alt + Enter` |
| **更多操作菜单** | 右键结果行 / 点击「操作」 | `⌘ + K` | `Ctrl + K` |
| **打开设置** | 点击首页底栏「小范围瞬移」 | `⌘ + ,` | `Ctrl + ,` |
| **遗忘某条学习记录** | 点击历史标记上的 `×` | `Shift + Backspace` | `Shift + Backspace` |
| **最近标签切换 (MRU)** | 首页点击 `Tab Switcher` | 按住 `Control` + `J` | 按住 `Ctrl` + `,` |
| **切换中途打字筛选** | 点击搜索框 | `⌘ + F` | `Ctrl + F` |
