## 1. 适用范围

本政策说明小范围瞬移如何访问、使用和保存数据。扩展用于搜索和管理浏览器内容，包括标签页、书签、历史记录和标签组，以及在用户主动操作时查看当前网站的存储。

小范围瞬移无需账号，没有开发者运营的后端服务，不包含遥测、广告或分析跟踪。扩展在本机处理功能所需的数据，不将这些数据上传给开发者，不出售用户数据，也不将其用于广告、信用评估或与所述功能无关的用途。

本政策适用于扩展本身。你主动访问的网站、Google 搜索及承载本政策的网页服务，分别适用其自身的隐私规则。

## 2. 扩展访问哪些数据

| 数据 | 用途与范围 |
| --- | --- |
| 标签页与窗口信息 | 读取标题、网址、标签页与窗口标识、分组、固定和静音等状态，用于搜索、切换和管理标签页。 |
| 书签 | 读取书签标题、网址和文件夹；按你的操作创建或删除 Chrome 原生书签。 |
| 浏览历史 | 查询最近浏览历史或你主动检索的全部历史范围，用于显示匹配结果。扩展不持久复制整个历史数据库，也不修改历史数据库。 |
| 最近关闭的会话 | 按你的操作恢复 Chrome 记录的最近关闭标签页或窗口。 |
| 网站 Local Storage、Session Storage 和 Cookie | 仅在你打开对应查看器时读取。Local Storage 和 Session Storage 限当前顶层页面；Cookie 限与当前页面网址匹配的记录，可包含 HttpOnly Cookie 和浏览器支持的当前分区 Cookie。查看器只读，不修改或删除这些值。网站可能在这些存储中保存个人信息或登录令牌。 |
| 键盘修饰键状态 | 网页中的快捷键桥接脚本监听可信键盘事件，维护 Control、Meta、Alt 的按下／释放状态，支持最近标签切换；不记录普通输入字符、输入框内容或页面正文。 |
| 系统空闲与配色状态 | 空闲状态用于安排自动收起；系统深浅色用于切换工具栏图标。 |

## 3. 本地保存的数据与保留方式

扩展使用 Chrome 的本地扩展存储和会话存储，不使用 `chrome.storage.sync` 同步这些数据到其他设备。

- **设置**：语言、主题和自动收起开关保存在本地，直到被修改或扩展数据被清除。
- **搜索排序记录**：部分成功执行的选择会保存规范化搜索词、目标标识、权重和最后使用时间。目标可能包含完整网页 URL（包括查询参数和片段）、书签 ID 或命令 ID；首页选择也可能形成记录。记录只用于本机排序，最多保留 500 条有效记录。超过 90 天的记录不再参与排序，后续记录写入或遗忘操作会清理旧记录；没有保证在第 90 天定时物理删除的后台任务。读取历史本身和失败的打开操作不生成选择记录。直接访问网址和 Google 搜索不写入此学习记录。
- **自动收起计时**：开启自动收起后，在本地保存适用标签页的完整网址和最后使用时间。关闭自动收起并完成清理后，计时记录清空。
- **分组恢复记录**：手动或自动收起会保存组名称、颜色、组内完整网址，以及同窗口其他 HTTP／HTTPS 标签页的完整网址，用于浏览器重启后核对组的归属。无法确认的记录可能继续保留，没有固定过期时间；关闭自动收起不保证清除所有待核对恢复记录。
- **会话状态**：面板来源、标签页／窗口／组标识、切换状态及收起撤销信息用于当前运行会话。其中部分保存在内存，部分使用 Chrome 会话存储；关闭面板会清理对应面板会话记录。
- **网站存储查看内容**：读取的名称、值和属性仅在当前查看面板内存中处理，不写入扩展的持久存储，不发送给开发者。关闭查看面板后，扩展不再保留该面板中的内容副本。你主动复制的内容会进入系统剪贴板；关闭面板不会清空剪贴板，系统或其他剪贴板工具可能继续保留副本。

## 4. 网站权限和快捷键脚本

扩展在安装时声明标签页、书签、历史、Cookie 等功能权限。面板注入及 Local Storage／Session Storage 读取使用用户操作触发的 `activeTab` 临时授权。

为识别最近标签切换期间修饰键的释放，轻量快捷键脚本会在 Chrome 允许访问的 HTTP／HTTPS 页面及子框架中自动运行。它不等待 Cookie 查看器的逐站授权，也不记录页面打字内容。

`cookies` API 权限在安装时声明；读取 Cookie 还需要适用的网站访问权限。缺少所需权限时，扩展提供授权入口，由你点击后向 Chrome 请求。请求范围为当前主机以及读取父域 Cookie 所需的父主机，止于可注册域边界，覆盖 HTTP／HTTPS 和全部路径，不包含兄弟子域通配符。例如，`a.b.example.com` 的请求可包含 `a.b.example.com`、`b.example.com` 和 `example.com`。

这是 Chrome 网站访问权限，不是仅适用于 Cookie 或某个网页路径的权限。已有适用授权时可能不再弹窗。你可以在 Chrome 的扩展详情和网站访问设置中查看或撤销授权；撤销后，相应功能可能无法继续使用。

## 5. 外部访问和数据共享

扩展不会在你输入搜索词时向搜索引擎请求在线建议。你主动执行 Google 搜索时，浏览器会打开带有查询词的 Google 搜索网址，Google 会收到该查询及正常网站访问产生的信息，其处理受 [Google 隐私政策](https://policies.google.com/privacy) 约束。

你主动打开网址、书签或历史结果时，浏览器也会访问对应网站。此类导航属于你请求的功能，不是向开发者上传浏览数据。

扩展使用 Chrome 的站点图标接口，不调用第三方图标服务；执行代码随扩展打包，不下载并执行远程代码。开发者不接收上述扩展功能数据，也不将其提供给数据经纪商、广告商或分析服务。

## 6. 你的控制方式

- 在设置中使用“重置搜索排序”清除排序学习记录，或使用结果的排序说明入口忘记相关偏好。目前没有关闭排序学习的独立开关，后续符合条件的成功操作仍可能生成新记录。
- 关闭自动收起可停止自动收起并触发相关清理。对待核对的分组恢复记录，可使用“停止恢复这条记录”；该操作移除记录，不关闭页面或删除原生组。
- 在 Chrome 扩展设置中撤销网站访问权限。重置搜索排序不会撤销权限，也不会清除设置或全部收起恢复记录。
- 从 Chrome 移除扩展会移除该安装的扩展本地存储。扩展没有额外的服务器副本需要申请删除。卸载不会撤销你已对 Chrome 原生书签、标签页、历史或标签组所做的操作，也不会清空系统剪贴板或删除其他工具保存的副本。

如果你允许扩展在无痕窗口运行，扩展不会在该窗口查询普通浏览历史或记录搜索选择学习；收起功能排除无痕标签页。无痕窗口内主动使用其他功能仍会处理完成操作所需的数据。
